★ **회차 문서 어디도 이 파일들을 경로로 부르지 않는다.** 결론은 이미 `findings.jsonl` 과
`premortem/*.md` 에 좌표·해시와 함께 실려 있다. 여기 있는 것은 **그 결론이 선 바닥**이고,
다시 재야 할 때 무엇과 대조할지를 준다.

⚠ **전부 HEAD `1a01057` 에서 떴다.** 지금 HEAD 와 다르므로 심볼 다이제스트를 나란히 댈
때는 그 사실을 먼저 적어라 — 같은 심볼이라도 `palimpsest@<sha>+worktree#<hex>` 의 앞쪽이
갈린다.

## 다시 재려면

`clone-before/after` 의 재현 절차는 `premortem/r2-raw.md` 가 진다. **격리 사본의 디렉터리
이름을 `palimpsest` 로 두어라** — 이름이 `RepoId` 의 성분이라 다른 이름으로 뜨면 심볼 id 가
통째로 어긋난다.

`p.txt`/`t.txt` 의 실험은 **기계를 옮기면 값이 또 갈린다.** 이 산출은 macOS 의 ugrep 7.8.4
와 BSD grep 에서 뜬 것이고, Linux 의 GNU grep 은 셋째 값을 낼 수 있다. 다시 돌릴 때
**어느 grep 인지 먼저 적어라.**
