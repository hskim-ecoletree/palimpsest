## 합이 의도를 덮나

합격선 문면은 덮인다. **전제 문면에 덮이지 않는 대목이 둘** 있다.

**①** *"그 산출을 **본** 뒤의 변경이 달라졌는지 잰다"* — **「본」을 재는 조건이 없다.**
`A5`·`A5-b` 가 재는 것은 **touch 가 코드를 본 시각**이지 **사람이 touch 산출을 읽었다는
사실**이 아니다. `C2` 의 귀속이 간접 증언이지만, 차선책 1 이 *"`C2` 가 0 이면 반증으로 적고
멈춘다"* 를 여니 **`C2` 가 0 인 갈래에서는 「봤다」를 대는 자리가 하나도 안 남는다.**
`## 범위 밖` 의 *"사전 등록을 쓰는 손과 실제 변경을 쓰는 손이 같다"* 는 **성실성**의 한계를
적은 것이고 이것은 **열람 사실**이라 같지 않다.

**②** *"하한 1 을 지키되 **상한을 3 으로 잠근다**"* 가 실질로 안 선다. ㉢ 의 touch 답이
후보 목록이면 산출에 사실 줄이 **구성상 없다**(실측: `pal touch write` 는 후보 3 줄 + 고정
근거 상자뿐이고 `※ 파일 간 해소 …` 같은 사실 줄이 `Ambiguous` 가지에서 아예 안 찍힌다 —
`crates/pal-cli/src/touch.rs:271-277`). 그러면 **㉢ 은 `C2` 의 귀속 모집단에 착수 시점부터
0 으로 들어간다.** `C5` 가 *"0 인 자리도 그대로 적는다"* 로 받지만, 인터뷰가 잠근 표본 셋 중
하나가 **합격선에 기여할 수 없는 자리**라는 사실은 조건 어디에도 안 적혔다.

**의도보다 큰 것은 없다.** `A5-c` 가 원문이 요구하지 않은 제품 결함 관측이지만
*"관측만 하고 안 고친다"* 로 묶여 있어 초과로 안 센다.
