## 실패한 접근 — 같은 벽에 다시 부딪히지 마라

1. **`^- \[` 로 상자를 세지 마라.** 코드펜스 안의 형식 예시와 `## 범위 밖` 불릿까지 센다
   (실측 `3/4`). 그리고 **열림 쪽만 고치면 분모가 깨진다** (`2/3`). `record.py` 의
   `조건들()` 을 불러라 — 저장소에서 상자를 읽는 자는 그것 하나다.
2. **절을 볼 때 깊이를 봐라.** 조건은 `## 완수 조건` 아래 `###` 하위 절에 산다.
   깊이를 안 보면 첫 하위 제목이 절을 덮어써 **회차 셋 전부에서 0** 이 나온다.
3. **`intent.md` 에 새 frontmatter 를 만들지 마라.** 게이트→`intent.md` 링크가
   **이미 둘에 있다**(`round-finding-records.md:9` · `round-completion-condition.md:4`).
   모자란 것은 `rust-extractor.md` 한 줄이고, 게이트는 회차 끝에 쓰이므로 **죽은 링크가
   원리상 안 생긴다.** 반대 방향은 회차 내내 17 번째 검사를 빨갛게 한다(격리 사본 재현).
4. **게이트 `## 판정` 을 정규식으로 통째로 훑지 마라.** 잡음이 지배한다 —
   `F04`~`F18` · `R8`~`R12`(정정 라운드) · `S01`(사전부검 시나리오) · `P1`~`P3`(진자).
5. **기존 게이트 표를 갈아엎지 마라.** 두 게이트의 모양이 **서로 반대**다 —
   `round-finding-records` 는 판정 열이 없고 `rust-extractor` 의 ⓐ 는 묶음 행이 없다.
   **표준 표를 위에 더하고 기존 표는 남긴다.**
6. **원 반환문의 기각 표 헤더는 `| # |` 로 시작해라.** 아니면 `xtask` 가 헤더를
   데이터 행으로 세어 합계 검산이 어긋난다 (내가 R3 에서 밟았다).
7. **레코드 좌표를 자동 추출하지 마라.** 51 행이 **안 만들기로 한 자리**를 가리켜
   `(경로 없음)` 으로 낮춰야 했다. 손으로 적거나 뽑은 뒤 존재를 확인해라.
8. **문서 안에 `](../../..` 꼴 문자열을 코드 스팬으로도 두지 마라.** 죽은 링크 검사가
   마크다운 링크로 오인한다.
