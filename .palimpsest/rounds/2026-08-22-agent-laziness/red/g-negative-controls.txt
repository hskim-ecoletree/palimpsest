# G — 음성 대조 (격리 사본) · 2026-08-23

## G7 — `record.py add` 가 파일 머리 줄 버전을 본다

```
$ record.py add <스키마 2 파일이 있는 회차>   # 지금은 3 을 쓴다
  ✗ <격리 사본>/g/r2/findings.jsonl: 머리 줄이 스키마 2 인데 지금 쓰는 것은 3 이다 — 한 파일에 형식 둘을 섞지 않는다. 이주하거나 새 파일을 열어라
rc=1

$ 같은 것을 스키마 3 파일에 (대조군 — 통과해야 한다)
<격리 사본>/g/r3/findings.jsonl: 1행 추가
rc=0
```

## `닫힘` 인데 시점이 없으면 형식 오류

```
  ✗ 1행: `닫힘` 인데 `닫은커밋` 이 없다 — **시점 없는 닫힘은 주장이지 기록이 아니다**
rc=1
```
