# F — Stop 훅 관측 (2026-08-23)

**관측만 한다.** 정책은 안 세우고 `crates/pal-cli/src/hook/policy.rs` 의 `EVENTS` 를
안 건드린다 (사전부검 승격 1 · 소유자 답 *"Stop 은 관측만 · 정책은 다음 회차"*).

## 어디서 쟀나

**격리 디렉터리**다. 이 저장소의 `.claude/settings.json` 은 **만들지도 고치지도 않았다**
— 회차 내내 없다. 훅 하나가 두 사건을 다 받는다: **같은 파일·같은 배선**이어야
양성 대조가 선다.

### `settings.json`

```json
{
  "hooks": {
    "Stop": [
      { "hooks": [ { "type": "command", "command": "$CLAUDE_PROJECT_DIR/hook.sh Stop" } ] }
    ],
    "SubagentStop": [
      { "hooks": [ { "type": "command", "command": "$CLAUDE_PROJECT_DIR/hook.sh SubagentStop" } ] }
    ]
  }
}
```

### `hook.sh`

```bash
#!/bin/bash
# 훅 하나가 두 사건을 다 받는다 — **같은 파일·같은 배선**이어야 양성 대조가 선다.
DIR="$(cd "$(dirname "$0")" && pwd)"
IN="$(cat)"
EV="$1"
ACTIVE=$(printf '%s' "$IN" | python3 -c 'import json,sys;print(json.load(sys.stdin).get("stop_hook_active"))' 2>/dev/null)
N=$(cat "$DIR/count-$EV" 2>/dev/null || echo 0)
N=$((N+1)); echo "$N" > "$DIR/count-$EV"
echo "[$EV] 호출 $N · stop_hook_active=$ACTIVE" >> "$DIR/log.txt"

# ★ **`stop_hook_active` 가드** — 없으면 메인 세션이 안 끝난다.
#   실측(policy.rs 머리): 1회차 false · 2회차부터 true 로 들어온다.
if [ "$ACTIVE" = "True" ] || [ "$ACTIVE" = "true" ]; then
  echo "[$EV] 가드 발동 — 통과시킨다" >> "$DIR/log.txt"
  exit 0
fi
# 자기 상한 — 가드가 안 먹는 하네스에서도 갇히지 않는다.
if [ "$N" -ge 3 ]; then
  echo "[$EV] 자기 상한 3 — 통과시킨다" >> "$DIR/log.txt"
  exit 0
fi
printf '{"decision":"block","reason":"[%s] 훅이 막았다 — 이 문장이 모델에 닿았으면 block 이 먹은 것이다. 그대로 `HOOK-BLOCK-SEEN` 이라고만 답하고 끝내라."}' "$EV"
exit 0
```

## ① 관측 — `Stop` 에서 `exit 0` + 표준출력 `{"decision":"block",…}` (F2)

프롬프트: *"그냥 'PING' 이라고만 답하고 끝내라. 도구를 쓰지 마라."*

```
$ claude -p --permission-mode bypassPermissions --max-turns 8 "…"
모델 출력:
claudeHOOK-BLOCK-SEEN

훅 로그:
[Stop] 호출 1 · stop_hook_active=False
[Stop] 호출 2 · stop_hook_active=True
[Stop] 가드 발동 — 통과시킨다
```

**먹는다.** 모델이 `PING` 대신 훅이 준 문장을 따라 `HOOK-BLOCK-SEEN` 을 냈다 —
**차단의 `reason` 이 모델에 닿았고 턴이 이어졌다.** 두 번째 호출에서
`stop_hook_active=True` 로 들어왔고 가드가 통과시켜 세션이 끝났다.

## ② 양성 대조 — 같은 설정으로 `SubagentStop` (F1)

**이것이 없으면 ① 은 판정이 아니다.** 「Stop 이 block 을 안 받는다」와
「내 settings.json 이 틀렸다」가 구별 불가이기 때문이다.

```
$ claude -p … "Task 도구로 general-purpose 에이전트 하나를 띄워라 …"
훅 로그:
[SubagentStop] 호출 1 · stop_hook_active=False
[SubagentStop] 호출 2 · stop_hook_active=True
[SubagentStop] 가드 발동 — 통과시킨다
[Stop] 호출 1 · stop_hook_active=False
[Stop] 호출 2 · stop_hook_active=True
[Stop] 가드 발동 — 통과시킨다
```

**먹는다.** `SubagentStop` 이 서브에이전트 종료에서 발화해 막았고, 같은
`stop_hook_active` 진행(1회차 `False` → 2회차 `True`)을 보였다. 그 뒤 `Stop` 이
메인 세션에서 같은 일을 했다. **배선이 옳다는 것이 증명됐으므로 ① 은 진짜 측정이다.**

## ③ `stop_hook_active` 가드 (F3)

가드가 없으면 훅이 매번 막고 **메인 세션이 원리상 안 끝난다.**
로그가 그 자리를 보여 준다 — 2회차에 `True` 로 들어오고 훅이 통과시킨다.

⚠ **가드만으로는 모자란다.** `policy.rs` 머리가 적어 둔 실측:
*"매 라운드 도구를 부르는 서브에이전트는 100회까지 한 번도 안 멈췄다 — 하네스가
반복 차단을 못 멈춘다."* 그래서 이 훅은 **자기 상한 3** 도 함께 걸었다.
이번 관측에서는 가드가 먼저 발동해 상한이 안 쓰였다 — **상한 자체는 미발화**다.
