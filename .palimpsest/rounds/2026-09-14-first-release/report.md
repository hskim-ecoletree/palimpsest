## 하네스가 설계대로 안 돈 것 — **대가를 적는다**

- **병합 검증이 CI 걸음 하나를 빠뜨렸다.** `cargo xtask test`·`check` 만 돌려 CI 의 `doctor --full` 구조 판정을 못 잡았다 — CI 두 번이 빨갰다.
- **README 의 공유 문장이 실행 전에 쓰였다.** 리허설이 거짓을 잡았다. 실행 뒤에 쓰는 것이 맞았다.
- **음성 대조 `D1-a` ⑴ 가 두 번 무효였다** — 내보내기 없이 잰 것, 상위 디렉터리가 없어 내보내기가 실패한 것. 둘 다 「결박을 안 넘겨서 0」이라 항등식이었다. 걸음을 README 모양으로 먼저 못 박지 않은 대가다.
- **구현을 워크트리 셋에 병렬로 맡겼다.** 규약에 없는 짜임이다. 병합 충돌 하나를 풀었고, 저장소 안의 워크트리 사본이 로컬 문서 검사에 잡음(죽은 링크 602)이 생겼다 — 깨끗한 클론에서 재서 가렸다.
- **그래프를 `grep` 대신 부르지 않았다**(규약 §6). 구현 코드 지도를 조사 에이전트가 문자열 검색으로 만들었다.
- **조건이 열일곱이다.** 소유자가 고른 「가볍게」 에 댄 에이전트의 어림 「열 안팎」보다 많다 — 음성 대조가 규약상 따로 ID 를 받는다. 라운드는 1 · 1 · ⟨리뷰⟩ 로 가볍게 돌았다.

## 능력 부재

- **「요약 규칙을 바꾸면 어느 결박이 뒤집히나」** — 결박이 감시하는 심볼이 속성이나 `self` 수신자를 지는지를 그래프가 답하지 못해, `A2-b` 의 모집단(20)을 원문 텍스트를 읽는 일회성 스크립트로 셌다. 이 회차가 `Symbol.decor` 를 그래프에 올려 **이제 그 물음의 재료가 그래프에 있다.**
- **「설치가 무시 목록에 무엇을 넣나 · 승인이 무엇을 어디에 쓰나」** — 설치·승인의 파일 효과를 그래프가 안 담아 코드와 실행으로 봤다. README 의 거짓 문장이 거기서 났다 — #166 이 공유 원장의 물음을 진다.
