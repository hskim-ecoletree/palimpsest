## 계획

순서는 **틀린 사실 → 거짓 0 → 화면 → 받는 길**이다. 뒤의 것이 앞의 것을 싣고 나가기 때문이다.

1. **#127 ①** — `doctor` · `export` 의 `Coverage { unresolved: 0, lowest_grade: L0 }` 하드코딩을 **그래프 전체를 만지는 명령으로서
   센 값**(`graph.dump` 와 같은 규칙)으로 바꾼다. `coverage_of` 의 *"질의마다 다른 값"* 설계와 그 시험은 **안 건드린다.**
   **②** 는 재현되지 않으므로 `06-doctor-full.txt` 를 근거로 이슈에 답한다. **③**(주석만 바뀐 구간의 본문 해시가 같음)은 ADR-0007 의
   설계라 이슈에 답한다. `ledger.snapshot` ↔ `graph.dump` 의 차이도 설계라고 답한다.
2. **#77 ①②** — Rust 선언 앞의 `attribute_item` 형제와 `self` 수신자의 `&` 가 **변했는가** 에 들어가게 한다. span 은 안 넓힌다.
   TypeScript·Kotlin 의 요약값은 바이트로 안 바뀐다.
   ★ **이미 선 결박의 판정이 코드 변화 없이 뒤집히면 안 된다**(착수 판정 `05-binding-status-start.json.txt`). 갈래는 루프에서 고른다 —
   ㉠ 결박 시점 스냅샷에서 새 규칙으로 요약을 다시 계산해 대 본다 · ㉡ 속성·수신자를 요약과 다른 축으로 두고, 그 축 없이 선 결박에는
   「속성은 감시 안 함」을 드러낸다. **어느 쪽이든 결과를 `A2-b` 가 잰다.**
3. **#139** — **스키마를 안 바꾸는 쪽을 본선으로 한다**: 파일 간 해소가 크레이트 경계를 넘는 임포트에서 대상 `mod` 선언이 **사적**이면
   엣지를 안 만들고 못 푼 참조로 까닭을 적는다 — 마지막 경로 조각의 이름이 사적 `mod` 와 재수출된 항목에 **함께** 붙는 실물 모양
   (`mod traverse;` + `pub use traverse::{…, traverse}`)이 대상이다. 크레이트 안 모듈 참조(참인 56)는 그대로다. 스키마·행 형식을 바꾸게
   되면 `ROW_FORMAT_REV` 와 `EXTRACTOR_REV` 를 **같은 커밋에서** 올린다.
4. **#159** — `pal install` 이 `.palimpsest/manifest.toml` 에 `[[repo]] id` 를 적는다. **값은 `bindings.jsonl` 의 결박이 선 식별자**가
   하나로 정해지면 그것이고, 결박이 없으면 디렉터리 이름이다. 매니페스트가 이미 있으면 안 건드린다.
   `touch` 는 **지금 식별자와 다른 식별자에 걸린 결박이 있으면**(매니페스트 유무와 무관하게) 그 사실과 수를 낸다.
   install 이 만든 매니페스트는 **커밋되기 전이면** `uninstall` 이 되돌리고, 커밋된 뒤에는 사용자의 선언으로 두어 안 지운다.
5. **#156** — `touch` 가 호출자 자리(경로:줄)를 앞 몇 개 싣고, 나머지는 `pal query symbol.callers` 로 **그대로 쳐서 펴지는 명령**을 안내한다 —
   이름이 여럿이면 `--pick <짧은 해시>` 까지 싣는다.
6. **받는 길** — 루트 `README.md` · `LICENSE-MIT` · `LICENSE-APACHE`(`Cargo.toml` 의 선언 그대로) · 워크스페이스 버전 `0.1.0` ·
   릴리스 워크플로의 「담는다」가 루트 README 와 라이선스를 싣고 낡은 주석을 고친다 · 「툴체인 없이」 걸음에 **받은 바이너리로 `touch` 한 번**을 더한다.
   **태그 전에 `workflow_dispatch` 로 한 번 돌려 초록을 본다.** 그 뒤 태그 `v0.1.0` push.
7. **효과** — ditto 의 **새 복제본**에서 **릴리스에서 받은 바이너리**로 README 걸음을 그대로 밟는다. 승인으로 결박을 만들고
   매니페스트와 `bindings.jsonl` 을 **그 복제본에 커밋한 뒤**, 그 복제본을 **다른 디렉터리 이름으로 클론**해 같은 `touch` 를 부른다.
   **같은 절차를 install 부터 착수 바이너리로** 돌려 둘째 클론이 0 을 내는 것을 대조로 둔다.
8. **처분** — R3 39 건을 철회 사유 ②로 코멘트와 함께 닫는다 · 사용 기록 이슈를 세워 착수 목록 첫 자리에 둔다(`docs/plan/02-order.md` 의
   첫 항목 문장) · `docs/plan/03-shortest-path.md` 에 끝의 정의와 릴리스 뒤 순서(언어 확장)를 적는다 · R1 다섯에 답하고 닫는다.
