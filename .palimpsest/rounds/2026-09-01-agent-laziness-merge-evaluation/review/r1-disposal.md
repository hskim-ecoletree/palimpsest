| 발견 | 처분 |
|---|---|
| R1-01 | R1-02와 같은 schema 1 호환 경계로 묶어 #101의 합격선으로 전환했다 |
| R1-02 | main 병합 금지역으로 판정하고 #101의 합격선으로 전환했다 |
| R1-03 | main 병합 금지역으로 판정하고 #101의 합격선으로 전환했다 |
