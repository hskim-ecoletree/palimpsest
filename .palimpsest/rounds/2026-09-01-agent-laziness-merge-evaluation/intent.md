## 개정

- 사전 실패 분석에서 source checkout의 설치 검사 Residual과 그래프 전수 판정을 섞으면 A3가 원래 의도보다 넓어진다고 확인했다. A3를 `answer`의 그래프 전수 결과로 한정하고 설치 배선은 A1·A2의 install 시험과 CI가 맡도록 바로잡았다.
- 같은 분석에서 “기존 회차의 실행 가능한 합격선”이라는 표현이 어떤 원장을 뜻하는지 모호했다. 이 브랜치에 실제 `GATES.md`가 있는 실행 계획 원장의 재검증과 저장소 전체 회귀 검사로 A2를 명확히 했다.
- 독립 검토가 schema 1 현재성 우회, 빈 종료문 통과, shallow clone 실패와 실행 계획 §8의 미완수 조건을 재현했다. 이는 평가 범위 밖 새 요구가 아니라 A1·A2·A4의 반증이다.
- A1·A2·A4가 반증됐으므로 A5용 최종 SHA를 push하지 않았고, A6의 선행조건이 서지 않아 병합하지 않았다.
