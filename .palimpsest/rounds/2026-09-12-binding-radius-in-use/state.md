## 걸리는 것 — 값을 치르고 배운 것

1. **`rc` 는 판정이 아니다.** 파이프 끝이 `tail` 이면 실패한 실행도 `rc=0` 이다.
2. **검증 중에 커밋하지 마라.** 빌드 시점 커밋과 실행 시점 HEAD 가 갈린다.
3. **`.palimpsest/intent.redb` 는 파생물이다.** 정본은 추적 중인
   `.palimpsest/intent/bindings.jsonl` 이다. 결박을 만진 뒤에는 반드시
   `pal intent import <추적본>` → `pal intent export --out <추적본>` 하고 diff 를 봐라.
   ★ **이 회차는 그 파일을 직접 고치는 회차다** — 이 함정이 다른 어느 회차보다 세게 걸린다.
4. **`state.md` 의 수를 믿지 마라.** 정본은 `cargo xtask check` · `record.py count` ·
   게이트 `## 판정` 이다.
5. **push 는 한 번.** CI 가 `cancel-in-progress: true` 다. 종료 판정은 「초록을 봤다」가
   아니라 **「회차의 마지막 커밋 SHA 에 `conclusion=success`」**다.
6. 이 PC 에 **pyenv 도 rustup 도 없다**. 파이썬은 repo `.venv`(3.12) 또는 `python3`,
   Rust 는 1.94.1 고정.
7. `pal` 을 쓰려면 `PATH="$PWD/target/release:$PATH"` 가 필요하다. `target/` 은 저장소에 없다.
