## ⑤ `Undeterminable` 이 `Stale` 을 가린 건수 ⟨`C2`⟩

```
undeterminable{watch_member_gone} = 0
id 집합 = []
```

**0 이다. 0 이어도 적는다** — 조건이 그것을 요구한다.

⚠ **0 이 나온 것은 우연이 아니라 설계다.** `pal radius` 는 감시 집합을 **HEAD 의
이웃에서 펴고**(`expand`) 기준값만 base 커밋에서 읽는다. base 에서 펴면 지금 없어진
심볼이 감시에 들어와 `WatchMemberGone` 이 `Stale` 을 덮는다(`evaluate` ②가 ③④ 앞에서
반환한다 · `crates/pal-core/src/binding.rs:636-643`). 코퍼스 실측이 그 전환을 `callers`
반경에서 **84 회** 로 적었으므로 그것은 드문 사고가 아니라 **예상된 대량 발생**이었다.
**그 경로가 실재함은 단위 시험이 붙든다** — `사라진_감시_원소가_변한_것을_가린다`.

## ⑥ ★★ 퇴행 상한 ⟨`C4`⟩

```
새로 stale 이 된 결박            = 5
undeterminable 로 옮겨간 결박     = 0
합격선: 옮겨간 것 ≤ 새 stale     → 0 ≤ 5  =  통과
```

**되돌린 결박은 없다.** 불통과였다면 그 결박들을 안 넓힌 상태로 되돌리고 id 집합을
여기 적어야 했다 — 그 길이 안 열렸다.
