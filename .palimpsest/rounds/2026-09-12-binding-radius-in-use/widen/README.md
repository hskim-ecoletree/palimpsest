# 결박 37 건의 반경 판정 — 넓히기 **전에** 세운다

> 회차 `2026-09-12-binding-radius-in-use` · 2026-09-13
> 산출: [`decisions.tsv`](decisions.tsv) — 열 이름 줄 + **37 행**

## 왜 넓히기 전인가 ⟨조건 `B2-a`⟩

원문 25 행이 *"기존 결박 37 건을 어떻게 하나? → **내가 근거를 대고 넓힌다**"* 다.
그 **「내가」가 소유자인지 실행자인지 문면으로 안 갈린다**(조건 평가 `CA1-12`).
어느 쪽이어도 서게 만드는 길은 하나다 — **판정을 보이는 자리에 먼저 세우는 것.**

**참여는 승인 요청이 아니라 가시성과 개입 가능성이다.** 그래서 이 파일을 넓히기 **전에**
커밋하고, 두 커밋의 SHA 가 다르며 앞이 뒤의 조상임을 `git merge-base --is-ancestor` 로
잰다. 판정을 소유자에게 **넘기지 않는다** — 넘기면 그것이 책임 전가다.

## ★ 판정이 측정값을 복사하지 않았다 — 검산

**가르는 물음: 판정이 호출자 수와 상관되나.** 상관되면 그것은 판정이 아니라 측정값의 복사다.

| 모집단 | `영향받는다` | `아니다` |
|---|--:|--:|
| **호출자 0 인 13 건** | **7** | **6** |
| 호출자 있는 24 건 | 11 | 13 |

**두 줄이 반반이다.** 호출자 0 인 것이 `아니다` 로 몰리지도, 호출자 많은 것이
`영향받는다` 로 몰리지도 않았다 — 예컨대 `1cc70cc19ef92186`(호출자 **17**)이 `아니다` 이고
`fd4efc1eaea040c4`(호출자 **0**)가 `영향받는다` 다.

## 무엇을 넓히나

| | 수 |
|---|--:|
| `판정 = 영향받는다` → `callers` 로 넓힌다 | **18** |
| `판정 = 아니다` → `symbol` 그대로 | **19** |
| 그중 감시 집합이 **실제로** 커질 것 | **11** |
| 넓힌 뒤 감시 합 (착수 **37**) | **190** |
| 다른 파일에 있는 새 원소 (조건 `B8`) | **112** |
| base 커밋에 없던 새 원소 (조건 `A3-b` ⑵) | **10** |
| `대상digest차이` 가 참인 넓힐 결박 (조건 `A3-b` ⑴) | **0** |

⚠ **넓힌 수는 합격선이 아니다** — `## 차선책` 둘째 항. 18 이라는 수가 이 회차의 성과가
아니고, **37 건 전부의 판정과 근거가 산출로 남는 것**이 요구다.

⚠ **`판정 = 영향받는다` 인데 감시가 안 커지는 일곱**은 `callers` 로 넓히되 그 사실을
적는다 — 산출에 `callers` 라 적히고 감시가 1 인 것이 사람에게 *"호출자를 지켜본다"* 로
읽히는 것이 `PM1-07` 이 잡은 거짓 신호이고, 조건 `B4` 가 그 건수와 까닭을 요구한다.

★ **`대상digest차이` 가 넓힐 18 건에서 전부 `거짓`이다.** 기준 시점 근사(base 커밋 ≠
결박한 순간의 워킹트리)가 **이 회차에서는 실제로 물지 않았다**는 뜻이다. 37 건 전체에서
참인 것은 하나(`49714573e0fa654c`)이고 그것은 `아니다` 라 안 넓힌다.
**그래도 그 열을 세운 것은 「이번에 안 물었다」와 「원리상 안 문다」를 가르기 위해서다.**
