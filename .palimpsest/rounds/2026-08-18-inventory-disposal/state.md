## 실패한 접근 — 이 회차 (다음 컨텍스트가 같은 벽에 안 부딪히도록)

**① `mapfile` 을 썼다.** macOS 의 bash 는 3.2 라 `mapfile`·`readarray` 가 없다.
`set -u` 와 겹쳐 「unbound variable」로 조용히 죽었다.

**② 첫 효과 탐침이 너무 넓었다.** *"이 저장소는 무엇을 만드는 물건인가"* 는
`AGENTS.md`·ADR-0025 가 이미 최신이라 **처분 전에도 맞게 답한다.** 탐침을
*"에이전트에 물리려면 · `P7` 은 유효한가 · MCP 는 어떤 자리인가"* 로 좁히자
세션이 스스로 *"문서 세 층이 서로 다른 답을 갖고 있어서"* 라고 진단했다.
★ **효과 측정은 낡은 문서가 실제로 답을 오염시키는 물음을 골라야 한다.**

**③ `crates/pal-cli/assets` 를 표면으로 더하려 했다.** `rust_sources()` 가 `.rs` 만
모아서 *"표면 소스에 Rust 파일이 없다"* 로 죽는다. 그리고 넣어도 잡을 것이 없다
(질의 10 개 이름이 거기 평문 0 건 · 따옴표 0 건). **허수 표면은 하한을 허수로 만든다.**
답은 `SURFACE_MIN` 을 1 로 내리는 것이었다 — 빈 목록은 `0 < 1` 이라 여전히 잡힌다.

**④ sunset 트리거를 파일 **이름**으로 잡으려 했다**(`round.json`). 병렬 회차 B 가
저장 형식을 아직 안 정했으므로(`redb` 인가 파일인가) 이름을 고정하면 **검사가
태어나면서 죽는다.** 갈래로 잡았다 — 사람은 `.md`, 기계는 `.json`.

**⑤ 죽은 링크를 일괄 치환했더니 텍스트가 안 따라왔다.** `AGENTS.md` 의
*"완성되면 실제로 어떻게 쓰이나"* 행이 **처분표를 가리키는** 꼴이 됐다.
★ **링크만 고치면 안 되는 자리가 있다 — 행 자체가 비는 문제다.**

**⑥ 렌더러 문자열에 상대 링크를 두려 했다.** `xtask/src/` 에 살면서 `docs/` 아래에
파일을 내므로 **두 기준 중 하나에서 반드시 죽는다.** 링크를 안 쓰고 코드 표기로 적었다.

**⑦ `git add -A <경로>` 가 pathspec 오류로 중단됐다.** 이미 스테이지된 삭제 경로를
`-A` 와 함께 주면 `did not match any files` 로 죽고 **그 뒤 인자가 전부 무시된다.**
삭제만 든 커밋이 나갔다. 되돌려(`reset --soft`) 다시 냈다.

**⑧ 내 실측 넷이 사전부검에 반증됐다.** 게이트 33(실은 **34**) · DESIGN 결정 94(실은
**99**) · 에픽 13(실은 **12** — `#41` 은 `epic` 라벨이 없다) · `P8` 근거 하나(실은 **둘**).
★ **처분 목록을 실측 없이 쓰면 무동작 항목이 섞인다** — `__pycache__` 를 `.gitignore`
에 넣는다고 적었는데 **이미 있었다**(`:15`).

**⑨ ★ 문자열 두 개 사이를 잘라내는 치환이 절 여섯을 통째로 삼켰다.** `## 산출` 을
실측치로 고치려고 *"`## 산출` 부터 `**프론티어가 바뀌었다**` 까지"* 를 갈아 끼웠는데,
그 사이에 **`## 산출 파일` · `## 착수 기준선 — 실행` · `## scripts/ 41 판정` ·
`## 실패한 접근 — 이 회차` · `## 결박` · `## 검증 기록` 여섯 절**이 있었다.
`state.md` 가 215 → **79 줄**이 됐다.

**나쁜 것은 삼킨 것이 아니라 조용했다는 것이다** — `cargo xtask check` 는 18/18 초록이고
죽은 링크도 0 이다. 검사는 **파일이 가리키는 것**을 보지 **파일이 담고 있어야 하는 것**을
안 본다. `grep` 으로 최신 회차를 더하려다 *"치환이 안 걸렸다"* 를 보고서야 알았다.

**규율**: 문자열 두 개 사이를 잘라내는 치환은 **자르기 전에 그 사이에 무엇이 있는지
센다.** 그리고 `git show <직전>:<경로>` 가 언제나 복원 경로다 — 실제로 그것으로 되살렸다.

★ **「취소 0」이라 적었는데 틀렸다.** 독립 리뷰 4 라운드가 실측으로 잡았다 —
회차 **32077912109 @ `ac39982`** 는 `cancelled` 다.

**내가 등록한 규율을 내가 깼다.** 의도 §개정이 *"커밋은 나누되 **push 는 한 번** 한다.
나눠 push 하면 앞의 런이 취소된다"* 를 적어 놓고, 독립 리뷰의 발견을 닫느라 앞 런이
끝나기 전에 다음 push 를 밀었다. 앞 회차가 정확히 같은 자리에서 6 잡 초록을 죽였고
그 실패가 규약에 들어갔는데, **이 회차가 그 규약을 쓰면서 같은 실수를 했다.**

★ **그리고 회차 기록이 그것을 덮었다.** 「취소 0」은 관측이 아니라 **내가 그럴 것이라
믿은 값**이었다 — `gh run list` 를 다시 안 봤다. **낡는 캐시를 없애는 회차가 자기
검증 기록에 캐시를 하나 두고 있었다.**

**규율**: 검증 기록의 각 행은 **`gh run view <id>` 를 다시 돌려** 적는다. 「그때 초록이었다」는
기억이지 관측이 아니다.

★ **판정에는 안 걸린다** — 종료 조건 6 은 *"**회차의 마지막 커밋 SHA** 에
`conclusion=success` 런이 붙어 있다"* 이고, `44150ab` 의 회차 **32078444814** 가
**7 잡 전부 success** 다. 중간 커밋의 취소는 그 SHA 의 판정이 아니다.

★ **새 검사가 세 OS 에서 같은 수를 냈다** — 모집단·링크·죽은 것이
`ubuntu`·`macos`·`windows` 전부에서 **글자까지 같다**(수는 안 적는다 — 회차 중에 세 번 움직였다). 경로 구분자와 줄바꿈이 갈리는
자리라 [ADR-0023](../../../docs/adr/0023-consistent-method-and-result-across-platforms.md)
이 정확히 겨냥하는 지점인데 안 갈렸다 — `상대_경로()` 가 `\\` 를 `/` 로 정규화한 덕이다.

★ **push 는 앞 회차가 끝난 뒤에만 민다** — `cancel-in-progress: true` 라 나눠 밀면
앞의 런이 죽는다. **그런데 한 번 어겼다**(위 `ac39982`). 앞 회차도 같은 자리에서
6 잡 초록을 죽였고 그 실패가 규약에 들어갔는데, **이 회차가 그 규약을 쓰면서 같은
실수를 했다.** 규율은 문서가 아니라 **push 전에 `gh run list` 를 보는 한 줄**이다.

⚠ **커밋 수·마지막 SHA 를 여기 안 적는다** — 리뷰 라운드마다 커밋이 나서 세 번 낡았다.
`git log --oneline 2989527..HEAD | wc -l` 과 위 검증 기록의 마지막 행이 답한다.

## 산출

⚠ **이 절을 세 번 고쳤고 세 번 다 낡았다.** 처음엔 회차 중간(`6c5651f` · 커밋 9)의
수를 적었고, 실측으로 다시 적은 뒤에도 커밋이 셋 더 나면서 또 어긋났다.

★ **그래서 수를 안 적는다.** 회차의 규모는 **명령이 답한다**:

```bash
git diff --shortstat 2989527..HEAD                      # 파일 · 줄
git log --oneline 2989527..HEAD | wc -l                 # 커밋
find docs -name '*.md' | xargs wc -l | tail -1          # docs 줄 수 (착수 28,314)
git diff --name-status 2989527..HEAD --diff-filter=A    # 생긴 것
```

**이것이 이 회차의 논지가 자기 문서에 적용된 자리다** — *"환경도 진실원이다. `--help`·
설정 파일·디렉터리 배치가 답하는 것을 문서가 복제하면 그 문서는 낡는 캐시다"*
(AGENTS.md). **`git` 이 답하는 것을 회차 기록이 복제하면 매 커밋마다 거짓이 된다.**

**프론티어가 바뀌었다** — 열린 이슈 22 → **11**, **막힘 11 → 0**. 에픽들이 막고 있던
의존이 전부 풀렸다. 착수 가능 11 건 중 **둘**(`#68` sunset · `#69` 문서 엣지)이
「만들 것」이고 아홉이 「고칠 것」이다.
