## 퇴로

**등록해 두면 나중에 쓰는 데 승인이 필요 없다.**

- **DESIGN 94 행 대응표가 회차를 다 먹으면** → `D1~D35` **35 행은 반드시 적고**,
  좌표로만 서는 59 개는 절 단위로 묶어 16 행으로 낮춘다(계 51 행). 그 사실을
  게이트 `## 판정` 에 적는다.
- **`xtask` 가 sunset 트리거를 코드로 못 잡으면** → 선언 파일 + GitHub 이슈로 낮추고,
  「구조적 강제가 못 선 이유」를 게이트 `## 판정` 에 적는다.
- **죽은 링크가 소스 주석 86 건까지 합쳐 손으로 안 끝나면** → 검사는 그대로 넣되
  **모집단을 문서로 좁히고**, 소스 주석은 검사가 세기만 하고 실패시키지 않는
  경고로 낮춘다. 남은 수를 게이트 `## 판정` 에 실측치로 적는다.
- **`crates/pal-cli/assets` 를 표면으로 더하는 것이 `check_catalog` 를 못 세우면**
  → `SURFACE_SOURCES` 를 `crates/pal-cli/src` 하나로 두고 **`SURFACE_MIN` 을 1 로
  내리되**, 「무엇이 약해졌는가」를 상수 주석과 게이트에 함께 적는다.
- **CI 가 병렬 회차 B 와 부딪히면** → `gh run list` 로 진행 중인 회차를 확인하고
  기다린다. 죽였으면 다시 push 한다.
- **처분 후 효과 측정이 B 의 push 와 섞이면** → A 의 마지막 처분 커밋 SHA 로
  `git worktree` 를 떼어 거기서 잰다. 그것도 안 되면 **측정이 교락됐다는 사실**을
  게이트 `## 효과` 에 적는다 — 틀린 답이어도 붙인다.
