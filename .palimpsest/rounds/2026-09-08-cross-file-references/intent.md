**축1 — 임포트 문의 경로 접두**

| 안 | 밖 |
|---|---|
| 균일 경로 형제 모듈 (`use inside::{Rel, Root}` · `use common::{…}`) | `pub use` 재수출 추적 |
| 형제 크레이트 깊은 경로 (`use pal_intent::round_condition::ConditionsReport`) | |
| 형제 크레이트 평평 경로 중 대상이 그 크레이트 루트 `lib.rs` 의 최상위 `pub` 인 것 (`use pal_git::GixRepo`) | |
| **`crate::`·`super::`·`self::` 접두** ⟨2026-09-08 에 들어왔다⟩ | |

**축2 — 참조 자리의 갈래**

ⓐ 파일 경계 넘기와, `use` 로 들어온 이름에 한한 ⓑ(`S::foo()`)는 **안**.
ⓒ(`x.foo()` 멤버 해소)는 **밖** — 타입 추론이 필요하다.

★ **이 두 축은 같은 낱말(「경로 해소」)로 부르지 않는다.** 판 1 이 그 낱말이 잠긴 의도
안에서 두 축을 가리킨다는 것을 실패급으로 잡았다 — 이름이 두 축을 가리키는 채로

### A — 파일 간 참조 해소가 선다

- [ ] A1 `use` 로 들어온 이름의 참조가 **다른 파일의 심볼을 가리키는 `REFERENCES` 엣지**가 된다 — 단위 시험이 픽스처 두 파일에서 엣지 1 건을 단언한다
- [ ] A2 그 엣지가 **`counts.locals` 로 안 샌다** — `RefCounts` 에 파일 간 갈래가 서고, 오늘 `locals` 로 흐르던 임포트 참조가 그 갈래로 옮겨간 것을 시험이 단언한다
- [ ] A3 잠근 축1 의 임포트 형태 **넷 각각**에 대해 엣지가 서는 것을 시험이 단언한다 — 균일 경로 형제 모듈 · 형제 크레이트 깊은 경로 · 형제 크레이트 평평 경로(루트 최상위 `pub`) · `crate::`·`super::`·`self::` 접두
- [ ] A4 **별칭과 중첩 목록에서 거짓 엣지가 안 선다** — `use a::Error as IoError;` 와 `use b::{c::C, d::D};` 를 심은 픽스처에서 엣지의 대상이 원본 심볼이거나, 못 풀면 엣지가 아니라 미해소로 나간다
- [ ] A6 **산출된 파일 간 엣지의 해소 등급(`ResolutionGrade`)이 후보 유일이다** — 후보가 유일하지 않은 참조는 엣지가 아니라 미해소로 나간다. 시험이 동명 심볼 둘을 심은 픽스처에서 그것을 단언한다. ⚠ **어느 `Exact` 인지 못 박는다** — 이 저장소에는 `ResolutionGrade::Exact`(임포트·정의가

  「exact 만」은 **앞의 것**이다. `IdentityGrade` 는 `#133` 이 지는 축이라 이 회차 밖이다.

### B — 못 푼 참조가 표시된다

- [ ] B1 `UnresolvedRef` 가 스키마의 사전 등록된 네 칸(`site`·`name`·`reason`·`attempts`) 그대로 서고 `cargo xtask check` 의 스키마 정합이 통과한다 — ⚠ 오늘 `schema/graph.toml` 이 그 노드를 `status = "not_built"`·`built_by = "F08"` 로 적고 Rust 타입은 **거주 불가한 빈 enum** 이라, 값을 세우려면 **그 둘을 함께 뒤집어야** `xtask` 의 *"not_built 인데 값을 만들 수 있다"* 검사를 지난다
- [ ] B2 `attempts` 가 **빈 배열이 아니다** — 실제로 시도한 해소 경로가 실린다. 원천이 없으면 이 조건은 반증이고, 빈 배열로 채우고 통과라 적지 않는다
