## 능력 부재

- **그래프가 Python 선언에서 Rust 검사로 이어지는 소비 관계를 못 답한다.** 실측:
  `pal query symbol.resolve 게이트파서` · `조건파서` 둘 다 *"이 스냅샷에서 찾지 못했습니다"*
  이고 가까운 이름도 0 이다. `pal query --list` 가 그 능력을 **`F07 cross-file-resolution`**
  으로 이름 붙여 「아직 못 만든 능력」에 싣는다.
- **그래서 이 회차의 소비 관계는 전부 코드 판독과 변이 실측이 냈다.** 그래프가 답한 것은
  `check_ledger_pair` 의 좌표 하나뿐이고(`xtask/src/main.rs:4934`), 역방향 호출자는
  `(없음)` 이었다. 모델 추정이 그 자리를 메운 것이 아니라 **변이가 메웠다** — 그 차이를
  적어 둔다.
