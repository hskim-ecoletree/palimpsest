# 원 결함의 재현 — 서명은 「망가뜨렸는데 초록」이다 (2026-09-03)

**재현 대상**: #94 본문의 *"이 사전의 기계 소비자가 `0` 이다. 아무도 안 읽는 선언이라
갈렸다는 것을 아무것도 못 잡는다"*.

★ **이 결함의 관측 가능한 서명은 빨강이 아니라 초록이다.** 소비자가 0 인 선언은 망가뜨려도
검사가 아무 말을 안 한다 — 그것이 결함의 정의다. 그러므로 아래 ②가 「초록」인 것이 재현
성공이고, 빨강을 얻으려 하면 그것은 다른 것을 재는 것이다.

## 어디서 쟀나 — 격리 사본이고, 사본이 사본을 잰다

```
git clone --no-local <저장소> red && cd red && git checkout 8af2240^   # → 0bdf66e
cd red && cargo xtask check      # 사본 안에서 **빌드해서** 돌린다
```

`cp -R`·`rsync` 가 아니라 `git clone` 이다 — 이 저장소의 `.git` 은 워크트리 포인터라
디렉터리 복사로는 이력이 안 따라오고, 이력이 없으면 「발견이 닫혔나」가 변이와 무관하게
빨개져 대조가 통째로 죽는다.

그리고 **프리빌트 바이너리에 `--root <사본>` 을 주지 않았다.** 사본 안에서 `cargo` 가
그 커밋의 `xtask` 를 빌드하므로, 재는 자와 재이는 것이 같은 판이다. 현재 판의 바이너리로
옛 트리를 재면 「`반환형식.반드시있어야하는절` 이 비었다」 같은 **버전 스큐**가 나오고,
그것을 RED 로 적으면 귀속이 통째로 틀린다.

## 세 관측

| # | 사본에 건 것 | 명령 | 종료값 | 결과 |
|---|---|---|--:|---|
| ① 기준 | 없음 | `cargo xtask check` | 0 | 검사 23/23 통과 |
| ② 재현 | 두 사전의 **손으로 쓴 규칙 잎 열넷 전량**을 `XX_거짓_규칙_XX` 로 (아래 「도달」이 셌다) | `cargo xtask check` | **0** | **검사 23/23 통과 — 아무것도 안 울었다** |
| ③ 음성 대조 | 같은 파일의 `종류` 를 `["XX_거짓_종류_XX"]` 로 | `cargo xtask check` | **1** | `FAIL 회차 레코드` · `Error: 1개 검사가 실패했다` |

②와 ③은 **같은 커밋 · 같은 사본 · 같은 파일**을 건드렸다.

## 도달 — **변이가 그 사본의 `--schema` 출력에 실제로 닿았다**

등록된 음성 대조의 셋째 절이다. ⚠ **`red-baseline.txt` 와 `red-mutated.txt` 는 바이트가
같다** — 둘 다 「23/23 통과」라서 그렇다. 그러므로 그 둘만으로는 「부수는 손이 닿았는가」를
못 말한다. 사본에서 `--schema` 를 변이 전후로 되읽어 직접 셌다:

```
$ python3 .claude/skills/round/bin/record.py --schema   # 변이 전 · 후를 각각
{"바뀐 잎": 14, "목록": ["조건파서.형식", "조건파서.ID문법", "조건파서.규칙더", "조건파서.규칙",
 "게이트파서.표", "게이트파서.검산", "게이트파서.형식이전", "게이트파서.빈모집단",
 "게이트파서.전량0", "게이트파서.미측정노출", "게이트파서.짝중복", "게이트파서.게이트없음",
 "게이트파서.하한", "게이트파서.대조밖"]}
```

두 사전의 **손으로 쓴 규칙 잎 열넷이 전부** 거짓 값으로 바뀌어 출력에 실렸다.
(`절`·`판정` 둘은 그 판에서도 상수 참조라 이 치환의 대상이 아니었다.)
독립 리뷰 2 라운드가 *"그 산출물이 없다"* 고 잡았고, 그래서 이 절을 더했다.

## 음성 대조가 무엇을 막나

③이 없으면 ②의 초록은 두 가지 중 어느 것인지 못 가른다 — *"선언에 소비자가 없다"* 인지
*"사본을 부수는 손이 애초에 아무 데도 안 닿았다"* 인지. ③이 빨개지므로 **부수는 손은
닿았다.** 남는 해석은 앞의 것 하나다.

## 무엇이 재현됐나

`8af2240^` 시점의 `조건파서`·`게이트파서` 는 `--schema` 의 **최상위**에 있었다 —
`종류`·`필드`·`enum` 과 같은 자리다. 그 판의 `xtask` 는 스키마에서 `종류` 하나만 읽는다.
**자리는 정본인데 읽는 자가 없었다.** 그래서 코드와 갈려도 검사가 못 잡고, 독립 리뷰
세 라운드가 사람 눈으로 같은 자리를 세 번 냈다(#94 본문).
