# 반(反) — `pal-decision-opponent` 의 원 반환문

> 초안(`thesis.md`)과 측정 산출물만 주었다. 대화 기록도 메인의 사고 과정도 안 줬다.

프롬프트에 사고 과정·대화 기록은 섞여 오지 않았다. 초안 전문과 측정 산출물만 받았고, 저장소를 직접 읽어 검증했다.

## 초안이 서는 자리

- **A2 의 「설명 밖 소비자 0」 방향은 변이가 아니라 정적 판독으로도 선다.** `닫힘축.뜻`(`record.py:377`) · `반환형식.역사형식`(`:454`) · `반환형식.판정인절`(`:522`) 셋은 `xtask/src/main.rs` · `record.py` · `extract.py` · `dashboard.py` · `crates/pal-cli/tests/round_scripts_run.rs` 전체에서 **정의 자리 1회 외 참조가 0**이다(`grep -rn '판정인절\|역사형식\|"뜻"' --include='*.rs' --include='*.py'` → 3줄, 전부 record.py 정의). 초안의 이 절반은 못 무너뜨렸다.
- **B2 의 아홉이 「고유 진단」이라는 주장은 참이다.** `m_B2-요구하는자리_check.txt:24`(「`IR1-05` 가 … `intent.md` 를 안 만졌다」) · `m_B2-의도파일_check.txt:24`(`plan.md`) · `m_B2-닫힘값_check.txt:27`(「`상태` 이 `닫힘` 다」) · `m_B2-열림축필드_check.txt:27`(「`상태2` 이 없다」) · `f_B2fix-면제출처_check.txt:24`(「`합계검산.면제출처` 에도 없고」) — 검사 이름은 겹쳐도 진단문은 키마다 갈린다.
- **변이 방법론(매번 원본 복원 · 기준 재측정 · 음성 대조)은 성립한다.** `red-observation.md` 의 `git clone --no-local` + 사본 안 빌드 + 대조 ③(`종류` 변이 → rc 1)은 「부수는 손이 닿았다」를 실제로 세운다.
