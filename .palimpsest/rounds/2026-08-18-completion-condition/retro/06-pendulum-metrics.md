# 진자 지표 — 등록 (C5 단계 1·3)

> ★ **알려진 셋을 보기 전에 등록한다.** 이 문서가 커밋된 뒤에야 처치군에 돌린다.
> 순서를 지키지 않으면 통과 조건이 곧 훈련집합이 되어 **검출기는 새 진자를 잡는다는
> 증거를 하나도 못 낸다**(사전부검 S4).

## 지표 셋 — 서로 다른 기제라 단일 지표로 안 덮인다

### P1 — 순변경 공집합

```
조건: 구간 안에서 그 경로가 2 회 이상 커밋됐고,
      git diff <착수> <종료> -- <경로> 가 공집합이다
```

**기계가 정확히 잰다.** 애매함이 없다. 잡는 것: 「고쳤다 되돌렸다」.

### P2 — 되돌린 줄

```
조건: 뒤 커밋이 앞 커밋이 추가한 줄을 삭제했다
      (git log -p 로 같은 경로의 +줄 이 뒤에서 -줄 로 나온다)
```

잡는 것: 부분 진자 — 파일 전체는 순변경이 있으나 **어떤 줄이 왕복**했다.

### P3 — 토큰 왕복

```
조건: git log -S'<토큰>' <구간> 이 3 커밋 이상이고,
      토큰의 최종 존재 여부가 착수 시점과 같다
```

잡는 것: 파일이 아니라 **문자열**이 왕복한 것.

## 오탐 상한 — 측정 전에 박는다

**실측된 기준선**: 구간 `2989527..7b683d0` 의 커밋이 만진 경로는 **167 개**이고
그중 **2 회 이상 만져진 것이 58 개(35%)** 다.

★ **「파일 ≥2 회 수정」은 지표가 아니다** — 35% 를 표시하면 *"회차 전체를 진자로
표시"* 이고, 등록된 음성 대조가 그것을 금지한다.

| 지표 | **오탐 상한** | 근거 |
|---|---|---|
| **P1** | 처치군 경로의 **5%** 이하 (167 중 **8 이하**) | 순변경 0 은 드물어야 정상이다. 흔하면 회차가 헛돈 것이고 그것 자체가 신호다 |
| **P2** | 처치군 경로의 **10%** 이하 (167 중 **16 이하**) | 부분 왕복은 P1 보다 흔할 수 있으나 여전히 소수여야 한다 |
| **P3** | 토큰별로 잰다. **후보 토큰 목록을 먼저 등록**하고 그중 몇이 걸리는지 센다 | 토큰은 내가 고르므로 사후 맞춤 위험이 가장 크다 |
| **셋의 합집합** | **20%** 이하 (167 중 **33 이하**) | 이것을 넘으면 「진자」가 회차의 정상 상태를 가리키게 된다 |

**상한을 넘으면**: 등록된 퇴로대로 **「이 지표로는 진자가 안 갈린다」를 산출로 내고
C7 후보에서 진자 기반 조건을 내린다.** 문턱을 사후에 맞추지 않는다.

## 홀드아웃 — 처치군에 돌리기 전에 (C5 단계 2)

**앞 회차 구간 `a0fbf72..2989527`** (커밋 7) 에 먼저 돌린다.

- 그 회차는 **사람이 진자라고 부른 적이 없다.** 종료 보고도 `state.md` 도 진자를 안 적었다.
- 그러므로 **거기서 나오는 것은 전부 오탐 후보**다.
- ★ **반대로 오탐이 정확히 0 이면 그것도 신호다** — 지표가 처치군에만 맞게 좁은 것이다.
  (커밋 7 개짜리 구간이라 표본이 작다는 것을 함께 적는다.)

## P3 의 후보 토큰 — 먼저 등록한다

사후 맞춤을 막기 위해 **처치군에 돌리기 전에** 후보를 적는다. 고른 규칙:
*"회차의 커밋 제목·본문에서 규약·표기로 쓰인 말"*.

| 토큰 | 왜 후보인가 |
|---|---|
| `계획 §` | 규약 표기 후보로 언급된 적이 있다 |
| `옛` | 「사라진 문서를 현재형으로 안 부른다」 규약의 표기 |
| `DESIGN §` | 삭제된 문서의 절 인용 |
| `WHITEPAPER` | 삭제된 문서 이름 |
| `how-it-works` | 삭제된 문서 이름 |
| `docs/adr/README.md` | 1 라운드가 만든 파일 |

⚠ **`계획 §`·`옛` 은 알려진 진자·규약과 겹친다.** 겹친다는 사실을 여기 적어 두어
「이 토큰이 걸린 것」이 발견이 아니라 **설계상 예상된 것**임을 뒤에서 구별할 수 있게 한다.
겹치지 않는 넷(`DESIGN §`·`WHITEPAPER`·`how-it-works`·`docs/adr/README.md`)이
**P3 의 진짜 시험**이다.
