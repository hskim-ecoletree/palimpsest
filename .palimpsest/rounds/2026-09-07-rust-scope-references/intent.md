# 잠긴 의도 — Rust 스코프와 참조 엣지

> 회차 `2026-09-07-rust-scope-references` · 착수 커밋 `a774053` · 이슈 [#130]
> 상태는 [`state.md`](state.md) 가 진다.

## 원문

소유자가 인터뷰 한 라운드에서 고른 것. **요약하지 않는다.**

- Rust 추출 등급을 이번 회차에서 L1 → L2 로 올리나 — **「엣지만 · L1 유지」**.
  > 고르면 일어나는 일: ScopeChain 을 채워 REFERENCES 엣지는 산출하되 `grade_of(Rust)` 는
  > `L1` 그대로 둔다. body_digest 가 안 움직여 결박 25건과 골든 파일이 그대로 있다.
  > 숨은 위험: 「L2 승격」이 다음 회차로 밀리면 그것이 꼬박힌 「나중에」가 된다.
  > 이슈로 세워야만 막는다.
- `impl` 블록의 스코프 소유(#78)를 이번에 포함하나 — **「분리한다 — #78 이 진다」**.
  > 숨은 위험: 이 저장소는 `impl` 블록이 많아 「줄어든다」의 크기를 안 재 봤다 —
  > 합격선이 그만큼 낮아져야 한다.
- 매크로 호출(`assert_eq!` · `vec!` · `println!`) 안의 이름을 참조로 세나 — **「센다」**.
  > 숨은 위험: `println!("{x}")` 의 포맷 문자열 캡처는 문자열 안이라 원리상 못 본다 —
  > 「센다」고 적어 놓고 일부만 세게 된다.
- 완수의 증인을 무엇으로 잡나 — **「세 자리 + touch 호출자」**.
  > `REFERENCES ≥ 100` 이고 이 저장소 Rust 심볼 하나에 `pal touch` 를 걸었을 때 호출자
  > 칸이 값을 돌려준다. 드러난 위험: `100` 의 근거가 실측이 아니다.

## 완수 조건

### A — 추출기가 산출한다 (결정론적 · 단위 시험)

- [ ] A1 Rust 스코프 사슬이 선다 — `mod m { fn f() { let x = 1; } }` 에서 스코프가 셋 이상이고 `ScopeChain::refs` 가 비지 않는다
- [ ] A2 **`impl` 이 스코프를 연다** — `impl A { fn new(){} } impl B { fn new(){} }` 에서 두 `new` 가 서로 다른 스코프에 서고 `file_edges` 가 엣지 0 을 낸다
- [ ] A3 평범한 호출 참조가 엣지가 된다 — `fn a(){} fn b(){ a(); }` 에서 `b → a` 엣지 정확히 하나
- [ ] A4 매크로 안 호출이 엣지가 된다 — `fn a()->u32{0} fn b(){ assert_eq!(a(), 0); }` 에서 `b → a`
- [ ] A5 매크로 안 **멤버 이름**은 참조가 아니다 — `assert!(x.foo())` 의 `foo` 가 `refs` 에 없다
- [ ] A6 매크로 안 **경로 꼬리**는 참조가 아니다 — `matches!(k, S::Var)` 의 `Var` 가 `refs` 에 없다
- [ ] A7 매크로 **밖** 경로 꼬리도 참조가 아니다 — `Self::new()` 의 `new` 가 `refs` 에 없다
- [ ] A8 `use` 절 안의 이름은 참조가 아니다 — `mod t { use super::*; fn f(){} }`
- [ ] A9 `x.foo()` 의 `field_identifier` 는 참조가 아니다
- [ ] A10 타입 이름이 값 자리에서도 해소된다 — `struct S; fn f(){ let _ = S; }` 에서 `f → S`
- [ ] A11 `imports` 가 `Capable::Present` 이고 `use a::b` · `use a::{b,c}` · `use a as e` · `use a::*` 넷이 각각 무엇을 담는지 시험이 단언한다
- [ ] A12 `exports` 가 `Capable::Present` 이고 **정렬·중복 제거된 뒤** `digest` 를 부른다
- [ ] A13 `pub` 의 뜻이 하나로 정해져 있다 — `pub(crate)` 와 중첩 `pub` 을 담는지가 시험으로 갈리고, **`stitch_of` 가 최상위만 EXPORTS 로 옮긴다는 사실**(`ledger.rs:377`)이 그 선택의 근거에 인용돼 있다
- [ ] A14 **지역 이름이 묶인다** — 파라미터 · `let` · `match_arm` 패턴 · `for x in` · `if let Some(x)` 다섯 자리에서 선언된 이름이 그 스코프 밖으로 안 샌다
- [ ] A15 **속성 안의 이름은 참조가 아니다** — `#[cfg(test)] fn a(){} fn test(){}` 에서 `test` 로 가는 엣지가 안 선다
- [ ] A16 **`impl` 메서드 이름이 모듈 스코프로 안 올라간다** — 호이스팅을 `hoist_home` 으로 표현하면 `impl` 스코프를 건너뛰어 A2 가 무효가 된다
- [ ] A17 **`cfg` 쌍둥이 선언은 엣지를 안 만든다** — 같은 스코프에 같은 이름이 둘이면 해소하지 않는다. `stitch_of` 가 EXPORTS 에서 이미 그렇게 한다(*"둘 이상이면 담지 않는다 — 하나를 고르면 그것이 조용한 오답이다"*)

## 차선책

- **B1 이 기여 파일 80 개에 못 미치면** — 그 수를 적고 어느 갈래가 얼마를 떨어뜨렸는지
  계수한다(파일 안 한정 · 최상위 참조 · 거르기 규칙 각각). B1 은 **반증**으로 적고
  [`03-shortest-path.md`](../../../docs/plan/03-shortest-path.md) §6 의 반증 1 번을 발화시킨다.
  **수를 낮춰 통과시키지 않는다** — 그것은 완화이고 승격이다.
- **E1 의 표본 30 건에서 가짜가 나오면** — 그 가짜가 어느 갈래에서 왔는지 대고 그 갈래의
  거르기를 고친다. 표본을 다시 뽑아 재는 것은 되고, **표본 규칙을 고쳐 가짜를 빼는 것은
  안 된다** — 그것이 측정 뒤에 합격선을 옮기는 것이다.
- **C2 가 흔들리면** — `body_digest` 가 왜 움직였는지를 먼저 대고, 원인이 등급이 아니라
  다른 것이면 그것을 고친다. 등급이면 이 회차의 전제가 무너진 것이라 **승격**이다.
- **C7(TypeScript 산출 불변)이 깨지면** — 공용화가 TypeScript 를 건드린 것이다. 뼈대에서
  갈라야 할 것을 안 갈랐다는 뜻이므로 그 자리를 찾아 고친다. **골든을 갱신해 맞추지 않는다.**
- **공용화가 회차를 삼키면** — 사전부검이 *"「표만 갈라도 된다」는 추정이고 실제로 안 해
  봤다"* 로 미리 적었다. 뼈대 공유가 노드 종류 표를 넘어 규칙까지 갈라야 하는 것으로
  드러나면, **그 사실과 갈리는 자리의 목록을 산출하고 승격**한다. 조용히 새 파일로
  돌아가지 않는다 — 그것이 소유자 답을 뒤집는 것이다.

## 범위 밖

- **파일 경계를 넘는 참조 해소** — 순서표 §2 의 2 번. `RefResolution::OutsideFile` 은 세기만 한다
- **Kotlin 추출기** — [#131]. 다만 공용화한 뼈대는 Kotlin 이 받을 수 있는 모양이어야 한다
- **[#78] 의 컨테이너 축** — *"`impl` 컨테이너가 트레잇을 못 담고, 대상 타입이 다른 파일이면
  아예 못 붙는다"*. ⚠ **`impl` 의 스코프 소유는 이 회차가 진다**(`A2`) — 두 축이 다르고,
  앞 판이 그 둘을 한 이름으로 묶어 놓아 조건이 서로 반대인 두 구현을 다 통과시켰다
- **L2 등급 승격과 재결박** — `D1` 이 이슈로 세운다
- **엣지 정확도의 전수 측정** — 표본 30 건(`E1`)까지만 잰다. 전수는 효과 확인 뒤다
- **`ImportSet`·`ExportSet` 의 소비자를 만드는 것** — 지금 `imports` 는 소비자가 0 이고
  `export_digest` 는 실어 나르기만 한다. 이 회차는 **산출까지**이고 쓰는 것은 F07 이다
- **1층 캐시 부피와 추출 시간의 상한** — `LocalRef` 가 늘어 캐시가 커지는 것은 안 잰다.
  ⚠ **수용하는 이유**: 상한 장치가 지금 없고(`budget.rs` 에 항목 크기 축이 없다) 그것을
  만드는 것은 이 회차가 안 만들기로 한 장치다(§11 ③ (가))
