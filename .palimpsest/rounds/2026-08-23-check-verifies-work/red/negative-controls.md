# 음성 대조 — 실제로 걸고 관측한 것

> `F2`(전부 걸었다)·`F3`(걸었고 빨개졌다)의 증거. **격리 사본에서 건다.**
>
> ⚠ **사본은 `git clone` 이어야 한다.** 파일 복사본에는 이력이 없어 A 축이
> 아무것도 못 잰다 — 그 사실 자체를 이 자리에서 잡았고 `안 보임 → 실패` 로 고쳤다.
>
> ⚠⚠ **그리고 `--root` 없이는 이 전부가 헛것이다.** 프리빌트 `xtask` 는 뿌리가
> 컴파일 시점에 박혀 **사본으로 `cd` 해도 원본을 잰다.**
>
> 잰 커밋: `84bc53d`

## 기준선 — 사본이 원본과 같은 답을 낸다
```text
검사 23/23 통과
```

## N1 — 실재하지 않는 SHA 를 `닫은커밋` 에 넣는다 (A1 짝)
```text
  FAIL  발견이 닫혔나
발견이 닫혔나: .palimpsest/rounds/2026-08-23-check-verifies-work/findings.jsonl:2: `PM1-01` 의 `닫은커밋` `deadbee` 가 **이 이력에서 안 보인다** — 없는 커밋이거나, 얕은 클론·squash 병합으로 이력 밖이다. CI 라면 체크아웃 깊이를 보라
```

## N2 — 그 처분이 요구하는 자리를 안 만진 커밋으로 바꾼다 (A2 짝)
```text
  FAIL  발견이 닫혔나
발견이 닫혔나: .palimpsest/rounds/2026-08-23-check-verifies-work/findings.jsonl:2: `PM1-01` 가 `b9fbef7` 로 닫혔다는데 그 커밋이 `.palimpsest/rounds/2026-08-23-check-verifies-work/intent.md` 를 안 만졌다
```

## N2-b — 끝난 회차에 열림 행을 만든다 (「열림으로 밀기」 도피로)
```text
  FAIL  발견이 닫혔나
발견이 닫혔나: .palimpsest/rounds/2026-08-23-agent-laziness-behavior/findings.jsonl:3: `PM1-02` 가 **열림**인데 그 회차는 끝났다(`report.md` 가 있다) — 끝난 회차에 열린 발견이 있으면 **그 회차가 안 끝난 것**이다. 「열림으로 밀기」로 이 검사를 비껴가지 않는다
```

## N6 — 새 회차를 「형식 이전」 선언 목록에 넣는다 (C3·C5 짝)
```text
  FAIL  선언 목록이 닫혀 있나
선언 목록이 닫혀 있나: `형식 이전` 목록의 `2026-08-23-check-verifies-work` 이 하한 `2026-08-19` 이후다 — **이 목록은 닫혀 있다.** 새 회차는 못 들어간다
```

## N6-b — 선언 목록에 실재하지 않는 회차를 넣는다
```text
  FAIL  선언 목록이 닫혀 있나
선언 목록이 닫혀 있나: `형식 이전` 목록의 `2026-01-01-없는회차` 은 실재하는 회차가 아니다
```
