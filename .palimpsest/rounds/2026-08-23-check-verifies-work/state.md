## 실패한 접근

- **「끝난 회차 = 모집단」을 그대로 걸기.** `report.md` 가 일곱 중 여섯에 있어서(RED-7)
  옛 게이트 둘이 통째로 실패한다. → 닫힌 예외 선언으로 우회했다 (`C2`).
- **레코드 `요약` ↔ 원 반환문의 문자열 대조.** 직접 쟀다 — 929 쌍 중 순서 337 ·
  집합 325 만 맞는다. 요약은 전사자가 **다시 쓴 것**이라 원문의 복사가 아니다.
  → **결박 필드**(스키마 4)로 갈아탔다 (`B1`). 옛 회차는 「형식 이전」 (`B3`).
- **`A2` 를 「경로 접촉」으로 재기.** `닫은커밋` 은 규약상 **처분 커밋**이라
  v3 회차의 닫힘 행 전부 중 120 이 빨개지고 사전부검 계열은 참인 답이 원리상 없다.
  → 「**처분이 요구하는 자리** 접촉」으로 고쳤다.
- **음성 대조를 별개 절에 두기.** 조건 파서가 `## 완수 조건` 만 읽어
  「원장 둘 대조가 댄다」가 거짓이었다. → `N1`~`N10` 을 상자로 올렸다.
- ★★ **결박 + 스키마 4.** 사전부검 R2 가 **더 작은 표면**을 실측으로 찾았다 —
  `extract.py` · `extract-review.py` + 예외표가 **이미 있고** 쓴 회차는 하나뿐이다.
  → **기계 추출을 규약으로 승격**한다. R2 의 시나리오 넷이 동시에 사라졌다.
- ★★ **격리 사본에서 프리빌트 `xtask` 돌리기.** `repo_root()` 가 컴파일 시점에
  박혀 **사본이 원본을 잰다**(실측: 사본 파괴 후에도 21/21). → `A9`(뿌리를 인자로)를
  **먼저** 세우고 나서 음성 대조를 건다.
- **「레코드를 정정한다」로 발화 행을 처리하기.** 증거 요구가 없어 「그 경로를 만진
  커밋 아무거나 넣기」가 절차가 된다. → 일반 처분 경로 + 못 대면 `대조불가`.
- ★★★ **`extract.py` 를 그대로 승격하기.** R3 이 실제로 돌렸다 — **기각 5 행이
  사라지고 유효성이 17/17 전부 `참`** 이 된다(옛 반환 형식용이라 `대상` 에서 파생한다).
  → **새로 쓴다.** 지금 형식은 그 칸들을 직접 적으므로 **읽으면 된다.**
- ★★★ **`cargo xtask check --root <사본>` 을 그냥 주기.** 지금은 **조용히 무시되어
  에러 없이 원본을 잰다.** → `A9` 는 「모르는 인자를 **거부**한다」까지다.
- **「다시 연다」로 발화 행 닫기.** `상태=열림` 이면 `A2` 모집단에서 빠져 **즉시 초록**이다.
  → `A6` 이 닫힘→열림 전환 수와 끝난 회차의 열림 행 수를 판정문에 싣는다.
