# 효과 관측 — 빚 유예 없는 판정 출력

2026-08-31, 저장소 루트에서 시험 명령이 아닌 실제 판정기 `cargo xtask check`를 실행했다.

```text
회차 레코드 — 손으로 채운 칸: 진행 중 0 · 끝난 회차 0 [갈린 칸 0 · 빠진 행 0]
원장 둘 대조 — 검산 줄 유예 발화 0 · 보고 없음 유예 발화 0
발견이 닫혔나 — 잰 것 529행 · 발화 0 · 감사 대기 발화 0 · 이 이력에서 안 보임 0행
선언 목록 — A 축 감사 대기 0개 · 종료 보고 검산 줄 유예 0개 · 종료 보고 없음 유예 0개
검사 23/23 통과
```

착수 때 같은 명령은 끝난 회차 손 전사 2530칸(`갈린 칸 1934`·`빠진 행 596`),
감사 대기 41행, 검산 줄 유예 2회차, 보고 없음 유예 1회차를 냈다. 출력이 단순히
사라진 것이 아니라, 복제본 음성 대조에서 다섯 결함이 각각 다시 드러나는 것도
[`red/negative-controls.md`](../red/negative-controls.md)로 확인했다.
