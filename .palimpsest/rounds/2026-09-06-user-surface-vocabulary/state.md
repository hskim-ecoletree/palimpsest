## 합(合)이 확정한 것

**A1** — `Live` → **`Fresh`**. 나머지 셋 유지. 갈림의 근거는 원문 한 문장이다 —
`live` 는 뜻이 약할 뿐 아니라 **다른 뜻(on-air)으로 읽힌다.** 잘못 읽히는 낱말은 병기로
안 고쳐진다. `undeterminable` 은 낯설 뿐 틀리게 읽히지 않아 병기로 닫힌다.

**A3** — 괄호 안 소문자 · 좁은 자리는 고정폭 열 안이 아니라 **줄 끝에 병기**
(`{:<N}` 은 char 수로 채우고 `unicode-width` 의존이 저장소에 0건이다) ·
영어권 생략은 **ADR 에 규칙만 적고 구현하지 않는다**(CLI 표면이 지금 전부 한국어다).

**D3** — 셋으로 가른다. 회차 절차는 `folded` 영어 정본 + 병기 · CLI `Fold` 는
**「이관(fold)」** · CLI `Elision` 은 **「생략(elision)」**.
⚠ `pal-core/src/envelope.rs:239` 가 *"부피를 옮긴 것. 절단이 아니다"* 로 못 박았고
`[f06].fold_is_not_elision` 이 시험으로 잠갔다.

**D1 의 남은 넷** — 원문 12행이 축을 정한다.
`처분`·`오라클` 은 **코드성**(영어 원 표기 정본 + 병기), `퇴로`·`막힘` 은 **산문**(사용자 언어).
⚠ 「차단」은 쓰지 마라 — `pal` 훅의 `{"decision":"block"}` 이 이미 「차단」이고
`pal-core/src/budget.rs:188` 의 「연속 차단 상한」도 별개다.
⚠ 「우회로」도 쓰지 마라 — `SKILL.md:175` 가 승격을 이미 그렇게 부른다.

**G1** — 대상 **969곳** 아홉 뿌리 · 대상 밖 1893곳 · **미분류 0**.
1순위는 설치 페이로드(`.py` 둘 포함), 2순위는 실행 문자열, doc 주석은 **7순위**다.
지난 17회차 종결 기록과 이번 회차의 이미 쓴 진행 기록은 **영구 범위 밖**이고 새 이슈도 안 만든다.
**다만 이 회차의 종결 문서부터는 교정 표기로 쓴다.**
