## 실패한 접근 — 다음 컨텍스트가 같은 벽에 안 부딪히도록

| 무엇 | 왜 실패했나 |
|---|---|
| **「`KO-SENTENCE-REGISTER.md` 를 그 저장소에 커밋 안 했다」고 적어 둔 것** | 낡았다. 커밋 `e7b3684` 로 커밋됐고 push 까지 됐다. **토론 설계자가 초안을 안 받는 자리에서 그 전제를 잡았다** |
| **새로 만든 에이전트 정의를 같은 세션에서 `Agent` 로 부르려던 것** | 레지스트리는 **세션 시작에** 읽힌다. 그 뒤에 만든 정의는 안 들어온다. 일반 서브에이전트에게 정의 파일을 전문 읽히고 그대로 행동하게 하면 격리는 유지된다 |
| **`센다` 를 일괄로 `잰다` 로 바꾼 것** | 두 뜻이다 — 판정(잰다)과 개수(헤아린다). 한쪽으로 몰면 「깨진 것을 잰다」가 된다 |
| **`봉투` 를 일괄로 `응답 묶음` 으로 바꾼 것** | 조사가 갈린다(`봉투는`→`응답 묶음은`) 그리고 **Rust 식별자에 공백이 들어가 컴파일이 깨진다** |
| **`G1` 이 등록한 사전형 정규식을 그대로 검사로 옮기려던 것** | 사전형(`켜다`·`접는다`)은 이 저장소에 0 건이다. 활용형으로 재야 하고, 경계가 없으면 `지켜진`·`보낸다` 가 위반으로 세어져 합격선이 원리상 0 에 못 닿는다 |
| **검출 수단을 경로로 자기 제외 하려던 것** | `xtask` 전체가 빠지고 이 회차가 고친 `xtask` 100 곳을 아무도 안 잰다. **파일 안의 표지로 갈라야 한다** |
| **감사자 반환문의 기각 절을 최상위 불릿으로 받은 것** | 추출기는 `### ` 항만 읽고 합계 검산은 불릿도 센다 — 「원문 14 ↔ 레코드 21」이 난다 |
| **`pal bind` 뒤에 커밋하면 결박이 남는 줄 안 것** | `intent.redb` 는 `.gitignore` 에 있다. `pal intent export --out .palimpsest/intent/bindings.jsonl` 을 돌려야 정본이 갱신된다 |
| **활용형 목록을 사전형 하나로 잠근 것** | 「낸다」만 재면 `냈다`·`내는`·`낼`·`낸` 이 검사 밖이다. 같은 동사가 **390곳** 남았는데 검사는 「0곳」을 냈다 — **낡은 검사는 통과한다** |
| **그 반동으로 활용형을 한 번에 다 넣은 것** | 763곳이 나왔고 표본을 읽으니 `살아남은`·`서 있다`·`셌다` 는 **일반 한국어**였다. 일반 한국어를 위반으로 세면 합격선이 원리상 0 에 못 닿는다 |
| **낱말 일괄 교체를 게이트에도 그대로 돌린 것** | 게이트의 **인용 블록 안 실행 출력**까지 고쳐서, 찍힌 적 없는 화면이 증거로 실렸다. 종결 문서는 위반 낱말을 **인용해야** 하므로 줄 단위 표지가 필요하다 |
| **`H1` 의 인용과 링크한 전문이 다른 실행이던 것** | 스냅샷 SHA 가 커밋마다 움직인다. 판정 커밋에서 다시 돌려 **같은 실행의 바이트**를 양쪽에 넣어야 한다 |
| **독립 리뷰가 도는 동안 잠긴 의도와 게이트를 고친 것** | R5 가 도는 동안 HEAD 가 여덟 번 움직였고 `intent.md` 두 번·게이트 세 번이 바뀌었다. 리뷰어의 발견 둘이 그 때문에 기각으로 뒤집혔다 — **운이 좋았던 것이지 구조가 막은 것이 아니다.** 리뷰가 무엇을 잰 것인지 사후에 대조할 수 없다 |
| **검출 수단이 증거를 고치라고 요구한 것** | 게이트가 인용한 `pal touch` 화면에 위반 낱말이 있어서, 초록으로 만들려고 **인용 블록 안에 표지를 끼워 넣었다.** 수단이 증거를 고치게 만들면 그 수단이 틀린 것이다 — 펜스 안을 빼야 한다 |
| **게이트가 판정을 사실보다 먼저 쓴 것** | `H2`(CI 런) · `H3`(이슈) · `B4`(rc) · `D2`(수) 넷이 그 갈래였고 독립 리뷰 셋이 각각 잡았다. **판정이 원장에 잠기면 아무도 다시 안 잰다** |
