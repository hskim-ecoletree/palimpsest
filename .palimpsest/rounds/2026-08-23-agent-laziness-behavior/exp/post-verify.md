# 사후 검증 — 닫힌 게이트가 실제로 서 있나

> 2026-08-23 · 회차가 **닫히고 push 된 뒤** 소유자가 요구했다 —
> *"깨끗한 세션에서 재검으로 해결되었는지부터 보고 싶다."*
> `gate-verifier` 가 **대화 기록도 회차의 서사도 안 받고** 돌았다.

## 선 것 — 돌려서 확인됐다

| | 무엇으로 |
|---|---|
| **합격선이 측정보다 앞서고 그 뒤 불변** | `rules.log` 가 **첫 사전 등록 커밋**에 들어갔고 `git diff <그 커밋>..HEAD -- exp/prereg/` 의 변경 목록에 **없다.** 첫 원자료 커밋은 그 뒤다 — **잰 결과를 하한으로 되받은 자리가 없다** |
| **레코드가 원 반환문과 안 갈렸다** | 열한 라운드를 `모집단·유효성·해악도` 세 칸으로 **행 순서까지** 대조 — 어긋남 **0**. **기각 행이 원문과 레코드에서 같다**(라운드별로도) |
| **채점표가 재현된다** | 보존 스냅숏으로 `O1` 재계산 — 게이트의 표와 소수점까지 같다 |
| **`A6` 반증이 실물** | 빈 디렉터리와 깨끗한 산출이 **같은 문장·같은 `rc=0`**, 없는 경로만 `rc=2` |
| **`D4`·`D6`·`D7`·`D10`·`D1`** | `report.md` 의 §10 네 이름 각 0 건 · `git ls-tree HEAD` 에 착수 재료 없음 · `SKILL.md` 증가분 실재 · 코드 변경 빈 출력 · `## 효과` 가 `scoretable.log` 와 동일 |

★ **회차가 스스로 적은 「레코드에서 세 번 조용히 떨어뜨렸다」는 지금 재현되지 않는다** —
고친 것이 실제로 고쳐졌다.

## 어긋난 것 — 일곱. 전부 고쳤다

| | 무엇 | 처분 |
|---|---|---|
| ⒜ | ★ **종료 보고의 검산이 게이트와 달랐다 — 같은 커밋에서.** 그리고 *"둘이 「원장 둘 대조」로 맞춰져 있다"* 라 적었는데 **`report.md` 는 어느 검사의 모집단에도 없다** | **수를 뺐다.** 세는 자리를 가리키고 **`report.md` 가 검사 밖이라는 사실을 적었다** |
| ⒝ | 게이트 헤딩 둘이 판정표와 갈렸다 — `B6` 이 통과인데 헤딩은 「반증」, 대조불가가 하나인데 헤딩은 「하나」와 「둘째」 | **헤딩을 고쳤다** |
| ⒞ | 할인이 「일곱」인데 여덟을 열거한다. **그 발견(`IR8-6`)이 「닫힘」인데 안 고쳐졌다** | **머릿수를 뺐다** |
| ⒟ | ★★ **거짓 닫힘.** `IR1-08`·`IR1-11` 이 한 커밋으로 닫혀 있는데 **그 커밋에 고침이 없다.** 실제 수정은 각각 R7·R2 에서 났고 그 사이 셋이 같은 걸 다시 냈다 | **`닫은커밋` 을 실제 고침 커밋으로 고쳤다** |
| ⒠ | `C7` 반증의 **등록된 처분**(*"그 세 축을 방향 주장의 근거로 쓰지 않는다"*)이 판정문에 없는데 **③ 논증이 `O5ⓐ` 위에 선다** | **적었다.** ★ 그리고 **논증은 그래도 선다** — `P` 의 `O5ⓐ` 가 두 채점자 모두에서 두 과제 모두 만점이라 **방향이 아니라 천장**이다 |
| ⒡ | 음성 대조 「넷/여덟」 산술이 안 맞고, 안 건 것 중 **둘은 실제로 걸렸다**(`A8`·`D8`) | **머릿수를 뺐다.** 남는 주장만 적었다 |
| ⒢ | `state.md` 가 *"남은 것은 `push`"* 로 낡았다 | **갱신** |

## ★★ ⒟ 가 가리키는 것

**레코드가 「닫힘」이라 적고, 고침은 없었고, 검사는 초록이었다.**

`xtask` 의 합계 검산은 **행 수만** 센다 — `닫은커밋` 이 **실제로 그것을 고친 커밋인지**
아무도 안 본다. 그래서 같은 병이 **네 번 다시 발견됐고**, 매번 「닫힘」으로 적혔다.

⚠ **이것이 [#92](https://github.com/hskim-ecoletree/palimpsest/issues/92) 가 진 자리이고,
이 회차가 그것을 실물로 보였다.** 다음 회차의 착수 재료다.

## 아직 아무도 안 돌려 본 자리 — 셋

1. ★ **`B7` 은 모집단 0 으로 통과했다.** 여섯 세션의 무효화가 전부 0 이라
   **「갈린다」 갈래가 한 번도 안 채워졌다.** 독립 리뷰 여덟 라운드가 전부 `통과`로 적었고
   **「모집단 0」이라 적은 곳이 없다.**
2. ★ **`report.md` 를 대조하는 기계가 없다.**
   「원장 둘 대조」는 `intent.md` ↔ 게이트만 본다.
   **초록은 「어긋남 0」이 아니라 「검사 모집단 안에서 어긋남 0」이다.**
3. **`O4ⓐ`·`O5ⓐ` 의 음성 대조** — 「원리상 못 건다」로 적었고 **대체 계기를 아무도 시도 안 했다.**
   **합격선 ③ 이 필수로 요구한 축**이 그 자리다.
