# 배선 탐침 — 서브에이전트가 실제로 무엇을 물려받나

> 2026-08-23 · **메인의 실측**이다 (에이전트 반환문이 아니라 관측 — §7 검산 면제 대상)
> 사전부검 R1 계열 ⑤(격리)가 낸 시나리오를 **추정으로 두지 않고 쟀다.**

값싼 모델 서브에이전트 하나를 띄워 넷을 재게 했다. 파일을 읽어 답하지 말고
**자기가 받은 것만** 답하라고 지시했다.

## 잰 것

| # | 물음 | 답 |
|---|---|---|
| 1 | 프로젝트 지시가 주입되나 | **부분.** `CLAUDE.md`(= *"에이전트 지시는 AGENTS.md 에 있다"*)는 주입된다. **`AGENTS.md` 본문은 안 온다.** 「사관·사서·큐레이터」·「「나중에」가 0」은 **없었다** |
| 2 | **사용자 메모리**가 주입되나 | **온다.** *"일 시작은 `/round`"* 를 메모리에서 이미 알고 있었다 |
| 3 | Bash cwd 가 호출 사이에 유지되나 | **리셋된다.** `cd /tmp` 뒤 다음 호출이 저장소 경로로 돌아왔다 |
| 4 | 저장소 밖을 읽고 쓸 수 있나 | **된다.** `/tmp` 아래 생성·기록·판독 성공 |
| 5 | `round` 스킬이 보이나 | **보인다.** `pal-independent-reviewer`·`pal-premortem-sweeper`·`gate-verifier`·`baseline-runner` 도 보인다 |

## 이것이 계획에 대해 뜻하는 것

**격리가 이름뿐이었다.** 실험 대상 에이전트는

- 저장소를 읽을 수 있고 (**정답표 노출 위험** — 금지역),
- `/round` 스킬을 **전문으로 부를 수 있고** (세 팔의 브리핑 차이가 지워진다 — **배선 교란**),
- 소유자 메모리에서 *"일 시작은 `/round`"* 를 이미 받고 있으며,
- `cd` 로 워킹디렉터리를 고정할 수 없다 (**절대경로만이 유일한 길**).

계획의 *"격리 워킹디렉터리"* 는 **디렉터리를 나눈 것이지 격리한 것이 아니다.**

## 재현

```bash
# 값싼 모델 서브에이전트에게 이 넷을 시킨다
#  ① 받은 지시에 무엇이 있었나 (파일 읽지 말고)
#  ② Bash 세 번: pwd / cd /tmp && pwd / pwd
#  ③ mkdir -p /tmp/pal-probe-x && echo hi > /tmp/pal-probe-x/a.txt && cat …
#  ④ 보이는 스킬 목록에 round 가 있나
```
