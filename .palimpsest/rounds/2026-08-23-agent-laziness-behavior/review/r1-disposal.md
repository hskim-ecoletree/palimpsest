# 독립 리뷰 R1 — 처분표

> 원 반환문: [`r1-raw.md`](r1-raw.md) · **남기지 않는다.**

**리뷰어가 발견 스물하나를 냈고 그중 다섯을 스스로 기각했다**(유효성 `거짓`) —
sunset 트리거 의심 · 게이트 제목의 낱말 · `C5` 낱말 수 · `O2=0` 이 죽은 가지라는 의심 ·
`O1` 재현 불가 의심. 넷을 **실제로 돌려 보고 접었다.**

## 무엇을 했나

| 무엇 | 처분 |
|---|---|
| **`D4`·`D6`·`D7`·`D8` 을 통과로 적었는데 넷 다 안 했다** (금지역) | **정정.** `D7` 은 **지금 지웠다** · `D6` 은 **대조 불가**(원리상) · `D4`·`D8` 은 **미측정**(종료 보고가 있어야 참이 된다) |
| **`A2` 는 미측정이 아니라 잔여다** | **정정.** 돌렸다 — **다섯 축 전부 발화**. ⚠ 사후에 돌린 것이라 그 사실을 게이트에 적었다 |
| **게이트 산문의 수 둘이 틀렸다** (거짓신호) | **정정.** 「서른여섯 중 스물넷」은 실측 **스물둘**이고 게이트가 **자기 안에서 어긋났다**. 수를 지우고 원자료를 가리킨다 |
| **「네 라운드 연속 수정 사항 없음」이 과장이다** | **정정.** 그 문구는 한 라운드뿐이다. `tbl.py` 가 r4·r5·r6 **같은 해시**라는 더 강한 사실로 바꿨다 |
| ★ **진행 원장이 승격 없이 사라졌다** (원의도) | **정정.** 게이트 `## 범위 밖` 에 **축소였음을 명시**했다. 확장자만 바꾸면 살릴 수 있었으므로 경계가 아니다 |
| **전사·파생물이 `exp/` 에 없어 `C7`·`C9`·`O4ⓐ`·`O5` 가 재현 불가** | **정정.** 여섯 세션 전사 서른여섯(7.1MB)과 눈가림 파생물 스물넷을 **보존했다**(`.jsonl` → `.log`) |
| 나머지 정정 열 | 게이트·의도의 문면을 고쳤다 |
| 리뷰어가 스스로 기각한 다섯 | **기각.** 레코드에 유효성 `거짓` 으로 싣는다 |

## 이 라운드가 잡은 것 중 가장 아픈 것

**「상자를 켜 놓고 안 한 것」이 넷이었다.** 이 저장소가 가장 오래 싸운 병이고
이번엔 **내가** 저질렀다 — 그것도 **그 병을 재려고 연 회차에서.**

리뷰어는 `git ls-tree HEAD` 로 착수 재료가 그대로 있는 것을, `bindings.jsonl` 의
마지막 두 행이 **앞 회차 것**인 것을, `report.md` 가 **없는** 것을 각각 돌려서 봤다.
**산문을 안 믿고 명령을 돌린 것이 이 라운드의 값이다.**
