# 독립 리뷰 R2 — 처분표

> 원 반환문: [`r2-raw.md`](r2-raw.md) · **남기지 않는다.**

리뷰어가 스물을 냈고 **여섯을 스스로 기각했다** — `O2=0` 의 모집단 의혹(넓혀도 0) ·
완료선언 탐지기의 항등식 의혹 · `A12` 오라클 결함 의혹 · 추가 격리 누출 ·
눈가림 우연 수준 시비 · `A10` 범위 구멍. **전부 돌려 보고 접었다.**

★ **먼저 적을 것: 채점이 재현됐다.** 리뷰어가 보존된 스냅숏 서른여섯에
사전 등록된 오라클을 다시 걸어 `O1` 을 통째로 다시 냈고 **36/36 이 소수점까지 일치**했다.
`O3`·`O4ⓑ`·비용·`A4` 문자 동일성·`A10` 빈 diff·격리 탐지기 0 건도 전부 다시 섰다.
**원자료 보존과 사전 등록 불변은 이 회차가 잘한 자리다.**

## 처분 — 금지역 셋

| 무엇 | 처분 |
|---|---|
| ★ **`s3` 의 전사↔라운드 짝짓기가 한 칸 밀렸다.** 등록된 규칙의 「첫 `user` 항」 절반이 **실제로는 안 돌았다** | **정정 · `B6` → 반증.** 첫 프롬프트의 내용으로 라운드를 직접 정해 **여섯 세션을 다시 붙였고** 검산이 여섯 다 선다. ⚠ **고치는 첫 시도가 여섯을 전부 더 밀었다** — 「추가 요구 표식이 단조 증가한다」고 잘못 가정했다. 두 번째에 맞췄다 |
| ★ **`A2` 의 「다섯 축이 전부 발화한다」가 안 선다.** 「O5 흠집」 행이 잰 것은 `O1` 이고, `R2-c` 가 `O5ⓐ` 의 계기를 눈가림 채점으로 옮겼으므로 **은퇴한 계기**를 시험했다. `O4ⓐ` 에는 흠집이 **아예 안 걸렸다** | **정정 · `A2` → 반증.** `O4ⓐ`·`O5ⓐ` 는 계기가 **사람의 판단**이라 「흠집 낸 참조 구현」으로 기계적으로 못 울린다 — **조건이 요구하는 것이 그 둘에 대해 원리상 안 선다.** ★ **합격선 ③ 이 `O5` 를 필수로 만들었는데 그 축의 음성 대조가 비어 있다** |
| ★ **게이트가 자기 안에서 어긋난다** — 음성 대조 표는 *"오라클 안 돌렸다"* 인데 본문은 *"돌렸다"* 이고 판정 표는 통과다 | **정정.** 표를 실제 결과로 고쳤다 — **넷을 걸었고 셋이 반쪽이거나 울었다** |

## 처분 — 나머지

| 무엇 | 처분 |
|---|---|
| **`A6` 의 「거짓 인자」가 정상 실행과 구별이 안 된다** — 빈 디렉터리와 깨끗한 산출이 같은 문장·같은 `rc=0` | **정정 · `A6` → 반증.** 잡히는 것은 **없는 경로**(`rc=2`)뿐이다 |
| ★ **축별 판정이 등록된 3×3 격자를 한 번도 안 썼다** — ⓐ·ⓑ 를 갈라 일곱 행을 냈는데 등록된 축은 다섯이다 | **정정.** 격자로 다시 냈다. `P+문면`/과제 B 의 `O4` 가 `R3-e` 가 일부러 채운 「ⓐ 개선 + ⓑ 동점 = 개선」 칸에 떨어진다. **판정 결론은 안 바뀐다** |
| ★★ **판정문에 「③ 이 `P` 의 천장 때문에 원리상 통과 불가였다」가 없다** | **정정.** 게이트에 절을 세웠다 — `P` 가 `O5` 에서 두 과제 다 천장이고 `O1` 은 과제 B 에서 천장이므로 **③ 은 측정 전에 이미 못 넘는 선이었다.** **처치에 대한 판정이 아니라 설계에 대한 판정이다** |
| `O4ⓑ` 가 바이트 동일 라운드를 분모 확대 때문에 「진전」으로 센다 | **범위밖.** 등록된 정의대로 잰 것이고 측정 뒤에 안 바꾼다. 사실을 종료 보고에 적는다 |
| 눈가림 파생물이 어긋난 순서를 실었다 | **정정.** 전사를 고쳤다. `O4ⓐ` 는 합집합이라 **수는 안 변한다** |
| `state.md` 가 사전 등록 이전에 멈춰 있다 · `승격 3·4` 가 `## 승격` 밖에 있다 | **정정** |
| 리뷰어가 스스로 기각한 여섯 | **기각.** 레코드에 유효성 `거짓` 으로 싣는다 |
