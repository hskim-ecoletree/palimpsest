## 검사 상태 — 이 파일이 낸 것

`cargo xtask check` 를 이 파일을 쓴 뒤에 돌렸다. **빨간 것은 하나이고 예정된 것이다:**

```
회차 레코드: 합계 검산 어긋남 — .../review/r6-raw.md:
원 반환문의 항이 21 인데 ... `출처=독립리뷰` · `라운드=6` 레코드는 0 행이다
```

**레코드 21 행을 같은 커밋에 실으면 21↔21 로 선다.** 나머지 20 개 검사는 초록이고,
`죽은 링크 부재`(문서 269 · 링크 473 · 죽은 것 0)와
`사라진 문서를 현재형으로 안 부른다` 도 이 파일 때문에 안 울었다.
