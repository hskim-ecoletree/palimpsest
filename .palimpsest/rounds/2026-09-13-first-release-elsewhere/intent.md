### 계획의 세부 — 사전부검 R1 이 고친 것 ⟨2026-09-13⟩

- **㈀ 해소 규칙은 TypeScript 자신의 순서를 따른다** ⟨R1 ⑧⑨⟩. 한 층에 넣어 모호로 잃지도, 임의 순서로 틀린 파일을 잡지도 않는다.
  확장자 없음 → `.ts` → `.tsx` → `.d.ts` → 디렉터리 `index.ts`·`index.tsx`·`index.d.ts` · `.js`/`.jsx`/`.mjs`/`.cjs` → 대응 `.ts` 계열 · 명시 `.ts`.
  **옳은지는 우리 규칙이 아니라 TypeScript 컴파일러(`ts.resolveModuleName`)가 판정한다** — ditto 원본의 `node_modules/typescript`(5.9.3)를 읽기로 쓴다.
- **㈀ tsconfig 는 스냅샷 트리에서 읽는다**(워킹트리 아님 · `--at` 과 같은 답) ⟨R1 ⑦⟩. 파일마다 **가장 가까운 조상** `tsconfig.json` · 주석과 꼬리 쉼표(JSONC) ·
  **저장소 안 상대 경로 `extends` 사슬** · `baseUrl` 없는 `paths`. 패키지 `extends`(`@tsconfig/…`)는 따라가지 않고, 그 파일의 별칭 임포트는 **「tsconfig 를 다 못 읽었다」는 까닭**으로 적는다 — `outside_repo` 로 적지 않는다.
- **㈀ 대상 파일 목록은 「심볼이 있는 파일」이 아니라 대장이 파싱한 파일 전부다** ⟨R1 ④⟩. 심볼 0 인 재수출 배럴로 펴지면 **「재수출을 지나는 이름 — 따라가지 않습니다」**
  까닭으로 적는다. `outside_repo`·`no_target_file` 로 떨어뜨리지 않는다.
- **㈀ 화면의 「못 선 몫이 가는 문」 문구는 언어 중립이다** ⟨R1 ④⑤⟩ — `std::*`·크레이트 뿌리 같은 Rust 의 뜻을 TS 화면에 싣지 않는다.
- **㈀ 파일 최상위 참조는 호출자에 안 든다는 사실을 화면이 말한다** ⟨R1 ③⟩ — 지금 단서는 `x.foo()` 만 적는다. 최상위 참조를 세는 일은 하지 않는다(심볼이 없어 엣지의 출발점이 없다).
- **㈁ 후보 목록은 `pal narrative` 가 계산한 것을 파생층에 남기고 `touch` 가 읽는다.** 그 목록이 **없으면「없음」이 아니라「아직 안 만들었다 — `pal narrative` 를 먼저 돌리십시오」**,
  **다른 스냅샷의 것이면 그 사실**을 찍는다 ⟨R1 ②⟩. 후보마다 **그 조각이 가리키는 후보 곳 수**를 함께 싣는다(`path` 같은 흔한 이름에 넓게 퍼진 조각이 21%다) ⟨R1 ⑩⟩.
- **㈂ 지목 인자는 `touch` 와 `pal query` 에 같이 선다** ⟨R1 ⑪⟩ — 같은 문구가 두 자리에 있다.
- **㈃ 는 지우는 것이 아니라 뜻을 사용자 말로 옮기는 것이다** ⟨R1 ⑤⟩. 「안 하기로 정한 자리」와 「원리상 못 하는 자리」의 구별은 화면에 남고,
  그 구별을 재는 시험 단언은 **옮기지 지우지 않는다.** 모집단은 장면 네 명령의 **정상 화면 · `--help` · 거부·오류 화면(표준오류)** 이다 ⟨R1 ⑥⟩.
- **㈀ 맨 지정자(패키지 이름)는 `outside_repo` 로 적지 않는다** ⟨R2 11⟩ — `node:` 만 저장소 밖이 확실하다. 그 밖의 맨 지정자는 워크스페이스 패키지일 수 있으므로
  **「패키지 이름 — 설치된 패키지인지 워크스페이스인지 가리지 않았다」** 까닭으로 따로 적는다. 워크스페이스를 따라가 푸는 것은 하지 않는다.
- **㈀ `moduleResolution` 을 읽는다** ⟨CA1-06⟩ — `bundler`·`node10` 은 확장자 없는 지정자와 디렉터리 `index` 를 풀고, `node16`·`nodenext` 는 TypeScript 가 푸는 꼴(명시 확장자 · `.js` 대응)만 푼다.
- **㈀ tsconfig 는 답이 선 트리에서 읽는다** ⟨R2 12⟩ — 기본(워킹트리)이면 커밋 안 된 tsconfig 편집까지, `--at <rev>` 면 그 커밋의 것. **상속된 `paths` 는 그것을 정의한 설정 파일의 자리를 기준으로 푼다**(TypeScript 규칙) ⟨R2 6⟩.
- **㈁ 대기 구역은 인입 분류 `candidates` 와 `bound` 를 둘 다 싣는다** ⟨R2 3⟩ — 「결박됨 137」도 승인 전에는 의도 저장소의 결박이 아니다.
  **읽을 때 의도 저장소의 결박·거부로 거른다** ⟨R2 4⟩ — 승인·거부한 조각은 대기에서 빠진다. 목록은 **2층 세대 교체가 지우지 않는 자리**에 둔다 ⟨R2 5⟩.
- **㈂ 지목 표기는 `narrative --pick` 과 같다** ⟨R2 13⟩ — 후보 화면이 짧은 해시를 찍고, 그 문자열이 `touch`·`query` 의 지목과 `narrative --pick` 에 **그대로** 통한다.
- **㈃ 는 실행한 화면 출력을 잰다 — 소스 문자열을 훑지 않는다** ⟨R2 8⟩. 모집단에 **최상위 `pal --help`** 가 든다 ⟨R2 7⟩.
- **㈀㈁㈂㈃ 은 파일 단위로 독립이 아니다** ⟨R2 10⟩ — `touch.rs` 의 이관표·후보 화면과 그 시험 단언을 여럿이 고친다. **한 손이 순서대로 한다**: ㈀ → ㈃ → ㈁ → ㈂. 병렬 하위 작업으로 나누지 않는다.
- **㈄ 에서 부를 심볼은 봉인 전에 규칙으로 정한다** ⟨R2 1⟩ — **과제가 지우는 파일에서 `pal symbols` 가 내는 선언 전부(메서드 포함)**를 부른다 ⟨CA2-03⟩. 고른 이름을 봉인에 적는다. 특정 심볼만 골라 부르지 않는다.
- **「호출자」는 하한이다** ⟨R2 2⟩ — 파일 최상위 참조와 문자열 레지스트리 조회는 안 든다. 장면 조건의 「실제 수」는 **「파일 경계를 넘은 하한」**으로 읽고, 화면이 그 사실을 말한다. 실제 파손 자리와의 대조는 `E3` 가 진다.
- **㈄ 는 결박도 인입도 없는 새 복제본에서 한다** ⟨R1 ①⟩. `pal install` → `pal narrative` → `touch` → **화면이 안내한 명령으로 승인** → `touch` 가 그 사용자 걸음 그대로다.
  ⚠ **과제를 고른 쪽은 ADR-0003 이 `codex.ts` 에 후보로 걸린다는 것을 착수 관측으로 이미 알았다.** 그 사실을 봉인 문서 머리에 적고 효과 판정의 입력에 넣는다 —
  숨기면 「덜 말했나」의 판정이 앞선 앎에 기운다.

- **CI 가 이 회차의 push 에도 안 뜨면** ⟨CA1-07⟩ — `F2` 를 `대조불가` 로 적는다. 로컬 `cargo xtask check`·`cargo xtask test` 의 초록을 산출로 남기고, 종료 보고에 소유자가 볼 자리 한 줄(저장소의 Actions 탭 — push 이벤트는 있는데 런이 0)을 적는다.
- **ditto 전량의 TypeScript 컴파일러 대조가 한 번에 안 돌면** — 선 엣지에서 고정 시드 무작위 표본 400 으로 재고, 표본임과 시드를 산출 머리에 적는다.

## 완수 조건

### 이 절이 쓰는 말

- **「TS 픽스처」** — 시험이 임시 디렉터리에 심는 git 저장소. **ditto 의 이름·경로를 쓰지 않는다**(결합 금지).
- **「TypeScript 컴파일러 대조」** — `node` 로 ditto 원본의 `node_modules/typescript`(5.9.3 · 읽기만)를 불러 `ts.resolveModuleName` 이 고른 파일과
  `pal` 이 세운 파일 간 엣지의 대상 파일을 댄다. 대조 스크립트는 `oracle/` 에 두고 **해소 규칙을 스스로 갖지 않는다**(TypeScript 가 답한다).
  이 저장소 CI 에는 TypeScript 가 없으므로 **일회성 실행이고 산출을 `oracle/` 에 남긴다.**
- **「사람 화면」** — `--json` 이 아닌 출력. 표준출력과 표준오류 둘 다.
- **「금지 패턴」** — **`regex` 크레이트 문법으로 지금 등록한다.** 단어 경계는 **ASCII 경계 `(?-u:\b)`** 다 — 유니코드 `\b` 는 `A5는`·`#133에서` 처럼 한글이 바로 붙은 꼴을 못 잡는다. 뒤돌아보기는 쓰지 않는다(그 크레이트가 지원하지 않는다) ⟨CA2-02⟩.
  `이 회차` · `앞 회차` · `회차의 범위` · `잠근 축` · 조건 ID `(?-u:\b)[A-KM-Z][0-9]+(-[a-z])?(?-u:\b)` 와 `(?-u:\b)L[5-9][0-9]*(?-u:\b)`(등급 `L0`~`L4` 를 뺀 나머지) ·
  규칙 ID `(?-u:\b)[A-Z]-[0-9]+(?-u:\b)`(`R-21` 꼴) · 이슈 번호 `(?:^|[^0-9A-Za-z])#[0-9]{1,5}(?-u:\b)` · 기능 코드 `(?-u:\b)F[0-9]{2}[a-z]?(?-u:\b)` · `\[f[0-9]{2}` · `ADR-[0-9]{4}` · `§`.
  ⚠ **낱말 `회차` 자체는 금지하지 않는다** — 설치된 하네스의 이름이고(`pal round`) 소유자의 선은 **회차 내부 어휘**다.
  ★ **재는 것은 `pal` 이 쓴 문구다** ⟨CA2-01⟩ — `--json` 이 있는 호출은 **같은 호출의 `--json` 이 싣는 사용자 저장소의 내용**(경로 · 앵커 · 심볼 이름 · 조각 본문)과 같은 부분 문자열을 지운 뒤 잰다. ditto 의 `ADR-0001-…` · `### D1 —` 는 대상 저장소의 이름이지 이 저장소의 어휘가 아니다.
  ★ **검사 함수는 한 벌이다** ⟨CA2-09⟩ — `crates/pal-cli/tests/` 의 시험 파일 하나가 패턴 목록과 함수를 갖고, 같은 파일의 `#[ignore]` 시험이 환경 변수 `PAL_VOCAB_SCAN=<출력 파일들>` 로 임의 출력을 같은 함수로 잰다. 다른 언어로 다시 적지 않는다.
- **「새 복제본」** — `git clone ~/dev/projects/ditto` 로 뜬 `aded7ce` 이고 `.palimpsest/` 가 **없는** 사본.
