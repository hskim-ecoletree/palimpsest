| R8 (독립 리뷰 처분) | **합계 검산을 `(출처, 라운드)` 쌍으로 바꿨다** — 라운드 번호만으로 세면 ① 출처가 겹칠 때 멀쩡한 레코드가 거짓 실패하고 ② 반환문 없는 출처는 아무 검산도 안 받는다(금지역). 그리고 **실측·인터뷰는 「면제」로 명시**한다 — 「안 잰 것」과 「잴 수 없는 것」을 같은 침묵으로 두지 않는다 |

| R9 | **`합격선판정` 필드를 없앴다** — 131 행 전부 `해당없음` 이었고 두 산출이 모순이었다. 정본은 **게이트의 `## 판정`** 이다 |
| R9 | **합계 검산을 `(회차, 출처, 라운드)` 삼중키로** 했다 — 앞 판의 이중키는 다음 회차가 자기 레코드를 놓는 순간 두 회차를 서로 거짓 실패시켰다 |
| R10 | **`schema_version` 을 2 로 올렸다** — `합격선판정` 제거가 깨지는 변경인데 버전을 안 올려, 버전 1 로 정당하게 쓰인 레코드가 스키마 1 에서 전부 실패했다 |
| R10 | **머리 줄에 `종류` 를 넣었다** — 앞 판은 `findings.jsonl` 이라는 **이름**만 행 검증을 받았고 다른 `.jsonl` 은 통과하면서 「쟀다」로 보였다. **이름이 아니라 선언이 가른다** |
| R10 | **기각 절이 표여도 센다** — 규약이 사전부검자에게 「기각도 표로」 시켜 놓고 검산은 불릿만 셌다. 다음 회차 첫 사전부검에서 거짓 실패했을 것이다 |
| R10 | **`record.py check` 의 rc 를 버리지 않는다** — rc≠0 인데 stderr 가 비면 초록이었다. 규약의 *"`rc` 는 판정이 아니다"* 는 **rc 만으로 판정하지 말라**는 뜻이지 무시하라는 뜻이 아니다 |
| R10 | **효과를 스크립트가 만든다**(`effect/build.py`) — 효과의 수를 **세 번 손으로 적었고 세 번 다 커밋 시점에 이미 거짓**이었다. 그중 하나는 게이트에 적혔다 |
| R10 | **C7-d 를 정정했다** — 「네 출처 전부의 원 반환문」은 원리상 불가다. **에이전트 출처(사전부검·독립리뷰)는 보존**하고, 인터뷰는 대화, 실측은 **커밋 메시지**가 원문임을 명시한다. 잴 수 없는 것을 안 재게 된 것이지 재는 양이 준 것이 아니다 |
| R8 | **계기판의 라운드 대조를 없애고 출처별 분포로 바꿨다** — 대조의 전제가 틀렸다. 사전부검 R1~R3 · 독립 리뷰 R1~R5 · 커밋 R1~R7 은 **서로 다른 셈**이고, 사전부검 R1 이 커밋 R1 과 우연히 겹쳐 그 틀림이 안 보였다 |
