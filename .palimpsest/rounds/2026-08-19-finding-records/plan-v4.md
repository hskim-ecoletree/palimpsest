## A. 레코드 자리와 스키마

`.palimpsest/rounds/<slug>/findings.jsonl`

**머리 줄**: `{"schema_version": 1, "회차": "<slug>"}` — `intent_jsonl.rs:36` 의 선례와 같은 형태.
쓰는 자가 「머리를 이미 썼는가」를 안다.

**이후 한 줄이 발견 하나:**

| 필드 | 값 | 왜 |
|---|---|---|
| `id` | `<출처약칭>-<라운드>-<번호>` | |
| `라운드` | 정수 | **레코드가 적는다.** 계기판이 커밋 태그 `[R<n>]` 과 **댄다** |
| `출처` | 독립리뷰 · 사전부검 · 인터뷰 · 실측 | |
| `모집단` | 원의도 · 저장소 · 자기장치 · 회차기록 · 규약 | ★ `자기장치` 도 **적는다**. (나)는 **닫는 것**의 분할이지 적는 것의 분할이 아니다 |
| `유효성` | 참 · 추정 · 거짓 | ⚠ **`획득` 을 만들지 않는다** — 두 어휘가 `추정` 을 같은 뜻으로 써서 한 비트가 두 칸에 갈린다 |
| `해악도` | 금지역 · 실패 · 거짓신호 · 미관 | §11 ② 의 판정 입력 |
| `처분` | 정정 · 확대 · 축소 · 전환 · 범위밖 · 기각 | 아래 대응표 |
| `승격됨` | 예 · 아니오 | 원천은 커밋 `[승격]`. 별도 값으로 안 둔다 |
| `조건변경` | 강화 · 완화 · 없음 | ★ **`완화` 가 여기 산다.** §5: *"재는 의도의 양이 줄었으면 완화"* — 위장한 정정을 가리는 축 |
| `합격선판정` | 통과 · 반증 · 대조불가 · 미측정 · 해당없음 | 독립 리뷰의 **다섯째 어휘**. `처분` 과 섞지 않는다 |
| `사전처분` | 계획수정 · 탐지수단 · 완수조건전환 · 수용사유 · 해당없음 | 규약 §2 의 넷. **§5 와 다른 축**이다 |
| `조건` | 완수 조건 id 또는 `없음` | |
| `경로` · `줄` · `기준커밋` | 좌표 셋 | ★ **검사는 `경로` 실재만 해소한다.** 줄 드리프트는 `기준커밋` 이 설명한다 |
| `요약` | 한 문장 | |

### 대응표 — 규약 §5 ↔ `처분` (v2 가 요구했고 v3 이 빠뜨린 것)

| 규약 §5 | 레코드 | 비고 |
|---|---|---|
| **안개** (*"적지 않는다"*) | **레코드에 안 들어온다** | ★ `기각` 과 다르다. 안개는 물음을 말할 수 없는 것, 기각은 **발견자가 스스로 물린 것**(#72 가 요구) |
| 범위 밖 | `처분=범위밖` | |
| 정정 · 확대 | `처분=정정`·`확대` · `승격됨=아니오` | 의도를 향해 감 |
| 축소 · 전환 | `처분=축소`·`전환` · `승격됨=예/아니오` | 전환은 항상 승격. 축소는 **등록된 퇴로면 아니오** |
| 완화 | `처분=축소` + `조건변경=완화` | §5 의 자를 그대로 |
| 승격 | **처분이 아니다** → `승격됨` | 루프 우회로다 |
| 막힘 | **처분이 아니다** | §11 ② 가 **`해악도` 에서 유도**한다(금지역·실패 → 막힘). 원천을 둘로 안 만든다 |

## B. 쓰는 자 — `.claude/skills/round/bin/record.py`

  셋에 함께 넣어야 하는데(와일드카드 없음) 그것이 새 표면이다.
  검사는 **`record.py --schema` 를 불러** 읽는다 — 파이썬 소스를 정규식으로 안 긁는다
- **호출 형태를 다섯 자리 전부** 고친다: `SKILL.md:96`·`:98` · `dashboard.py:14`(docstring) ·
  `dashboard.py:84`(**사람이 막힌 순간 보는 오류 메시지**) · `NEXT-D-handoff.md:48`
- ⚠ **호출 형태를 재고 정한다** — `python3` 가 Windows 러너에 서는지 이 저장소는 **안 쟀다**
  (CI 에 python 설정 스텝 **0 건**). **먼저 재고**, 안 서면 다른 축으로 간다.
  ADR-0023: *"적어 둔 주석은 아무것도 안 막는다"* · 고를 축은 **양쪽이 할 수 있는 것**

## C. 재는 자 — `cargo xtask check` 의 새 검사

모집단 `.palimpsest/rounds/**/*.jsonl` + `**/*.tsv`. **각 파일이 자기 스키마를 선언**한다.

- `02-classification.tsv` 도 모집단에 들어 **열 수 일관성이 재어진다** — #71 이 지목한
  파일이 사각에서 나온다. **110 행 소급 이전은 범위 밖**(재는 것과 옮기는 것은 다르다)
- **모집단이 비면 실패.** 0 건은 「안 부른다」가 아니라 「안 봤다」다
- **합계 검산의 규칙을 못박는다**: 보존된 원 반환문의 **`^### ` 항 + `## 내가 기각한 것`
  아래 최상위 불릿** = 그 라운드의 레코드 행 수. ★ **이 규칙으로 세면 지금 r1=23 · r2=17 ·
  r3=19 다** — 회차가 그 수를 맞춰야 한다
- `경로` 실재 해소. `줄` 은 안 잰다
- **음성 대조**: 깨뜨린 줄 · 빈 모집단 · 없는 경로를 격리 사본에 심으면 빨개져야 한다

## D. 계기판 칸 둘 — `dashboard.py`

**⑦ 원 의도 비율** · **⑧ 발견 유효성**.

- ⑦⑧ 은 **파일 전체**, ①~⑥ 은 **커밋 범위** — **다른 범위임을 출력에 박는다**
- 레코드가 없으면 **「못 셌다」**
- **출력에 박는다**: *"⑦⑧ 의 원천은 기록된 판정이지 git 이 아니다."*
  §5 의 「원천이 산문이면 못 더한다」를 **충족했다고 주장하지 않는다**
- **`라운드` 를 커밋 태그와 대고, 어긋나면 그 사실을 낸다**

## E. 설치 표면

`layout.rs` 세 목록에 `record.py`. 실질 델타는 이 파일 하나.

- **탐지 수단**: 설치본에서 스크립트가 **실제로 도는지** 재는 시험.
  지금 `dashboard.py` 는 시험 **0** · CI 잡 **0** 으로 「완료」에 잡혀 있다
- **음성 대조**: 설치본에 `.palimpsest/` 가 없어 ⑦⑧ 이 「못 셌다」인 것이
  **정상인지 고장인지** 가리는 시험

## F. 에이전트 정의 둘 — 반환 형식을 레코드에 맞춘다

⚠ **구조 없는 절은 「기각」 하나가 아니다.** 리뷰어에 넷이 더 있다 —
`### 빠진 것` · `### 요구되지 않은 것` · `### 있는데 틀린 것` · `## 미측정 목록`.
**다섯 절 전부**를 같은 표로 낸다.

- 사전부검 반환에 **`모집단`·`유효성`** 을 더한다
- **`근거` → `획득`** 으로 개명(레코드의 `경로` 와 이름 충돌 해소). ★ **레코드에는 안 실린다**
- ⚠ **이 편집이 줄을 민다**(실측: 93→95). 그래서 A 의 좌표가 `기준커밋` 을 든다

## 수용 사유 명시 (금지역인데 안 닫는 것)

**`.jsonl` 이 sunset 트리거를 비껴간다.** 소유자가 승격 2 에서 *"안 만지고 #68 에 관측만"*
을 골랐고 관측은 [실렸다](https://github.com/hskim-ecoletree/palimpsest/issues/68#issuecomment-5336746344).

⚠ **정직하게 적는다** — `docs/sunset.toml` 은 **두 가지로 읽힌다**:
`:17-22` 는 **갈래**(기계가 쓰는 것 = `.json`)로, `:15` 는 **쓰는 자**(`pal` 이 돌렸을 때)로 읽힌다.
이 회차는 **후자를 골랐다.** 파일이 그렇게 말한 것이 아니라 **우리가 고른 읽기**다.
게이트 `## 판정` 에 **금지역 수용**으로, 그 사실과 함께 적는다.
