# palimpsest — Claude Code 플러그인 (얇은 어댑터)

**로직이 여기 들어가면 안 된다** — 플러그인은 전달 경로이지 코어의 정의가 아니다
([F06 §4.4](../../docs/plan/features/F06-surface.md)).

여기 있는 것은 셋뿐이다:

| 파일 | 무엇 |
|---|---|
| `.claude-plugin/plugin.json` | 이름·판·설명 |
| `.mcp.json` | `pal serve` 를 MCP 서버로 등록한다 — **`pal` 이 `PATH` 에 있어야 한다**(`pal install` 이 얹는다) |
| `commands/*.md` | 슬래시 명령 둘. **CLI 를 부르고 산출을 그대로 읽으라고만 적는다** |

★ **질의 이름이 하나도 없다.** 있으면 그것이 카탈로그·CLI·MCP 에 이은 **네 번째
목록**이다(`[f06b.pass]` ⑨).

## 왜 저장소 루트가 아닌가

플러그인의 표준 자리는 저장소 루트다. 그런데 **`.mcp.json` 을 루트에 두면 이 저장소를
여는 것만으로 MCP 서버가 붙는다** — 개발 중인 도구가 자기 개발 세션에 자동으로
매달리는 것이고, `pal` 이 아직 `PATH` 에 없는 상태에서는 그냥 실패한다.

`surface/` 는 이미 표면 계약이 사는 자리다(`queries.toml`). 플러그인도 표면이므로
여기 둔다. 배포할 때 이 디렉터리가 플러그인 루트가 된다.
