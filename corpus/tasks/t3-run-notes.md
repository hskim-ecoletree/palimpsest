절차는 [`t3-protocol.md`](t3-protocol.md) §다른 PC에서 실행하는 절차.

## 2026-08-12 · 시작 전 선언

**사전 열람 없음.** 판정 시작 전에 물었고 판정자가 "본 적 없다"고 답했다
(커밋 diff 로 스쳐 본 것 포함해서 묻고 받은 답이다).
따라서 이 회차에는 **"오염 — 사전 열람"** 표시를 붙이지 않는다.

블록 순서는 등록된 대로 고정한다:
A1(1–4) → D(5–12) → B1 · B2 → C(29–34) → A2(35–38) → E → F.
