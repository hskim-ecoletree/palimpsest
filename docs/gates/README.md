# 이 디렉터리는 **동결된 기록**이다

`docs/gates/` 의 **판정 문서**(`F*` · `G*` · `S*` · `preflight`)는 **그 회차가 그때 무엇을
쟀는지**를 적는다. 사후에 안 고친다.

⚠ **수를 안 적는다.** 「N 파일이 동결됐다」는 파일이 하나 늘면 즉시 거짓이 되는
캐시다(이 문서를 놓는 것만으로도 그렇다). 재는 방법은 `ls docs/gates/` 이고,
언제 무엇이 들어왔는지는 `git log docs/gates/` 다.

## 왜 안 고치나

**사후에 고치면 그것은 사전 등록이 아니게 된다.** 게이트 문서는 *"측정 전에 등록한
합격선"* 과 *"그것을 재고 낸 판정"* 을 담는다. 판정이 난 뒤에 합격선을 손보면 그
게이트가 무엇에 대해 통과했는지가 사라진다. `corpus/criteria.toml`(사전 등록 대장)과
`docs/adr/`(채택 시점의 결정 기록)이 같은 자격이다.

**그래서 `cargo xtask check` 의 죽은 링크 검사는 이 셋을 안 훑는다.** 훑으면 검사가
동결을 깨라고 요구한다.

## 그래서 여기 죽은 링크가 있다

2026-08-18 재고 처분이 `WHITEPAPER.md` · `docs/DESIGN.md` · `docs/how-it-works.md` ·
`docs/plan/features/` 25 파일을 지웠다. 이 디렉터리와 `docs/adr/` · `docs/instructions/` ·
`corpus/` 에서 그것들을 가리키던 링크는 **그대로 둔다.**

**무엇이 어디로 갔는지는 [`docs/plan/disposal-map.md`](../plan/disposal-map.md) 가 진다.**
그리고 원문은 사라지지 않았다 — `git show <커밋>:<경로>` 로 언제든 열린다.

## ★ MCP 를 현재형으로 서술하는 게이트가 있다

`F06b` · `F06` · `F05` · `F11-touch` · `F12` 가 `crates/pal-mcp` 를 **있는 것**으로
쓰거나 *"아직 없어서 대조 불가"* 로 적는다. 2026-08-18 에 어댑터가 지워졌으므로
(ADR-0025) **그 문장들의 사유가 바뀌었다:**

> **「아직 안 만들어서 대조 불가」가 아니라 「요구가 철회되어 영영 안 잰다」다.**

문장은 안 고친다(동결). 사유의 정정은 여기 있고,
[재고 처분 게이트](inventory-disposal.md) `## 판정` 이 폐기된 사전 등록 합격선을 센다.

⚠ 그리고 `F06b.md:38` 의 실측 `774 / 0 / 1` 은 **어댑터가 있던 세계의 값**이다. 같은
줄이 어댑터 없는 세계를 `755 · 41줄` 로 예측해 뒀고, **삭제 후 실측이 정확히 755 였다.**

## 새 게이트는 절 이름 넷으로 쓴다

`## 합격선` · `## 판정` · `## 효과` · `## 범위 밖`. 전문은 `/round` 스킬 §9.
**옛 게이트를 그 형식으로 옮기지 않는다** — 지난 판정은 그때의 기록이라 형식을 바꿔도
새로 재는 것이 없다.

## 조건 ID 의 문법 — **표준 표가 이것을 그대로 쓴다**

```
^[A-Z][0-9]+(-[a-z])?$
```

대문자 한 글자 + 숫자, 뒤에 `-a` 꼴 하위 첨자. `A1` · `C11` · `C9-a`.
**조건의 첫 낱말**이어야 하고 굵게(`**A1**`)는 받는다.
세는 자리: `python3 .claude/skills/round/bin/record.py conditions <intent.md>`.

⚠ **엄격한 파서와 안 적힌 문법은 같이 가면 안 된다.** 옛 회차 둘은 이 문법을 안 지켜
그 조건들이 전부 「ID 가 없다」로 난다 — **그 회차들이 쓰일 때 이 문법이 어디에도 안
적혀 있었기 때문이다.** 그래서 여기 적는다.

## `## 판정` 의 표준 표 — 수가 아니라 **조건 ID**

```markdown
| 판정 | 조건 |
|---|---|
| 통과 | A1 A2 A3 |
| 반증 | — |
| 대조불가 | C9-a C9-b |
| 미측정 | — |

**검산** — 통과 3 · 반증 0 · 대조불가 2 · 미측정 0 = 5
```

**두 열이고 수 칸이 없다.** 수를 적으면 그것이 캐시고, 캐시는 갈린다 — 이 디렉터리가
맨 위에서 *"수를 안 적는다"* 고 적은 것과 같은 자다. **ID 를 적으면 수는 세면 나오고,
대조가 「집합 같음」이 되어 훨씬 강하다** — 수만 맞고 내용이 다른 경우를 잡는다.

★ **판정 원장은 둘이다.** 이 표와 회차의 `intent.md` 완수 조건 상자. 둘이 갈리는 것을
`cargo xtask check` 의 **「원장 둘 대조」**가 댄다:

| 무엇 | 어떻게 |
|---|---|
| 짝짓기 | 게이트 본문에 적힌 `.palimpsest/rounds/<회차>/intent.md` 로 **역인덱스** |
| 대조 | ID 집합 **양방향** + 조건마다 상자와 판정 태그 |
| 검산 | 적힌 수 ↔ ID 목록 길이 |
| 하한 | **끝난 회차 중 가장 최근 것**이 검사에 들었는가 |

⚠ **표준 표가 없는 게이트는 「형식 이전」이고 검사 밖이다** — 오류가 아니다. 위의
「옛 게이트를 옮기지 않는다」가 그대로 산다.

★ **「안 바뀐다」가 무엇에 대한 말인지 못 박는다** — 이 문서 맨 위가 정의한
**판정 문서**(`F*` · `G*` · `S*` · `preflight`)다. 그것들은 **한 글자도 안 바뀐다.**
회차 게이트(`round-*` · `rust-extractor` · `inventory-disposal` · 기능 이름)는
**판정을 안 바꾸는 정정**을 받는다 — 예: 재는 명령이 틀렸으면 고친다.
⚠ 앞 판은 이 구별 없이 *"이 디렉터리의 옛 판정 문서는 아무것도 안 바뀐다"* 라고만
적었고, **그 문장을 쓴 커밋이 같은 커밋에서 회차 게이트 둘을 고쳤다**(독립 리뷰 R8).

★ **기존 묶음 표·근거 표는 지우지 않고 표준 표를 위에 더한다.** 근거가 사라지면 그
판정이 무엇에 근거했는지가 사라진다.
