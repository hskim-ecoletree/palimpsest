# S2 게이트 — `pal touch <좌표>` · 판정 기록

**판정: 아직 없다 — 측정 전이다.**

이 파일은 **합격선을 등록한 커밋에서 함께 만들어졌고, 그 시점에 `Coord`·`Envelope`·
`SymbolId` 는 존재하지 않았고 2층도 없었다.** 비어 있는 것이 지금의 정상 상태다.
판정은 **통과 · 반증 · 대조 불가** 셋 중 하나로 여기 적힌다([계획 §7.1](../plan/README.md)).

## 등록된 합격선 — 결과보다 먼저

| | 값 |
|---|---|
| **오라클** | **값이 아니라 불변식이다** — `body_digest` 가 옳은 값인지 말해 줄 바깥의 표가 없다 |
| **코퍼스** | `boxwood-portal-kotlin @ a29cad0bf6a8` 의 `.kt` 671 파일 (S1 이 검증한 핀) |
| **① 봉투** | `Envelope` 필드 누락 **0** — `elision` 은 없어도 명시적 `none()` |
| **② 빈 답** | 결박·해소·효과·판정 자리가 **빈 배열이 아니라 `Capable::NotBuilt{기능번호}`** |
| **③ 정규화** | 포매팅·주석에 **불변** · 의미 변경에 **가변** — **양방향을 함께** |
| **④ 정체성** | 같은 심볼은 같은 `symbol_id` · **이동하면 id 는 바뀌고 digest 는 그대로** |
| **⑤ 2층** | 지우고 1층에서 **재구축했을 때 같다** |
| **⑥ 실물** | 코퍼스에서 이름으로 심볼이 찾아진다 |
| 기한 | **없다** — 계획 §7.2 |

**③ 이 양방향인 이유가 이 게이트의 핵심이다.** 앞의 것만 보면 상수를 돌려주는 digest 가
통과하고, 뒤의 것만 보면 원문 해시가 통과한다. 원문 해시는 [R-07](../plan/00-risks.md#r-07)의
거짓 양성 그 자체다.

**합격선을 누가 정했는가** — S1 과 같다. 소유자 위임 하에 에이전트가 정했고
[R-18](../plan/00-risks.md#r-18)이 세게 걸린다. 소유자가 뒤집으면 그 사실이 여기 적힌다.

## 이 게이트가 판정하지 않는 것

- **정규화가 "옳은지"** — 불변식 둘만 본다. 어디까지 지워야 의미 보존인가는 F03 의 표본이 진다.
- **참조 해소(F07)** · **결박(F09~F12)** · **예산 절단(F05)** — 전부 `NotBuilt` 이고
  그것이 ② 가 시험하는 자리다.
- **R-07 이 닫히지 않는다.** 거짓 양성률은 실제 커밋 이력에 대고 재야 한다.
