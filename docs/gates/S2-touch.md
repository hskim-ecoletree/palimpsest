### ③ 정규화가 양방향으로 섰다 — R-07 이 사는 자리

| 입력 변화 | `body_digest` | 왜 중요한가 |
|---|---|---|
| 공백 · 줄바꿈 · 들여쓰기 | **불변** | 포매터 커밋 하나에 결박이 무더기로 `stale` 이 되면 사람이 표시를 무시한다 |
| 주석 추가 | **불변** | 문서 수정이 코드 변경이 아니다 |
| 선택적 세미콜론 | **불변** | Kotlin 에서 스타일이다 |
| 반환값 변경 | **가변** | |
| 파라미터 타입 변경 | **가변** | |
| 본문에 호출 추가 | **가변** | |
| **지역 변수명 변경** | **가변 — 지우지 않는다** | [R-22]. 스코프 해소(L2)가 없는데 지우면 서로 다른 코드가 같은 요약을 갖는다 |

**앞의 셋만 보면 상수를 돌려주는 요약이 만점을 받고, 뒤의 셋만 보면 원문 해시가 통과한다.**
원문 해시는 R-07 의 거짓 양성 그 자체다. 그래서 양방향을 함께 요구했다 —
S1 의 캐시 음성 대조와 같은 형태의 방어이고, 세 슬라이스 연속으로 같은 함정을 막았다.

토큰 사이에 `\x1f` 를 넣는다. 넣지 않으면 `fun f` 와 `funf` 가 같은 바이트열이 된다.

### ④ 두 축이 실제로 분리돼 있다

`symbol_id 3b24ed45c5f2` ≠ `body_digest b9fd0caa81de`. 경로가 `symbol_id` 의 성분이고
`body_digest` 의 성분이 아니므로, **파일을 옮기면 정체성은 끊기고 본문 요약은 남는다** —
그것이 [R-08](../plan/00-risks.md#r-08)의 재결박 제안을 가능하게 하는 유일한 근거다.

`identity ordinal` 로 나오는 것도 옳다. 이 추출기는 **L1(구조)** 이라 스코프가 없고,
심볼의 정체성 등급은 `min(판별자 상한, 언어 등급)` 이다. 언어 단위가 아니라 **심볼
단위**로 계산한다([R-22]).

## 이 회차가 드러낸 것 — 캐시 키 설계가 관측됐다

`Symbol` 에 `body_digest` 가 붙어 추출 산출이 바뀌었는데 `EXTRACTOR_REV` 가 `"s0"` 그대로였다.
**옛 캐시를 새 스키마로 읽으려다 실패했다.**

이것은 사고가 아니라 **설계가 작동한 자리**다. stack §5.1 이 추출기 버전을 1층 캐시 키에
넣은 이유가 정확히 이 경우이고, 값을 `"s2"` 로 올리자 키가 달라져 옛 항목이 조회되지
않는다 — **삭제 없이 무효화된다.** 문법 rev 는 그대로다. 축이 둘인 이유가 이것이다.

`pal-store` 의 캐시가 *"깨진 캐시를 조용히 미스로 만들지 않는다"* 는 규칙을 지킨 덕에
오류로 드러났다. 미스로 처리했다면 성능 저하로만 보이고 영원히 발견되지 않았을 것이다.

### 판정 — **등록의 수정이 아니라 이행의 기록이다**

근거 전문은 `corpus/criteria.toml` `[s2].restated_after_f05`(등록 커밋 —
**스크립트를 고치기 전**). 가르는 문장 하나:

> **등록의 수정**은 합격선이 요구하는 것을 바꾸는 것이다.
> **이행**은 요구가 그대로 참인데, 그것을 재는 검사가 **요구를 그때의 모양으로 굳혀**
> 놓아서 모양이 바뀌자 요구까지 못 읽게 된 것이다.

**스크립트 자신이 이미 같은 처분을 두 번 적어 두었다** — `bindings`(S3 가 채웠다)와
`matches_worktree`(F01 이 채웠다). *"자리가 채워진 것은 합격선의 위반이 아니라
이행이다."* **셋째와 넷째가 이번 것이다.**

| | 판정 | 근거 |
|---|---|---|
| **① `elision`** | **모양이지 요구가 아니었다** | `[s2.pass].envelope_grounds` 가 요구한 것은 *"명시적 `none()`"* 이고 새 모양에서도 참이다. 옛 검사가 요구를 **리터럴 하나로 굳혔다** |
| **② `facts`** | **이행** | `bindings`·`matches_worktree` 와 글자 그대로 같은 일 |
| **② `rebuild`** | **이행** | 옛 주석이 뒤집는 조건을 스스로 적었다 — 아래 |

**`rebuild` 가 가장 값진 자리다.** 옛 주석이 이렇게 적어 두었다:

> **재구축은 여전히 `NotBuilt` 다** — 관측 경로가 F05 이고, 그 자리가 **조용히**
> `Settled` 로 채워지면 *"재구축 중이 아니다"* 가 **관측 없이** 단언된다.

**조용히가 아니다.** [ADR-0010] 이 무대 테이블(`*.staging`)을 세웠고 **무대가 있으면
재구축 중이다** — 그것이 관측이다. **주석이 요구한 조건이 실제로 충족됐다.**
관측 경로 없이 `Settled` 가 됐으면 그때는 위반이었고, **그 구별이 이 재판정의 전부다.**

### `elision` 을 다시 쓴 형태 — **리터럴이 아니라 요구를 잰다**

    자리가 있고 · 선언된 통이 **1 개 이상**이고 · 그 통이 **전부** 비어 있다

**`{}` 는 실패다** — 통이 0 이면 *"안 잘랐다"* 가 아니라 *"아무 말도 안 했다"* 이고
그것이 [스택 §5.4](../plan/00-stack.md) 가 금한 조용한 절단이다. **그리고 이 형태는
F0x 가 통을 하나 더 더해도 안 깨진다.**

### ★ 음성 대조 여덟 — **검사를 요구로 옮기면 아무것도 안 세기 쉽다**

`--self-test` 가 방향마다 봉투를 망가뜨려 잡는지 센다. **성한 봉투를 안 잡는 것도
함께 센다**(F22-4 와 같은 형태).

```text
★ 음성 대조 — 방향마다 망가뜨려서 잡는다
  ✓ 성한 봉투는 안 잡는다                      그대로
  ✓ elision 자리를 통째로 지운다                          잡힌다
  ✓ elision 을 `{}` 로 — 통이 하나도 없다                 잡힌다
  ✓ elision 에 자른 것을 싣는다                          잡힌다
  ✓ 봉투 필드 하나(coverage)를 지운다                      잡힌다
  ✓ 안 만든 자리 하나를 `[]` 로                           잡힌다
  ✓ 안 만든 자리에서 기능 번호를 지운다                         잡힌다
  ✓ 채워진 자리(bindings)를 not_built 로 되돌린다           잡힌다
  ✓ rebuild 를 not_built 로 되돌린다                   잡힌다
  음성 대조 실패 0 건
```

### ⚠ 발견 하나를 1급으로 적고 넘긴다 — **`facts` 의 모집단**

이 코퍼스에서 `facts` 가 `{callers: 0, callees: 0}` 이다. **Kotlin 추출기는 스코프
체인을 안 만들고**(`Capable::NotBuilt`) 그래서 파일 내 엣지가 0 이다.
**[ADR-0002] 가 가른 바로 그 자리다** — 「없음」이 아니라 「안 만듦」인데
`crates/pal-cli/src/touch.rs` 가 `facts` 를 **무조건** `Capable::Present` 로 싣는다.

**`[s2]` ② 의 합격선은 아니다** — ②가 요구한 것은 *"빈 자리가 `[]` 가 아니라
`not_built{기능번호}`"* 이고 그것은 지켜졌다. 그러나 **같은 규율이 한 층 아래에서 안
지켜지고 있다.**

**여기서 안 고친다.** 고치면 산출이 움직이고 소유자가 다르다 — 파일 간 해소는 **F07**,
추출기의 능력을 자리에 싣는 것은 **F02-3 의 계약**이다. **스크립트가 이것을 통과로
세지 않고 「발견」으로 찍는다** — 조용히 넘기지 않는 것이 여기서 할 수 있는 전부다.
