  **세 회차가 다른 수를 낸다.** 그리고 앞 둘에 대해 ⑤⑥ 을 **「못 잰다」로** 낸다 —
  표기가 이 회차에서 태어났다. **0 을 「없었다」로 읽지 않는다.**

- [`effect/install-roundtrip.txt`](../../.palimpsest/rounds/2026-08-18-completion-condition/effect/install-roundtrip.txt)
  — `pal` 을 직접 불러 **남의 파일 둘이 미리 있는 프로젝트**에서 install → update →
  uninstall 왕복. **남의 파일이 살아남았고** 사용자가 고친 정책은 *"사용자 수정 — 지웠다"*
  로 **말하고** 지운다.

★ **효과가 결함 둘을 잡았다.** 계기판이 **빈 범위에서 크래시**했고(이제 「못 잰다」고
말한다), 설치가 **놓기는 하는데 되돌릴 수 없었다**(`PAYLOAD` 에만 더하고 상한 목록에
안 더했다 — 시험 셋으로 묶었고 음성 대조가 발화했다).
