## 등록된 합격선 — 결과보다 먼저

계획 §3 은 이 슬라이스가 판정할 것을 *"제품의 형태가 처음으로 보인다"* 로 적었다.
그것은 반증 가능한 문장이 아니므로 바꿨다:

> **사람이 손으로 넣은 것이 파생층을 지워도 살아남고, 코드가 변하면 그 사실이 표시된다.**

앞의 절반이 R-21 이고 뒤의 절반이 R-07 이다. 둘 다 **치명**이다.

| | 값 |
|---|---|
| **① R-21** | **2층을 통째로 지운 뒤에도 결박이 그대로** |
| **② 결박이 뜬다** | `touch` 의 `bindings` 가 `NotBuilt` 가 아니라 `Present` |
| **③ 낡음** | 코드 그대로면 `Live` · 바뀌면 `Stale{triggered_by}` (**양방향**) |
| **④ 사라짐** | 심볼이 없어지면 `Stale` 이 아니라 `Orphaned` |
| **⑤ 구조** | `pal-intent` 에 **지우는 공개 API 가 없다** |
| 기한 | 없다 |

**① 이 이 게이트의 정수다.** 지금까지 `pal-store` 가 `pal-intent` 에 닿지 않는지를
정적으로만 검사했는데, 의도 저장소가 비어 있었으므로 그것은 **빈 방에 자물쇠를 건 것**
이었다. S3 에서 처음으로 그 방에 사람의 노동이 들어간다.

R-21 이 조용히 일어나는 이유도 여기 적어 둔다 — **재구축 등가성 검사가 그 상태에서도
통과하기 때문이다.** 2층은 1층에서 완벽히 복원되므로 검사는 초록이고, 사라진 것은
사람이 넣은 것뿐이다. 그래서 ① 이 재는 것은 *"2층이 복원되는가"* (그것은 S2 합격선 ⑤
였다)가 아니라 **"2층을 지웠는데 의도가 남는가"** 다.

## 이 게이트가 판정하지 않는 것

- **F09 의 완료가 아니다.** 감시 집합의 **반경** · `StaleDerived` · `Superseded` 축 ·
  승인 흐름은 F09~F12 다. S3 의 감시 집합은 **결박 대상 심볼 하나**뿐이다.
- **문서 인입(F10)이 아니다.** 조각을 문서에서 잘라 신호로 좌표를 찾는 일은 그 기능의 것이고,
  S3 는 사람이 이름으로 직접 지정한 결박 하나를 다룬다.
- **R-07 이 닫히지 않는다.** 거짓 양성률은 실제 커밋 이력에 대고 재야 한다.
