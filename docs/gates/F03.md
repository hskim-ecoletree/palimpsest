## 1. R-22 의 판정 — **ADR-0006 이 지목한 문장**

[ADR-0006](../adr/0006-identity-grade-is-per-symbol.md)이 *"R-22 의 판정은 **F03** 이고,
「포매팅 커밋에서 `stale` 0 건」이 그 합격선"* 이라고 적었다. **그 문장이 이 지붕의
판정 대상이었다.**

| | 관측 |
|---|---|
| **합성 포매팅 커밋** (우리가 가한 변형 일곱 · `prettier` 포함) | **`stale` 0 건 / 4,578 심볼** |
| **실 이력의 「포매팅 위주」 커밋 20 건** | `stale` **9** — 그중 손 검토상 거짓 양성 **0** |
| 린터가 손댄 커밋 여덟 (`style` · `chore(format)` · `biome lint:fix`) | **`stale` 0 건** |

**R-22 는 P0 의 등급에서 닫힌다.** 등급이 못 미치는 심볼에서 이름을 지우지 않고
(F02-3 이 세운 심볼 단위 등급), 지워도 되는 심볼에서는 지우며, **그 둘이 반대 방향으로
함께 시험된다.**

**닫히지 않는 절반**: 이 판정은 **L2a(파일 내)** 위에서의 것이다. F07 이 L2b 를 세우면
등급이 오르고 그때 좌표가 다시 움직인다 — **설계된 바이고**(`extractor_version` 이
좌표 축이다) 회귀가 아니다.

## 3. 이 기능이 실제로 찾은 것 — **검사가 검사를 못 하는 형태 아홉**

F02 의 산출이 *"우리가 못 읽은 것을 「변한 것이 없다」로 적는"* 병의 세 얼굴이었다면,
**F03 의 산출은 「대조가 자기도 모르게 꺼져 있는」 형태 아홉이다.**

| | 어디서 | 무엇이 꺼졌나 |
|---|---|---|
| 저장소 이름이 회차마다 달랐다 | F03-1 | **무엇을 재든 언제나 실패**하는 검사 |
| 재정렬을 바이트 자리로 셌다 | F03-1 | 8 건이 나왔고 실제로는 **0** |
| 맞바꾸기를 문자 자리로 잘랐다 | F03-1 | 파일이 깨져 **잴 것이 없어졌다** |
| 열쇠에 자리를 넣었다 | F03-2 | 4,578 중 **136** 만 짝지어졌다 |
| 의미 변형을 주석 안에 놓았다 | F03-2 | **설계대로 동작한 것**을 결함으로 셌다 |
| 템플릿 안을 들여썼다 | F03-2 | 문자열의 **값**이 바뀌었다 |
| 주석의 아포스트로피를 문자열로 봤다 | F03-2 | **심볼 134 개가 사라졌다** |
| 정규식 리터럴을 안 갈랐다 | F03-2 | 따옴표 짝이 어긋났다 |
| 후행 쉼표를 붙이려 했다 | F03-2 | 씨앗이 이미 붙어 있어 **아무것도 안 바꿨다** |

**아홉 중 다섯이 「어디가 코드이고 어디가 아닌가」였다.** 그래서 F03-2 는 변형기들이
**스캐너 하나**를 공유하게 만들었다.

**그리고 이 목록의 값은 아홉이라는 수가 아니라 그것들이 어떻게 드러났는가다** —
넷은 *"어긋났다"* 로, 다섯은 **침묵**으로 드러났다. 침묵으로 드러나는 것을 잡으려고
합격선 안에 하한을 박았다: 변형이 아무것도 안 바꾸면 실패, 대조할 항목이 둘 미만이면
실패, `proptest` 에 *"모든 변형이 적어도 한 씨앗을 바꾼다"*.

**F22 의 대조가 F03 의 결함을 잡은 사례도 하나 나왔다** — 스키마에 `container` 를
필수로 올렸는데 `pal doctor` 의 투영이 그것을 안 내서 심볼 1,296 개 전부가 위반이 됐다.
`f22-4-verify.py` 의 ②(*"성한 코퍼스 2층에서 위반 0 건"*)가 잡았다. **픽스처 여덟은
전부 통과했고 실물만 어긋났다** — 그 항목이 존재하는 이유 그대로다(`8ad1e50`).

| | 무엇이 틀렸나 |

| F03 §3.2 | 컨테이너를 *"파일→클래스→(중첩)클래스"* 로 적었다 — 실물은 더 넓다(중첩 함수 · 함수 안 타입 별칭 여덟) |
| F03 §3.1 **예시** | 정규형에 `;` 가 남아 **바로 위 표와 어긋났다**(표는 "선택적 세미콜론을 지운다") |

**넷 다 「코드를 문서에 맞추지도 문서를 코드에 맞추지도 않고」 먼저 판정했다.**

고쳤다. 그리고 **§3.1 의 예시는 이제 시험의 오라클이다**
(`정규형이_문서에_적힌_그대로다`) — 어긋나면 둘 중 하나가 반드시 고쳐진다.

## 6. 이 기능이 만든 표면 · 의존 · 좌표 이동

**표면 하나**: `pal ledger --symbols`. 골든이 읽는 창이고, 줄 단위라 `diff` 가 곧
움직인 것의 목록이다. **`--json` 의 형태는 안 건드렸다** — `s0-compare.py` 가 그것을
파싱한다(F02 가 `--graph` 를 더할 때와 같은 판단).

**새 의존 하나**: `proptest` — **`dev-dependencies` 이고 산출 바이너리에 안 들어간다.**
`cargo deny` 의 licenses **예외를 하나도 안 늘렸다**(F02 가 둘을 들이면서 그랬던 것과
같다). `trybuild` 는 들이지 않았다 — `rustdoc` 의 ```compile_fail 이 이미 그 일을 한다.

**검사 하나**: `cargo xtask check` **7 → 8**. 선택 필드 금지 1단계.

**좌표가 두 번 움직였다**: `EXTRACTOR_REV` `f02-3` → `f03-1` → `f03-2`.
**층 표시(`pal1`)는 안 올렸다** — 키의 **형태**가 아니라 이미 키에 있던 성분의 **값**이
바뀐 것이고 [ADR-0004](../adr/0004-cache-key-covers-every-input-that-decides-the-output.md)가
요구한 것은 전자다(F02 §5 와 같은 판단).

**골든 셋이 움직였다** — 그리고 **셋 다 움직인 것을 적고 나서 축복했다**:

| 골든 | 움직인 것 |
|---|---|
| `portal-backend.ledger.json` | **한 곳** — `detector.extractor` `f02-3` → `f03-2` |
| `ditto.symbols.tsv` (새것) | 첫 축복 4,578 줄 |
| `portal-backend.symbols.tsv` (새것) | 첫 축복 1,296 줄 |

`s0-reference-vector.tsv` 와 `f02-recall-sample.tsv` 는 **안 움직였다** — 선언 수와
손 목록은 좌표계와 무관하다.

## 7. #50(Kotlin 문법 핀)의 순서 — **판단하고 적는다**

핸드오프가 이 판단을 착수 세션에 넘겼다. **결론: #50 을 F04 보다 먼저, 그리고 지금
바로 다음에 한다.**

근거 셋:

1. **골든이 방금 축복됐고 #50 은 그것을 다시 움직인다.** F02 가 실측한 대로 문법 포크
   다섯이 `partial` 27 중 26 을 읽으므로 **선언 수가 바뀐다**(56 → 9). 그러면
   `s0-reference-vector.tsv`(1,126 줄) · `portal-backend.ledger.json` ·
   `portal-backend.symbols.tsv`(1,296) 가 **전부** 움직인다
2. **그런데 ADR-0007 이 그 비용을 키웠다.** 정규형이 이제 **문법 노드 이름**에 묶여
   있어서, 문법을 올리면 `body_digest` 도 함께 움직인다. **미룰수록 한 번에 움직이는
   것이 늘지는 않지만, 그 사이에 쌓이는 골든과 결박은 는다**
3. **F04(캐시)가 골든 인프라를 놓기 전에 하는 것이 싸다.** F02 지붕이 *"축복 대상이
   아직 자주 바뀌는 산출이면 골든이 잡음이 된다"* 라고 적었고, 문법 핀이 그 「자주
   바뀜」의 마지막 남은 원인이다

**F03 을 막지 않았다는 판단은 그대로다** — 좌표가 움직이는 것 자체는 설계된 바이고
(F03 §6.3), 이 기능은 그것을 **목록으로 적는 장치**를 세웠다. 그 장치가 서 있는 지금이
문법을 올리기 가장 싼 때다.

## 9. ADR 둘을 발행한다

계획 §7 의 규율: **ADR 은 기능 착수가 아니라 종료 시점에 발행한다.**

| | |
|---|---|
| [ADR-0007](../adr/0007-the-normal-form-is-a-tree.md) | **정규형은 토큰 열이 아니라 트리다** — 그래야 스타일을 지울 수 있다 |
| [ADR-0008](../adr/0008-controlled-mutation-and-real-history-do-not-substitute.md) | **합성 대조와 실 이력은 서로를 대신하지 못한다** — 그래서 둘 다 둔다 |

**지금 있는 여섯과 모순되지 않는다.** ADR-0004(캐시 키)와의 관계는 §6 에,
ADR-0006(심볼 단위 등급)과의 관계는 §1 에 적었다 — 이 기능은 ADR-0006 이 지목한
판정을 **수행**했지 뒤집지 않았다.
