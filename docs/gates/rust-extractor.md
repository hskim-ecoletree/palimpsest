(*"기계 대조군이 돌았고 손 표본과의 차이가 판정에 적혔다"*)이 지금 충족된다.
R3 의 판정을 받는다:

```
── 음성 대조 (syn) ──
  손 표본 268 · syn 268
  손에만 0 · syn 에만 0
```

⚠ **B3 는 다르다.** 승자가 축 등록보다 **9 분 앞선** 커밋에 이미 박혀 있었고,
그 순서는 **되돌릴 수 없다.** R3 도 *"통과로 올리면 그것이 더 나쁘다"* 로 기각했다.

### ⓑ①② 대조 불가 — 재현율 94.40% · 정밀도 94.40%

**완수 조건 D5 는 통과다**(*"집합 비교로 냈다"*). 그러나 합격선이 요구한
**「빠뜨린 것 0 · 잘못 잡은 것 0」은 안 섰다:**

```
표본     파일 13 · 손 표본 선언 268 (열쇠 268)
산출     선언 268 (열쇠 266)
① 빠뜨린 것  15
② 잘못 잡은 것 15
재현율   94.40%
정밀도   94.40%
```

⚠ **앞 판은 `②13 · 95.11%` 를 실었다.** 그때 검증 스크립트가 **열쇠 집합으로**
비교해 중복을 삼켰고(산출 268 을 266 으로 보고), 삼켜진 둘이 하필 **R-16 이 사는
축**이었다. 다중집합으로 고치니 **더 정직한 수**가 나왔다.

★★ **어긋남의 원인이 하나가 아니라 둘이었다.** 앞 판은 하나로 적었고 독립 리뷰 R1 이
둘째를 격리 파일로 잡았다.

**둘째 — `impl` 이 대상 타입보다 앞에 오면 같은 파일에 있어도 안 붙었다.**
`self.symbols.iter().position(…)` 이 **이미 순회한 것만** 보므로,
구조체를 `impl` 위로 옮기기만 해도 그래프가 조용히 바뀌는 형태였다.
**고쳤다** — 파일 전체를 본 뒤 해소하는 2 패스로 바꾸고 시험 셋을 달았다.
⚠ **그 형태가 이 표본 13 파일에는 안 나타나서 수치는 안 움직였다.** 표본이 그 축을
못 재고 있었다는 뜻이고, 그것이 곧 이 발견의 값이다.

**첫째(그리고 수치를 지배한 것) — `impl` 대상 타입이 같은 파일에 없으면
컨테이너를 못 붙인다.** 실측:
`BuildContext`·`ArgMatches`·`Command`·`Parts`·`ConfigRelativePath`·`String`
**여섯 다 같은 파일에 정의가 0 개**다 — 외부 타입 `impl` 은 Rust 의 관용이다.

⚠ **어긋남은 28 이 아니라 30 이다**(①15 + ②15). 28 은 검증 스크립트가 열쇠 집합으로
비교해 중복 둘을 삼켰을 때의 수다.

`Containment` 는 `LocalIx` 쌍이라 **심볼이 있어야** 걸 수 있고, 외부 타입을 심볼로
만들면 손 표본 규칙 ①(*"`impl` 은 심볼이 아니다"*)을 뒤집는다. **그 표본은 코드보다
먼저 커밋됐으므로 뒤집는 것이 곧 「표본을 결과에 맞추는 것」**이고 이 회차가 등록한
금지역이다.

★ **그래서 「반증」이 아니라 「대조 불가」로 적는다** — 추출기가 틀린 것이 아니라
**`FileGraph` 가 그 관계를 담을 자리가 없다.** 분할 [#78] 이 진다.

⚠ **손 표본을 안 고쳤다.** 규칙이 *"어긋난 것을 게이트에 적는다"* 라고 정했고 그대로 했다.

### ★ D4 는 게이트를 쓰다 「안 쟀다」를 발견하고 돌렸다

판정을 정리하던 중 **기계 대조군을 안 돌린 것**을 봤다. 「미측정」으로 적는 길이
있었으나 **이 회차에서 할 수 있는 일**이었으므로 돌렸다(§10 의 가르는 문장). `syn` 으로 같은 13 파일을 세었다:

```
손 표본 268 · syn 268
손에만 0 · syn 에만 0
```

★★ **다른 파서가 같은 268 집합을 냈다.** 손 표본이 **전사에서** 고장났다면 여기서
드러났고, 안 드러났으므로 어긋남 30 의 책임이 **손 표본이 아니라 추출기 쪽**이다.

⚠ **독립성의 한계를 적는다.** 파서는 다르지만 **규칙(컨테이너 벗기기 · 본문 있는
trait 만 · 함수 안은 안 셈)은 같은 회차가 두 번째로 옮겨 쓴 것**이다. 그러므로
268/268 이 말하는 것은 **「전사가 정확하다」이지 「규칙이 옳다」가 아니다**
(독립 리뷰 R3). 규칙 자체를 반증하려면 **규칙을 안 본 제3자**가 세야 한다.

## 범위 밖

**이 게이트가 답하지 않기로 한 것.** 착수 때 정했고 회차 중에 새로 안 생겼다.

- **L2(스코프 해소)** — 승격 1 로 축소. 그래서 Rust 심볼의 `identity` 가 전부
  `Ordinal` 이고 「순서에 취약한 것」과 「그냥 L1 인 것」이 대장에서 같은 글자다 → [#79]
- **속성 축** — `#[derive(Debug)]` ↔ `#[derive(Debug, Clone)]` 의 `body_digest` 가
  **같다**. `span` 을 넓히는 것으로는 안 닫힌다 → [#77]
- **`impl` 컨테이너** — 트레잇 이름을 안 싣고, 대상 타입이 다른 파일이면 못 붙는다.
  cargo 380 에서 **`ordinal>0` 121(1.9%)** 가 선언 순서에 매인다 → [#78]
- **`GRAMMAR_REV` 합성** — TypeScript 핀이 **이미** 캐시 키 밖이고 Rust 핀도 그렇다.
  ADR-0004 위반이 한 회차 더 산다. ⚠ **알고 두는 것이다** → [#80]
- **CI 의 회귀 관측** — 골든을 대는 스크립트가 CI 에 없다. **이 축의 판정은 이 기계
  하나에서만 재현된다** → [#81]
- **`cfg` 해석** — 추출기는 `cfg` 를 안 읽는다. `#[cfg]` 로 갈린 동명 선언이
  `Ordinal` 로 강등되는 것은 **설계대로**다(실측 2 건)
- **`corpus/criteria.toml:10516` 이 「추출기는 넷뿐」을 현재형으로 말한다** —
  그 파일은 소유자 판정으로 회차가 안 만지는 자리다. 죽은 링크 검사도 인용 검사도
  그 모집단을 뺀다
  ★ **`F11-touch.md`·`F12.md` 는 「원리상 못 고친다」가 아니라 잔여였다.**
  같은 회차가 지시 문서에 갱신 줄을 다는 선례를 만들었고, 독립 리뷰 R1 이 그것을
  지적해 **두 문서에 같은 줄을 달았다.** 판정 본문은 안 바꿨다 — 그때의 측정이다.
  ⚠ 잠긴 의도 §범위 밖은 여전히 *"고칠 수 없으므로 적는다"* 라 적혀 있다.
  **그 문장이 틀렸고 이 게이트가 정정한다**(독립 리뷰 R2)
- **Java·JavaScript 추출기** — 선언된 1급인데 `NotBuilt` 인 채로 남는다
- **Markdown 의 결박** — #69 가 진다 (⚠ 파일 수는 안 적는다 — 변한다)
