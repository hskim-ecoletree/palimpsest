## 정정 — 관측 회차가 성립하지 않는다 (2026-08-12, 착수 직후)

**등록에 "판정용 3dea6df · 관측용 최신"이라고 적었고 그것은 같은 것을 둘로 적은 것이었다.**

```
git rev-list --count 3dea6df..origin/HEAD   →  0
최신 태그 v1.1.0                             =  3dea6df
crates.io tree-sitter-kotlin-ng 1.1.0        =  3dea6df
마지막 커밋 2025-01-16                        →  19개월째 정지
```

**결과를 보기 전에 고쳤다** — [§5.1](../plan/features/P0-preflight.md)의 규율은
*"커밋 이후 불변"*이 아니라 **"결과 이전"** 이다. 조용히 고치지 않고 여기 적는다.

**이것이 드러낸 것 — S0 을 막지는 않지만 기록되어야 한다.**
T7 이 관측한 결함 둘은 **문법 업그레이드로 고쳐질 수 없다.** 최신이 곧 T7 이 쓴 그것이다:

| 결함 | 규모 |
|---|---|
| Exposed `} get` 파싱 실패 | **73파일** — T7 실패 87건의 84% |
| 조용한 오파싱 | **17파일** |

crates.io 에 포크가 여섯 있다(`-sg` · `-codanna` *"includes unreleased fixes from upstream"* ·
`brokk-` · `-sqry` · `-updated` · `tree-sitter-kotlin`). **포크가 그만큼 생겼다는 것이
upstream 이 멈췄다는 신호다.** Kotlin 은 1급 지원 대상인데 그 문법이 유지보수되지 않는다.

**처분은 F02 가 진다** — 포크 채택 · 자체 패치 · 관용구 우회 중 무엇인지 지금 정하지 않는다.

## 이 게이트가 판정하지 않는 것

**추출 품질이다.** 벡터가 완전히 일치해도 증명되는 것은 **"Rust 경로 == CLI 경로"** 까지이고,
둘은 같은 방식으로 틀릴 수 있다 — T7 이 발견한 조용한 오파싱 17건은 파서가 오류를 내지
않으므로 양쪽에서 똑같이 사라진다. T7 이 뽑은 선언 **2,241건 중 사람이 세어 본 것은 41건(1.8%)** 뿐이다.

품질은 [계획 §5](../plan/README.md)의 오라클 *"심볼 리콜 표본"* 이 지며 **소유 기능은 아직 미정**이다.
근거는 [`criteria.toml`](../../corpus/criteria.toml) `[s0.does_not_prove]`.

**Java · JavaScript · TypeScript 도 판정하지 않는다.** 셋은 1급 지원 대상이지만
([지시 §1](../instructions/2026-08-12-owner-direction.md)) 사전 등록된 대조값이 없다.
S0 에서 셋의 자리는 `Capable::NotBuilt` 이고, 각각의 게이트는 따로 선다.
