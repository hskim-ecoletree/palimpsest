# F10-6 게이트 — **「다음에 오는 선언」을 「붙어 있음」으로** (#62 · #63) · **통과**

**판정: 통과.** 그리고 **[ADR-0016] 이 요구한 형태로 통과했다** — 명제를 다시 적은
것이 아니라 **구현이 계산하는 것을 명제에 맞췄다.**

`[f10.6]` 이 물은 것:

> **「다음에 오는 선언」을 「붙어 있음」으로 만들 수 있는가. 그리고 만들면서
> 안 붙여야 할 것을 계속 안 붙이는가.**

**둘 다 선다.** 결박이 **23 → 137** 로 서고 거짓 결박률이 **26.1% → 4.0%** 로 내려갔으며,
**빈 줄로 갈린 50 건과 붙을 선언이 없는 16 건은 하나도 안 붙었다.**

⚠ **그러나 이 회차의 가장 무거운 것은 통과가 아니라 [#63] 이다.**
재측정 표본이 **또 20 에 못 미쳤는데, 이번엔 이유가 갈렸다** — 결박은 **희소하지 않고**
(창 안 모집단 **52**), **표본기가 코퍼스당 10 으로 자른다.** §7 이 그것이다.

## 1. ⚠ **이 회차는 실측을 이미 본 뒤에 등록됐다** — 그것을 먼저 적는다

`registered_before_any_measurement = **false**` 다. [#62] 의 첫 코멘트가 진단을 끝내
두었고 **고칠 자리의 좌표까지** 알고 등록했다. `[f10.5].self_judged` 가 *"F10 의 실측을
이미 본 뒤에 쓴다"* 를 **한 겹 더 미끄럽다**고 적었는데, **이 절은 두 겹 더 미끄럽다.**

**줄이는 방법 다섯을 걸었고, 그중 셋이 실제로 무언가를 막았다:**

  · ★ **처방이 듣는 양(211)을 하한으로 등록하지 않았다.** 재현율의 하한은 **이미
    등록돼 있던** `bound_count_min`(50)이 졌다. **그리고 그것이 옳았다** — 실제 결박은
    **137** 이고 **234 가 아니었다**(처분 (나)가 50 건을 도로 떨어뜨렸다).
    ★ **211 을 하한으로 박았으면 이 회차는 반증으로 닫혔을 것이다.** 그것은 설계가
    틀려서가 아니라 **답을 베낀 눈금이 틀려서**였을 것이다
  · **값을 하나도 새로 안 지었다** — 5% · 50 · 50 · 20 · 10% 전부 `[f10.pass]` 와
    `[f10.4.pass]` 에서 옮겼다. 하한 1 은 이 저장소의 하한 관례다
  · **표본을 새로 뽑고 새 파일에 적었다** — F10-5 의 반증 근거를 안 덮었다

## 2. 무엇을 고쳤나 — **[ADR-0016] 이 요구한 형태로 적는다**

| | 문장 | 그것을 계산하는 코드 |
|---|---|---|
| **적힌 명제** | *"이 주석은 이 선언에 붙어 있다"* | — (요구사항이었다) |
| **옛 계산** | *"다음 형제 마디가 여기서 시작하고, 2층 심볼이 정확히 그 바이트에서 시작한다"* | `parse.rs::다음_선언` + `narrative.rs` 의 `자리` 맵 |
| **새 계산** | *"주석과 다음 마디 사이에 **빈 줄이 없고**, 그 마디에서 **래퍼를 벗긴 안쪽 선언**이 2층 심볼과 같은 바이트에서 시작한다"* | 같은 두 자리 |

### 가. 처분 (가) — **래퍼 마디를 벗긴다**

`export function f` 에서 다음 형제는 `export_statement` 이고 그 시작 바이트는
**`export` 키워드 자리**인데, 2층 심볼은 안쪽 `function_declaration` 에서 선다
(`typescript.rs::visit_export` → `declare`). `const X = …` 도 같다
(`lexical_declaration` ↔ `variable_declarator`). **한 바이트 차이로 못 붙었다.**

**근거는 원리다** — `export` 는 **가시성**을, `const` 는 **저장 종류**를 적을 뿐
**선언이 아니다.** 주석이 가리키는 것과 심볼이 서는 것이 **같은 선언**인데 마디의
시작만 다르다.

### 나. ⚠ **정확 일치를 푸는 쪽은 안 골랐다 — 그것이 이 처분의 절반이다**

*"그 바이트 이후 첫 심볼"* 로 조회를 바꾸면 래퍼는 저절로 풀린다. **그러나 그것은
추측이다** — 거리를 열면 **빈 줄로 갈린 파일 머리 주석이 더 멀리 있는 것에도 붙고**,
처분 (나)가 막으려는 바로 그것이 **다시 열린다.**
**벗기는 것은 구문 트리의 사실이고 거리를 여는 것은 추측이다.**

### 다. 처분 (나) — **빈 줄로 갈리면 붙어 있는 것이 아니다**

*"붙어 있다"* 는 **인접**이고 빈 줄은 **경계**다. ⚠ **주석을 건너뛸 때도 걸음마다
본다** — `// A` · 빈 줄 · `// B` · 선언 에서 A 가 B 를 건너뛰며 **빈 줄까지 건너뛰면**
이 규칙이 새 나간다(`빈_줄은_주석_블록도_가른다`).

### 라. 처분 (다) — **벗길 목록은 언어가 낸다**

`다음_선언` 은 **언어 공통**인데 래퍼는 언어마다 다르다. `parse.rs` 에 박으면
*"모든 언어가 TypeScript 처럼 생겼다"* 는 주장이 된다.
**TypeScript 넷 · Kotlin 빈 목록**(§6).

### 마. ★ **옛 시험이 옛 명제를 박고 있었다**

`주석이_다음_선언에_붙는다` 는 `src[at..].starts_with("export function cancel")` 을
단언했다 — **그것이 옛 고장 그 자체였다.** 단언을 **「심볼이 서는 자리와 같은가」**
로 바꿨다. **그것이 부르는 쪽이 실제로 하는 계산이다.**

## 3. ① 거짓 결박률 — **26.1% → 4.0%.** 그리고 새 형태가 하나 났다

```text
참 48 · 거짓 2 = **4.0%**   (상한 5%)   표본 50 · 결박 137 에서 등간격
```

★ **F10-5 는 결박이 23 이라 전수였고 표본 50 이 아니었다** — 이 절에서 ①이 **처음으로
자기 정의대로** 재어졌다.

| 거짓 | 형태 | 처분이 겨냥했나 |
|---|---|---|
| `loopStuckBlocked` | 주제는 `deriveNonPassStatus`(L610) · **빈 줄 없음** | ⚠ **아니다 — 예측했다** |
| `isAtOrAboveHome` | `findRepoRoot`(L52)의 doc 이 **그 함수 자신의 doc 위에 빈 줄 없이 얹혔다** | ⚠ **아니다 — 새 형태다** |

★ **둘 다 「구문 트리로 안 갈리는 것」이다.** 잘못 놓인 doc 주석은 문법의 사실이 아니라
**사람의 배치 실수**이고, 그것을 가르려면 **주석의 내용을 읽어야 한다** —
`[f10.pass]` ②가 금지한 자리다(유사도 금지). **그래서 안 고치고 §12 로 넘긴다.**

### ★ 그리고 회복된 것이 표본에서 세어진다

**종류로 세면 처분 (가)가 무엇을 돌려줬는지가 그대로 보인다:**

```text
F10-5 의 결박 23   function 19 · method 1 · type_alias 3 · **variable 0**
F10-6 의 표본 50   function 28 · interface 4 · type_alias 5 · class 1 · **variable 12**
```

★ **`variable` 은 전부 `const X = …` 이고 F10-5 에서는 하나도 안 붙었다.**
*"`export`·`const` 에 붙은 것은 0 건"* 이라는 진단이 **종류 분포로 다시 확인된다.**

## 4. ② 결박 하한(재현율) — **23 → 137.** 그리고 **234 가 아니다**

```text
표식 주석 조각  330  (ditto · portal-backend 0)
  결박됨   23 → **137**
  후보     0  → 0
  미결박  307 → **193**
```

★ **진단은 211 이 회복된다고 했고 실제는 114 였다.** 처분 (가)가 211 을 돌려주고
**처분 (나)가 그중 50 건을 도로 떨어뜨렸기 때문**이다 — `[f10.6].attachment_ruling`
처분 (나)가 *"이 처분은 재현율을 깎는다. 그것을 숨기지 않는다"* 라고 재기 전에 적었다.

⚠ **그래서 「빈 줄로 갈린 50 건 중 참이었을 것」이 이 회차의 미지수다.**
§5 가 그것을 다룬다.

**portal-backend 는 결박 0 이고 그것은 0% 가 아니라 대조 불가다** — `.kt` 에 `ADR-`
표식 주석이 **0 건**이다([ADR-0002] · [F16](../plan/features/F16-conventions.md)).

## 5. ④ 음성 대조 — **붙는 것을 늘렸는데 안 붙어야 할 것이 안 붙었다**

```text
빈 줄로 갈림        모집단 **50**  ·  결박 **0**
붙을 선언이 없음     모집단 **16**  ·  결박 **0**   (`import` 뒤 · 파일 끝)
```

★ **모집단 하한이 이 항목의 절반이다.** 없으면 **「막아서 0」과 「그런 주석이 없어서
0」이 같은 값**이 되고, 표식 주석이 하나도 없는 저장소에서 **만점**이 난다.

**그리고 갈래는 산출이 아니라 소스에서 줄로 셌다** — 산출로 세면 *"안 붙었으니 안
붙어야 할 것이었다"* 가 되어 **순환**하고, `다음_선언` 과 같은 방법으로 세면
**구현이 자기를 채점한다.** ⚠ **줄 기반이라는 것을 등록에 적어 두었다.**

### ⚠ 이 항목이 재지 **않는** 것 — 빈 줄로 갈린 50 중 참이 몇인가

**그것은 이 회차가 안 쟀다.** 재려면 **떨어진 50 건을 손으로 판정**해야 하고, 그것은
*"안 붙은 것이 옳게 안 붙었나"* 라는 **다른 측정**이다. 옛 여섯 중 다섯이 이 형태였고
**전부 거짓이었다**는 것이 유일한 근거인데, **그 표본은 여섯이다.**
**§12 로 넘긴다** — [ADR-0014] 가 이름 붙인 자리와 같은 형태다.

## 6. ⑥ Kotlin — **픽스처는 서고 실 코퍼스는 대조 불가다**

`다음_선언` 은 **언어 공통**이므로 처분 (나)는 두 언어를 다 지난다. 처분 (가)의
목록은 Kotlin 에서 **비어 있고**, 그것은 문법의 사실이다 —
`queries/kotlin/top-level.scm` 이 `source_file` 의 **직계 자식**을 심볼로 세므로
주석의 다음 형제가 **곧 그 마디**이고, 가시성·`annotation` 은 `modifiers` 로
**그 마디 안**에 들어간다.

```text
픽스처   인접 주석 → **결박 1**   ·   빈 줄로 갈린 주석 → **미결박 1**
실 코퍼스  portal-backend 의 `.kt` 중 `ADR-` 를 가진 파일 **0 개** → **대조 불가**
```

★ **빈 목록인 것이 「안 봤다」가 아니라 「보고 비었다」임을 시험이 센다** —
`코틀린도_심볼이_서는_자리에_붙는다` 가 **심볼이 서는 바이트와 같은가**를 단언한다.
⚠ **픽스처의 통과를 실 코퍼스의 통과로 적지 않는다**([ADR-0002] ·
[palimpsest-preflight-oracle-language-gap] 이 이름 붙인 자리다).

## 7. ★ ⑦ [#63] — **또 대조 불가다. 그러나 이번엔 이유가 갈렸다**

```text
⑨ ditto            결박 9 · 커밋 120 훑음 · 켜진 것 **0**        — 대조 불가 (코퍼스당 10)
⑨ portal-backend   창 안에서 건드려진 파일의 결박됨이 **0 건**    — 대조 불가
```

**세 회차 연속 대조 불가이고, 못 닫은 이유가 세 번 다 다르다:**

| | 왜 못 닫았나 |
|---|---|
| **F10** | 표본 15 · 켜진 것 7 — **그중 둘이 결박 자체가 거짓** |
| **F10-5** | 표본 9 · 켜진 것 0 — **결박이 너무 적다**(23) |
| **F10-6** | 표본 9 · 켜진 것 0 — ★ **결박은 충분한데**(창 안 **52**) **표본기가 코퍼스당 10 으로 자른다** |

### 가. ★ **[#63] 의 물음 2 에 답이 나왔다 — 하한 20 의 문제가 아니다**

[#63] 이 물었다: *"표본 하한 20 이 결박이 희소한 세계에서 영영 안 채워지는 값 아닌가."*

**이번 실측이 그 물음을 기각한다. 결박은 희소하지 않다:**

```text
ditto            결박 137 · 그중 창(커밋 120) 안에서 건드려진 파일의 것 **52**
portal-backend   결박   0 · 창 안 **0**              ← 표식 주석 0 건이라 구조적이다
f10-verify.py    `SAMPLES_PER_CORPUS` = **10**       ← 코퍼스당 상한
```

★ **그러므로 이 축에서 도달 가능한 최대가 10 이다** — 등록된 하한은 **20** 이고
코퍼스는 둘인데 **하나가 구조적으로 0** 이다. **표본기의 상한과 합격선의 하한이
어긋나 있고, 결박이 얼마나 늘든 이 어긋남은 안 없어진다.**

### 나. ⚠ **그런데 이 회차에서 표본기를 안 고쳤다 — 그것이 규율이다**

**고치면 값이 채워질 수도 있다. 그러나 고칠 자리는 측정기이고, 합격선을 못 채운 것을
본 뒤에 측정기를 고쳐 다시 재면 그 값은 이 회차의 근거가 될 수 없다**
(`[f10.2].sample_selection` 마지막 줄이 구현에 대해 적은 그것과 같은 형태다).
**등록에도 없다** — `[f10.6.pass].remeasure_grounds` 는 *"또 못 미치면 그것도 답이다"*
까지만 적었고 **표본기를 고친다고는 안 적었다.**

### 다. ★ **그리고 벽이 하나 더 있다 — 켜진 것이 0 이다**

표본을 52 로 늘려도 **거짓 양성률은 여전히 안 재어질 수 있다.**
`켜진 것`(창을 지나며 `stale`/`orphaned` 가 된 결박)이 **0** 이기 때문이다.
**표본이 차는 것과 잴 것이 생기는 것은 다른 문장이고, 지금 막힌 것은 둘 다다.**

**⚠ [ADR-0014] 의 빚은 안 닫혔다.** 낮추지 않는다 — **낮추는 것이 아니라 다른 측정을
설계해야 하는지**를 [#63] 에 적고 [F09 게이트](F09.md) §4-마 에 소급해 적는다.

## 8. ⑧ 후보 여럿의 모집단 — **열아홉째가 안 켜졌다**

```text
후보 여럿인 제안  **987**  (F10-5 회차와 같다)
```

`[f10.6].control_off_modes` 가 *"결박이 늘면 `[f10.5.pass]` ⑦의 모집단이 준다"* 를
재기 전에 적었다. **안 줄었다** — 표식 주석은 후보가 **0** 이고(확정 아니면 미결박),
후보 987 은 **문서 조각**에서 온다. **두 모집단이 겹치지 않는다.**

★ **예측이 틀렸고 그것이 기록이다.** `[f10.5.pass]` ⑦의 하한은 계속 선다.

## 9. ⑤ 기준선과 골든 — ⚠ **이번엔 「당연히」가 아니었다**

**골든 넷 하나도 안 움직였다.**

| 골든 | 값 |
|---|---|
| `s0-reference-vector.tsv` | 불일치 **0** · 1,122 파일 · 선언 **2,315** |
| `portal-backend.ledger.json` | **동일** (997) |
| `ditto.symbols.tsv` | 4,578 줄 · **움직인 것 0** |
| `portal-backend.symbols.tsv` | 1,340 줄 · **움직인 것 0** |

★ **왜 이번엔 이것이 진짜 음성 대조인가**: F10·F10-5 는 **의도층**만 건드렸으므로
골든이 안 움직이는 것이 **구조적으로 당연**했다. **이 절은 `pal-extract/src/parse.rs`
를 고쳤다** — 추출기 둘이 함께 지나는 파일이고, **시그니처를 바꿨다.**
`주석_수집이_요약을_안_건드린다` 가 그 경계를 지킨다.

### 가. 기준선 — **스물둘에서 스물셋이 됐다.** 착수 전 한 번, 종료 시 한 번

```text
cargo xtask check **15/15** · cargo test **384 → 389** · clippy **8** · s0 불일치 0
  선언 총수 2,315 · 선언 ≥1 파일 1,122(100%)
f22-1 9/9 · f22-2 7/7 · f22-3 실패 0 · f22-4 실패 0 · s1 4/4 · s2 6/6 · s3 5/5
f01 8/8 · f02-1~4 각 5/5 · f03-1 6/6 · f03-2 둘 · f03-3 4/4
f04 ⚠ 어긋남 1 (⑨ ditto 5.5 → **6.1배** · 하한 10)        ← [#61] · 환경
f05 ⚠ 어긋남 1 (⑨ ditto 8.9 → **9.4배** · 선 10) · 대조 불가 1  ← [#61] · **세 회차 다 났다**
f06 어긋남 0 · 대조 불가 2
f09 ⚠ 어긋남 1 (⑥ 하한 · [#58])
f10   어긋남 **4 → 3** · 대조 불가 **2 → 3**    ← 아래
f10-5 어긋남 0 · 대조 불가 **2 → 1**            ← 아래
f10-6 **어긋남 0 · 대조 불가 4**                ← ①은 손 판정이라 게이트가 낸다
```

★ **`f04`·`f05` ⑨ 가 세 회차 연속으로 선 아래이고 값이 매번 움직인다**(5.5/6.1 ·
8.9/9.4). **한 번은 관측이고 셋은 성질이다** — 소유자가 F05·F04 라 [#61] 로 넘긴다.

### 나. ⚠ **남의 게이트 둘이 이 회차 때문에 움직였다 — 그것을 통과로 적지 않는다**

```text
f10-5 ② 결박 하한   대조 불가(23 < 50) → **선다**(137)   ← 대조 불가가 2 에서 1 로
f10   ② 결박 하한   FAIL(23 < 50)      → **선다**(137)   ← 어긋남이 4 에서 3 으로
f10   ② ditto 강 신호 미결박   67.0% → **64.4%**         ← 여전히 상한 10% 위
f10   ① 층화        (결박 하한이 서야 도달한다) → **대조 불가**  ← 대조 불가가 2 에서 3 으로
```

⚠ ★ **F10 과 F10-5 의 판정은 안 바뀐다.** [ADR-0016] 이 스스로를 막은 그대로다 —
*"구현을 고친 뒤의 값은 그 회차의 통과 근거가 될 수 없다."*
**F10-5 의 ②는 그 회차에 대조 불가였고, 지금 서는 것은 F10-6 의 값이다.**
그리고 **`f10` 의 대조 불가가 하나 는 것은 회귀가 아니다** — ①의 층화는 **결박 하한이
서야 도달하는 줄**이고, 서기 전에는 **줄 자체가 안 났다.**

## 10. R-18 — 합격선을 정한 것도 판정한 것도 에이전트다

**닫히지 않는다.** 이 절에서 특히 무거운 자리 셋:

  · **거짓 2 의 판정이 손이다.** `[f10.2].sample_selection` 규칙 5 를 글자 그대로
    썼지만 *"주제인가 예시인가"* 는 사람의 읽기다. **표본과 근거를 조각마다 남긴 것이
    그 판정을 뒤집을 수 있게 하는 유일한 장치다**
  · **처분 둘을 고른 것이 에이전트다.** 반대 후보(조회 거리 열기)를 기각한 근거를
    §2-나 에 적었고, **그 기각이 틀렸다면 거짓률이 4.0% 보다 낮아질 수도 있었다**
  · **§7-나 의 「안 고친다」도 에이전트의 판단이다.** 소유자가 뒤집을 수 있다
