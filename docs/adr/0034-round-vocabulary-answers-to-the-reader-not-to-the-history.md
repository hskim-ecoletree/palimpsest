## 맥락

소유자가 `docs/overview.md` 를 읽고 이 저장소의 회차 어휘를 평가했다. 지적은 두 갈래다.

**첫째, 낱말이 안 통한다.** 1차 원문이 이름으로 지목한 것은 **「절단」**(원문 31행)과 **「봉투」**(32행)다.

> 절단, 예산 절단: elision 처음 접하는 어휘라서 찾아보니 언어학·발음 상 또는 문학등에서 '일부러 생략하는 음절'이라고 하네. 일반적으로는 '축약'또는 '생략' 이라고 하고, 그런데 절단은 손상과 파괴에 더 가까운 느낌이라 문맥 상 의도와는 맞지 않아.

> 봉투, 봉투 조립: 아마 envelop 을 얘기하는 것 같은데, 이 어휘는 잘 몰라서 사전을 찾아보니 '감싸다', '~를 덮다' 의 의미가 있던데. 봉투로 쓰는게 맞아?

**둘째, 「접다」 계열이 이해를 막는다**(원문 23행).

> '접다': 가장 많이 보이는 패턴 중 하나로 **선행 하네스는 접는 문을 갖고 열일곱 번 접었는데 사유 필드가 없어 왜 접었는지 하나도 못 읽는다.** 접는다는 어휘가 등장한 표현은 제대로 이해한 적이 없음. (…) '접는 문'은 정말 가관이라고 할만 함

그리고 표기 형식을 지정했다(원문 5행).

> 용어 중 상태나 코드성 데이터는 영어를 우선으로 하고, 사용자 표면에 나갈 때 사용자 언어와 같이 표기하는 형식을 사용할 것.

## ⚠ 이름의 근거로 이슈 인용을 쓰지 않는다

이슈 #111 은 소유자 인용 셋을 실었다. **그중 둘이 1차 원문에 없다.** 원문 31행 전문에 `퇴로`·`처분`·`오라클`·`8.8` 이 0 건이고, `git log --all -S` 로 훑으면 그 문장이 **이 회차의 정(正) 초안에서 처음 나타난다.** 「막힘」은 인용조차 없다.

소유자는 2026-09-06 에 **「넷 다 개명한다」**로 답했다. 그것은 **개명 지시**이지 *"그 인용이 내 말이다"* 가 아니다. **그러므로 이 ADR 은 이름의 근거를 원문 5행의 「코드성 데이터 / 산문」 축에서만 댄다.**

## 결정

### 1. 일곱 낱말

| 지금까지 | 축 | 새 표기 | 근거 |
|---|---|---|---|
| **처분** | 코드성 | **처리 방침(disposal)** | JSONL 필수 필드이자 enum 이다 → 원문 5행의 「코드성」. 영어 원 표기는 이미 저장소에 있다 — `disposal-overrides.jsonl` |
| **오라클** | 코드성 | **판정 명령(oracle)** | 식별자 `oracle` 과 해시 도메인 `pal.round.oracle.v1` 을 진다 → 코드성. 영어를 정본으로 두고 병기한다 |
| **접힘** | 코드성(기계 표시) | **철회(folded)** | 파일 이름 `folded.md` 가 이미 기계 표시다 → 영어가 정본. 한국어 쪽은 **「접다」 계열을 안 쓴다**(원문 23행) |
| **퇴로** | 산문 | **차선책** | 코드에 0 건이고 도달 표면이 스킬 문서뿐이다 → 산문. 사용자 언어 한 낱말 |
| **막힘** | 산문 | **교착** | 같음 |
| **절단** | — | **생략(elision)** | 원문 31행이 낱말을 직접 지정했다 |
| **봉투** | 코드성 | **응답 묶음(envelope)** | 타입 `Envelope` 를 진다 → 영어가 정본. 소유자가 「봉투」의 적합성을 물었고, 이 타입이 실제로 하는 일은 **답에 스냅샷·범위·생략·이관·로그·크기를 함께 묶어 내보내는 것**이다 |

**쓰지 않기로 한 낱말 둘 — 이미 다른 뜻이 있다.**

| 쓰지 않는 말 | 이미 무엇인가 |
|---|---|
| **차단** | `pal` 훅의 `{"decision":"block"}` 이 이미 「차단」이다(`crates/pal-cli/tests/hook.rs`). `crates/pal-core/src/budget.rs` 의 「연속 차단 상한」도 별개다. 「막힘 → 차단」은 낱말을 세 번째 개념에 겹친다 |
| **우회로** | `SKILL.md` 가 **승격**을 이미 *"잠금으로 되돌아가는 우회로"* 라고 부른다. 「퇴로 → 우회로」로 가면 두 개념이 한 낱말이 된다 |

⚠ **「생략」을 `fold` 에 주지 않는다.** 원문 31행은 그 낱말을 **`elision` 에** 배정했다. `fold` 에 주면 화면이 *"생략 1027건이 다른 질의로 옮겨졌습니다 — 잘린 것이 아닙니다"* 가 되어 뒷절이 앞절을 부정한다.

### 2. 세 뜻을 가른다 — 「접힘」·「오라클」이 각각 두 개념을 지고 있었다

| 자리 | 개념 | 새 표기 |
|---|---|---|
| 회차 절차 | 안 하기로 정하고 **사유를 남긴다** | **철회(folded)** |
| CLI `Fold`(`crates/pal-cli/src/evidence.rs`) | 값이 **있다.** 부피를 다른 질의로 옮겼다 | **이관(fold)** — `이관 N건 — 본체를 다른 질의로 옮겼습니다. 생략된 것이 아닙니다` |
| CLI `Elision` | 값이 **없다.** 예산 상한에 걸려 안 봤다 | **생략(elision)** |
| 회차 절차의 「오라클」 | 완수 조건을 판정하는 명령 | **판정 명령(oracle)** |
| 검증의 「바깥 오라클」 | 우리 답을 채점하는 외부 기준(SQLite CTE 등) | **바깥 대조 도구** |

`crates/pal-core/src/envelope.rs` 가 *"접기 — 부피를 옮긴 것. 생략이 아니다"* 로 타입에서 이미 갈라 두었고 `[f06].fold_is_not_elision` 이 시험으로 잠갔다. **화면이 그 가름을 따라간다.**

`surface/queries.toml` 의 `graph.dump` 요약 *"바깥 오라클이 읽는 창"* 은 사용자 화면에 나가고 바이트 대조를 지난다. 그것이 「바깥 대조 도구」로 바뀌었고, 파생 문서 `docs/query-catalog.md` 를 생성기로 다시 냈다.

### 3. 기계 계약 — 새 표기를 쓰고, 옛 표기도 계속 읽는다 (별칭)

「철회」의 기계 표시를 지는 자리가 둘이다.

| 계약 | 무엇을 요구하나 |
|---|---|
| `xtask/src/main.rs` 의 「원장 둘 대조」 | `folded.md` 에 `## 왜 철회했나` |
| `crates/pal-cli/src/round/status.rs` | `folded.md` 의 필수 절 셋 · `state.md` 의 `## 지금 단계` 본문 |

**그 문자열을 실제로 지고 있는 파일 다섯이 전부 지난 회차의 종결 기록이다.**

- 고치면 **증거 위조**다 — 그 회차가 그때 쓴 문장이 아니게 된다.
- 안 고치고 검사만 새 표기로 옮기면 **그 회차 전부가 빨개진다.**

**그래서 검사를 별칭으로 연다.** 새 표기(`## 왜 철회했나` · 「철회」)와 옛 표기(`## 왜 접었나` · 「접힘」)를 둘 다 받고, **새 회차는 새 표기로 쓴다.**

음성 대조를 걸었다 — `git clone` 으로 뜬 사본에서 `--root` 를 주고, 한 `folded.md` 의 제목을 **양쪽 표기가 아닌 것**으로 바꿔 검사가 실제로 빨개지는 것을 봤다. 그리고 새 표기만 든 사본이 통과하는 것도 함께 봤다. `pal round stop` 쪽은 새 표기로 쓴 종결문 픽스처를 시험에 더했다 — 옛 표기 픽스처만 두면 별칭이 「옛 것만 받는다」로 퇴화해도 아무것도 울지 않는다.

### 4. 레코드 필드 `처분` 은 옮기지 않는다

`findings.jsonl` 의 `처분`·`사전처분` 은 **필수 필드이자 파서 계약**이다. 좌표가 셋이다 — `.claude/skills/round/bin/record.py` 의 `REQUIRED` · `crates/pal-cli/src/round/status.rs` 의 `required_strings`·`known_fields` · `xtask/src/main.rs` 의 `요구하는_자리`.

**결정: 필드 이름을 안 바꾼다. 표시와 이름을 가른다.** 용어의 정본은 `disposal` 이고 사람이 읽는 자리는 전부 「처리 방침(disposal)」이다.

근거 셋:

1. **모집단이 잠겨 있다.** 실측 — `findings.jsonl` 여러 파일에서 `"처분"` 키를 지는 행이 **1500 을 넘고** 예외표 두 파일에서 **89**(예외표 전체는 125행이고 그중 `"처분"` 키를 지는 것이 89 다). ⚠ **정확한 수를 이 ADR 에 안 적는다** — 회차가 레코드를 더할 때마다 늘어서, 여기 박으면 다음 커밋에서 낡는다. 잰 커밋과 함께 적는 자리는 게이트의 `D2` 절이다. 그 대부분이 지난 회차의 종결 기록이고, 이 회차의 범위 결정(`G1`)이 그것을 영구 범위 밖으로 두었다.
2. **소급 이주를 안 하기로 이미 정했다.** `SKILL.md` 의 레코드 스키마 절이 *"소급 이주하지 않는다"* 를 못 박았다. 별칭으로 열면 같은 개념의 키가 두 벌이 되고, 그때 `record.py count` 의 집계 축이 갈린다 — §3 의 별칭은 **문서 제목** 하나라 그 위험이 없지만 필수 필드는 다르다.
3. **소유자가 지정한 형식이 겨눈 것은 「사용자 표면에 나갈 때」다.** JSONL 키는 저장 형식이지 출력이 아니다. **출력은 전부 바꿨다** — `record.py count` 의 축 이름 · `check` 의 오류 문장 · 계기판의 해악 게이트 줄 · `SKILL.md` · 에이전트 정의 다섯.

⚠ **이것이 이 결정의 값을 치르는 자리다.** 레코드를 직접 열어 보는 사람은 필드 이름 `처분` 과 문서의 「처리 방침」이 다른 낱말인 것을 본다. 그래서 `SKILL.md` 와 `docs/overview.md` 가 그 사실과 까닭을 명시적으로 적는다.

### 5. 적용 범위 — 확정만 하지 않는다

이름은 **실제로 적용됐다.** 설치 페이로드가 남의 프로젝트로 나가므로 거기까지 포함한다.

| 자리 | 무엇 |
|---|---|
| `.claude/skills/round/SKILL.md` | 절 제목 · 루프 도식 · 종결문 서식 |
| `.claude/skills/round/bin/record.py` · `dashboard.py` | **실행 출력**으로 찍는 자리 — 대응표 · 해악 게이트 줄 |
| `.claude/agents/pal-*.md` 다섯 | `description` 과 판정 기준 표 |
| `crates/pal-cli/src/round/status.rs` · `xtask/src/main.rs` | 별칭과 오류 문장 |
| `crates/pal-cli/src/{evidence,touch,doctor,query}.rs` | 화면 문자열 |
| `crates/pal-cli/assets/**` | 설치본 |
| `schema/graph.toml` · `surface/queries.toml` 과 파생 문서 둘 | 생성기로 다시 냈다 |
| `docs/**`(동결분 제외) · `scripts/**` | 산문 |

## 범위 밖

- **`docs/adr/**` · `docs/gates/**` · `docs/instructions/**` · `corpus/**`** — 그 시점의 기록이거나 합격선 정본이다.
  ⚠ **`docs/research/**` 는 여기 없다.** `G1` 의 정반합 판정이 그것을 **대상에 넣었다** —
  `docs/plan/disposal-map.md`·`docs/agents/domain.md`·`crates/pal-core/src/derived.rs` 가
  그것을 **살아 있는 참조**로 인용하기 때문이다. 이 절이 한때 그것을 동결로 적었고,
  그래서 20곳이 「0곳」으로 집계됐다(독립 리뷰 R1 · 발견 5 · 금지역).
- **`.palimpsest/rounds/**` 의 지난 회차 기록** — 인용과 잡아 둔 출력이다. §3 의 별칭이 그것을 안 건드리고도 검사가 서게 한다.
- **개발자만 읽는 「오라클」** — `scripts/*.py` 와 시험 주석의 「바깥 오라클」은 검증 분야의 표준 용어이고 사용자 표면이 아니다. §2 가 가른 것은 **사용자 화면에 나가는 자리**다.
- **`Fold`·`Elision`·`Envelope` 타입 이름** — 영어가 정본이므로 안 바꾼다.

## 대안과 그것이 빠진 까닭

| 대안 | 왜 안 골랐나 |
|---|---|
| 지난 17회차 기록을 전량 이주한다 | 증거 위조다. 그리고 「원장 둘 대조」가 기존 회차 전량에 대해 다시 돌아야 한다 |
| 새 회차부터만 새 어휘를 쓰고 검사는 그대로 둔다 | 새 표기로 쓴 회차가 빨개진다 — 검사가 옛 문자열만 요구한다 |
| `findings.jsonl` 키를 `disposal` 로 옮긴다 | §4 |
| `findings.jsonl` 키를 별칭으로 연다 | §4-2 — 필수 필드가 두 벌이 되면 집계 축이 갈린다 |
| 「막힘 → 차단」 | §1 — 「차단」은 이미 훅의 것이다 |
| 「퇴로 → 우회로」 | §1 — 「우회로」는 이미 승격의 것이다 |
| 「접힘 → 생략」 | §1 ⚠ — 소유자가 그 낱말을 `elision` 에 배정했다. 정반대다 |

## 결과

- 회차 문서와 CLI 화면이 같은 낱말을 쓴다. `docs/overview.md` 가 달고 있던 「스킬 용어: X」 각주가 없어졌다 — 두 어휘가 하나가 됐기 때문이다.
- 지난 회차 기록은 한 글자도 안 바뀌었고 검사는 전량 통과한다.
- 레코드 필드 이름 하나(`처분`)가 옛 이름으로 남는다. 그 사실과 까닭이 `SKILL.md` 와 `docs/overview.md` 에 적혀 있다.
