# ADR — **채택 시점의 결정 기록**

여기 있는 것은 **그때 무엇을 왜 정했는지**다. 사후에 안 고친다.

## 왜 안 고치나

ADR 은 근거를 지고 채택된다. 근거 절을 나중에 손보면 **그 결정이 무엇에 근거해
채택됐는지가 사라진다** — 남는 것은 「지금 보기에 그럴듯한 이유」이고, 그것은 결정의
기록이 아니라 결정의 **재구성**이다.

`docs/gates/` 의 판정 문서 · `docs/instructions/` 의 소유자 지시 원문 ·
`corpus/criteria.toml` 의 사전 등록 대장이 같은 자격이다.

**그래서 `cargo xtask check` 의 죽은 링크 검사는 이 디렉터리를 안 훑는다.** 훑으면
검사가 동결을 깨라고 요구한다.

## ★ 그래서 여기 죽은 링크가 있다

2026-08-18 **재고 처분 회차**가 `WHITEPAPER.md` · `docs/DESIGN.md` ·
`docs/how-it-works.md` · `docs/plan/features/` 25 파일을 지웠다. 이 디렉터리에서
그것들을 가리키던 링크는 **그대로 둔다.**

⚠ **`ADR-0025` 자신이 그 문서들을 자기 논증의 근거로 인용한다** — 백서 §1
(*"낡은 문서는 거짓 신호가 된다"*)과 `DESIGN §0.7`(사관↔큐레이터 충돌). 그 링크를
고치면 **ADR-0025 가 무엇을 읽고 방향을 틀었는지가 안 보이게 된다.**

**무엇이 어디로 갔는지는 [`docs/plan/disposal-map.md`](../plan/disposal-map.md) 가 진다.**
결정 99 개(`D1~D35` + 좌표 64)와 기능 26 개의 행선지가 거기 한 행씩 적혀 있다.

**원문은 사라지지 않았다:**

```bash
git log --diff-filter=D --oneline -- docs/DESIGN.md   # 언제 지웠나
git show <커밋>^:docs/DESIGN.md                        # 그때의 전문
```

## 지금 몇 개인가

세지 않는다. `ls docs/adr/` 가 답하고, 언제 무엇이 들어왔는지는 `git log docs/adr/` 다.
**문서가 그 수를 복제하면 그 문서는 낡는 캐시다**(AGENTS.md).

## 언제 새 ADR 을 내나

**기능이 끝날 때.** 착수 시점의 ADR 은 결정이 아니라 **계획의 복사본**이다
(`/round` §9). 그래서 `DESIGN.md` 가 남긴 「ADR 후보」 44 개 중 이 회차가 발행한 것은
**하나**(`0026`)뿐이고, 나머지는 아직 안 만든 기능의 결정이라 [처분표](../plan/disposal-map.md)
가 `B`(다음 회차가 다시 정한다)로 적었다.

역방향도 사실이다 — **여기 있는 26 개 중 13 개는 `DESIGN.md` 의 후보 목록에 없었다.**
구현이 그 자리에서 새로 세운 결정이고, 그것이 이 규칙이 작동한 증거다.
