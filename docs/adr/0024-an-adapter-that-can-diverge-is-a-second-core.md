# ADR-0024 — **갈릴 수 있는 어댑터는 두 번째 코어다.** 표면을 더할 때 목록을 더하지 않는다

**상태**: 채택 (2026-08-17) · [F06b](../gates/F06b.md) 종료 시점에 발행 ·
근거 [F06b 게이트](../gates/F06b.md) 판정 절 · [F06 §1.1·§2](../plan/features/F06-surface.md) ·
[ADR-0012](0012-a-single-truth-file-declares-only-what-has-a-counterpart-in-code.md)

## 맥락

F06 은 표면의 지위를 이미 정해 두었다 — ***"1급은 CLI 다. 프로토콜은 어댑터다."***
그리고 §2 의 규칙 1 이 *"질의 추가는 `queries.toml` 변경으로만 일어난다"* 를 못 박았다.

그런데 **같은 문서 §4.2 의 구현 스케치가 그 규칙과 부딪혔다.** 스케치는 MCP 툴을
`#[tool_router]` + 질의마다 함수 하나로 그렸다:

```rust
#[tool(description = "…")]
async fn touch(&self, Parameters(a): Parameters<TouchArgs>) -> … { … }
```

**이 형태는 질의 열 개에 함수 열 개를 손으로 적는다.** 그 열 개가 곧 두 번째 목록이고,
`queries.toml` 이 변해도 따라오지 않는다. 카탈로그 ↔ 코드의 양방향 대조
(`[f06.1.pass]` ①)는 **그 두 번째 목록에 대해서는 아무 말도 하지 않는다** — 새 표면에
대해 대조가 **꺼진 채로** 도는 것이고, [ADR-0012] 가 *"짝 없는 이름"* 으로 이름 붙인
자리의 뒷면이다.

## 결정

**표면을 더할 때 목록을 더하지 않는다. 목록은 언제나 코드가 이미 아는 것에서 렌더링된다.**

셋으로 나뉜다:

1. **툴 정의는 `QueryName::ALL` 을 순회해서 만든다.** 매크로로 함수마다 툴을 세우지
   않는다. `rmcp` 의 `ServerHandler::list_tools` 를 직접 구현하면 되고, 그 형태가
   실제로 선다는 것은 착수 전에 확인했다.
2. **어댑터가 조립을 갖지 않는다.** 질의를 돌리는 데 필요한 것(대장 · 2층 · 의도
   저장소 · 예산 · 낡음)의 조립은 표면 **밖**에 하나로 남고, 어댑터는 그것을 트레이트로
   **받는다**. 어댑터가 자기 조립을 쓰면 예산 하나가 달라도 같은 질의가 다른 답을 낸다.
3. **새 표면은 「자기 목록을 갖지 못하게 하는 검사」의 대상에 즉시 들어간다.**
   `cargo xtask check` 의 방향 4 가 훑는 디렉터리 목록에 그 표면을 더하지 않으면,
   그 표면에 대해 검사가 꺼진 채로 돈다.

셋째가 이 ADR 의 실질이다. **첫째와 둘째는 이번에 지켰다는 사실이고, 셋째는 다음에도
지켜지게 하는 장치다.**

## 결과

- MCP 툴은 질의가 늘면 **따라 는다.** 갈릴 방법이 없다.
- 어댑터 크레이트는 `pal-cli` 에 의존할 수 없다(의존 방향 규칙 3). 그 제약이 둘째를
  **강제한다** — 조립을 쓰려면 트레이트로 받는 수밖에 없다.
- 방향 4 의 스캔 대상이 상수 하나(`SURFACE_SOURCES`)로 모였고, **없는 디렉터리는
  조용히 건너뛰지 않고 문제로 적힌다** — 스캔이 0 개를 훑고 통과하는 형태를 막는다.

## ⚠ 이 결정이 안 덮는 것

- **`.rs` 밖의 표면.** 방향 4 는 Rust 소스만 훑는다. 플러그인 매니페스트
  (`plugin.json` · `commands/*.md`)에 질의 이름을 박아도 **아무것도 울지 않는다.**
  지금은 손으로 댔고, 그 사실이 [F06b 게이트](../gates/F06b.md) §판정-나-⑨ 에 있다.
- **인자의 타입.** 이름과 필수 여부는 대조되지만 카탈로그의 `type`(`SymbolName` ·
  `RepoPath`)이 어댑터가 내는 스키마와 같은지는 아무도 안 댄다.
- **호스트가 하나라는 것.** 세션은 클라이언트 하나로 쟀다. *"MCP 를 지원한다"* 는
  그보다 넓은 문장이고 이 결정은 그것을 주장하지 않는다.
