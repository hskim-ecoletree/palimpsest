# ADR-0006 — 정체성 등급은 **언어가 아니라 심볼**이 진다. 그리고 그것이 정규화를 정한다

**상태**: 채택 (2026-08-13) · [F02](../gates/F02.md) 종료 시점에 발행 ·
근거 [F02-3 게이트](../gates/F02-3-scope.md) · [R-22](../plan/00-risks.md#r-22)

## 맥락

`body_digest` 는 *"이 선언이 **변했는가**"* 에 답하는 값이다. 그 답이 쓸모 있으려면 두
방향이 동시에 참이어야 한다:

- **포매터가 매일 바꾸는 것**(공백 · 주석 · 지역 변수 이름)에 안 움직여야 한다. 안 그러면
  `rename` 한 번에 결박이 무더기로 `stale` 이 되고, 사람이 표시를 무시하기 시작하면
  제품이 죽는다([R-07](../plan/00-risks.md#r-07))
- **의미가 변하면** 반드시 움직여야 한다

지역 변수 이름을 지우려면 **어느 이름이 지역인지 알아야 한다.** 그런데 그것은 언어가
아니라 **그 심볼 하나하나**에 달려 있다 — 같은 TypeScript 파일 안에서도
`const { a, b } = x` 가 있는 심볼은 무슨 이름이 묶였는지 알 수 없다.

[R-22](../plan/00-risks.md#r-22) 가 경고한 것이 정확히 그 자리다:

> 등급이 못 미치는데 지우면 **서로 다른 코드가 같은 digest 를 갖는다.**

**언어 단위 등급 표 하나로는 이것을 표현할 수 없다.** `grade_of(TypeScript) == L2` 는
*"이 언어에서 스코프를 만든다"* 는 뜻이지 *"이 심볼에서 스코프 해소가 성공했다"* 가
아니다. 표만 남기면 **실패한 심볼이 성공한 것처럼 보이고 그 심볼에서 이름이 지워진다.**

반대로 심볼 등급만 남기면 대장 머리의 *"결박 불가 언어 N 개"* 가 설 자리를 잃는다
([DESIGN §2.2](../DESIGN.md)) — 사용자는 파일을 열기 전에 **그 언어가 결박 가능한지**를
알아야 한다.

## 결정

**등급을 두 층으로 둔다. 언어 표는 *선언 상한*이고, 실제 등급은 *심볼*에 실린다.**

```rust
grade_of(Language) -> ExtractGrade     // 선언 상한 — 대장 머리가 읽는다
Symbol { …, identity: IdentityGrade }  // 실측 — 정규화가 읽는다

identity = min(측정값, grade_of(언어).identity())
```

그리고 **그 값이 정규형을 정한다**:

| 심볼 등급 | 정규화 |
|---|---|
| `exact` | 그 심볼 안에서 선언된 **심볼이 아닌** 이름을 **선언 순서의 자리 번호**로 지운다 |
| `ordinal` | **지우지 않는다** |

세 규칙이 함께 간다:

1. **실측이 선언 상한을 넘지 못한다.** 넘으면 언어 표가 심볼이 가진 것보다 낮은 값을
   광고하고, 그러면 표가 뜻을 잃는다
2. **모르면 지우지 않는다.** 이름을 못 잡은 바인딩이 심볼 안에 하나라도 있으면 그 심볼은
   `ordinal` 이다 — 본문의 어떤 이름이 그것을 가리키는지 알 수 없기 때문이다
3. **자리 번호는 구별된다.** 전부 한 바이트로 지우면 `f(a, b)` 와 `f(a, a)` 가 같아진다.
   *어느 지역인지*는 남기고 *그 이름*만 지운다

### 무엇이 「해소 실패」인가 — **이 정의가 결정의 절반이다**

| 참조가 | 실패인가 |
|---|---|
| **import · 전역**(`console`) | **아니다** — 파일 하나만 보는 연산에서 **정확한 답**이다 |
| 선언 전 참조(TDZ) | 그렇다 |
| 이름을 못 잡은 바인딩이 심볼 안에 있다 | 그렇다 |

**`OutsideFile` 을 실패로 세면 안 된다.** 실물에서 파일 밖 참조가 9,862 건이라 거의 모든
심볼이 `ordinal` 로 떨어지고, 그러면 이 등급이 *"이 심볼이 얼마나 자족적인가"* 를 재게
된다 — **지우기의 안전성과 무관한 값**이다. R-22 가 묻는 것은 *"이 이름이 지역인지
아는가"* 이지 *"이 이름이 어느 파일에 있는지 아는가"* 가 아니다.

## 결과

- **한 언어 안에서 등급이 갈린다.** ditto 496 파일의 심볼 4,656 중 **335 가 `ordinal` 로
  내려앉는다**(구조 분해 · TDZ). 그 심볼들에서는 이름이 안 지워진다
- **언어를 올릴 때 다른 언어가 딸려 오르지 않는다.** `grade_of` 의 팔을 언어마다 갈라
  두는 것이 이 결정의 딸린 규율이다 — F02-3 이 TypeScript 만 L2 로 올렸고 Kotlin 은 L1 ·
  `ordinal` 로 남았다. 합쳤으면 `f01-verify` 의 등급 음성 대조가 무의미해졌을 것이다
- **`body_digest` 를 만드는 시점이 순회 밖으로 나간다.** 등급은 파일 전체를 다 보아야
  정해지므로, 선언을 만나는 그 자리에서 요약을 계산할 수 없다(`24207a3` 이 그 구조적
  변경이다)
- **추출기 버전을 올려야 한다.** 정규형이 바뀌면 옛 캐시가 옛 요약을 새 스키마로 되돌려
  준다 — [ADR-0004](0004-cache-key-covers-every-input-that-decides-the-output.md) 의
  키에 그 축이 이미 있다

### 이 결정이 닫지 **않는** 것

**R-22 는 여기서 닫히지 않는다.** 그 위험의 판정은 **F03** 이고, *"포매팅 커밋에서
`stale` 0 건"* 이 그 합격선이다. 이 결정이 세운 것은 **그 게이트가 최종 형태에서 측정될
수 있게 되는 것**까지다.

**그리고 A 만 재면 안 된다.** *"지우는가"* 만 보면 **"항상 지운다"** 가 만점을 받고,
그것이 R-22 가 경고한 충돌 그 자체다. `ordinal` 심볼에서 **안 지우는 것**을 같은 무게로
재는 검사가 이 결정과 함께 서야 한다.
