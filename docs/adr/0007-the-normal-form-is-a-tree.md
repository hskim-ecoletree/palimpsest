# ADR-0007 — 정규형은 **토큰 열이 아니라 트리**다. 그래야 스타일을 지울 수 있다

**상태**: 채택 (2026-08-13) · [F03](../gates/F03.md) 종료 시점에 발행 ·
근거 [F03-2 게이트](../gates/F03-2-normalize.md) · [R-22](../plan/00-risks.md#r-22)

## 맥락

`body_digest` 는 *"이 선언이 변했는가"* 에 답한다. 그 답이 쓸모 있으려면 **포매터가
매일 바꾸는 것에 안 움직여야** 한다([R-07](../plan/00-risks.md#r-07)).

F02 는 정규형을 **평평한 토큰 열**로 만들었다 — 구문 트리를 순회하며 리프 토큰을
모으고, 주석과 선택적 세미콜론을 버린다. 그것으로 공백·주석·세미콜론·따옴표·후행
쉼표까지는 지울 수 있었다.

**그런데 실물 포매터는 괄호를 지운다.** `prettier` 를 ditto 496 파일에 한 번 돌리자
심볼 **58 개**(파일 40)가 움직였고 **원인이 그것 하나였다**:

```ts
(a, b) => (cond ? x : y)     →     (a, b) => cond ? x : y
```

그리고 **평평한 토큰 열에서는 그 괄호를 지울 수 없다.** 지우면

```
(a+b)*c   →   a + b * c
a+b*c     →   a + b * c      ← 같아진다
```

[R-22](../plan/00-risks.md#r-22)가 경고한 **"서로 다른 코드가 같은 digest 를 갖는다"**
그 자체다. 괄호는 **우선순위를 싣는 유일한 토큰**이었고, 그것을 지우는 순간 정규형이
프로그램을 구별할 수 없게 된다.

## 결정

**정규형은 트리의 직렬화다. 마디마다 여닫는 표식을 싣는다.**

```text
(a+b)*c  →  ⟨ ⟨a+b⟩ * c ⟩
a+b*c    →  ⟨ a + ⟨b*c⟩ ⟩      ← 다르다
```

그러면 **우선순위를 트리 모양이 지므로 괄호 토큰을 버릴 수 있다.** 이것이 이 결정의
전부이고, 뒤따르는 것 셋이 같은 원리에서 나온다:

| 벗기는 것 | 왜 벗겨도 되나 |
|---|---|
| `parenthesized_expression` | 자식의 자리를 트리가 이미 안다 |
| 합집합·교집합 타입의 **선행 `\|`** | 왼쪽 피연산자가 없는 `\|` 는 구분자뿐이다 |
| **자식이 하나뿐인** `union_type`·`intersection_type` | 그 자식과 같은 타입이다 — 그런데 트리에는 마디가 하나 더 있다 |

셋째가 이 결정의 딸린 규율이다: **표식을 싣기 시작하면 「같은 뜻인데 마디 수가 다른」
자리가 전부 후보가 된다.** 선행 `|` 하나를 지우는 것만으로는 부족했고, 그 사실이
`| A | B` 와 `A | B` 를 대 보고 나서야 드러났다.

**F03 문서 §2 가 이미 *"구문 트리에서 주석·공백·포매팅을 제거한 정규형"* 이라고
적었다.** 이 결정은 그 문장을 뒤집는 것이 아니라 실현하는 것이다 — 평평한 토큰 열은
*"구문 트리에서"* 의 절반만 쓰고 있었다.

## 결과

- **정규형이 문법 노드 이름에 묶인다.** 마디 표식이 tree-sitter 의 `kind()` 다.
  문법을 올리면 노드 이름이 바뀔 수 있고 그러면 **모든 요약이 이동한다.**
  [ADR-0004](0004-cache-key-covers-every-input-that-decides-the-output.md)의 키에
  `grammar` 축이 이미 있으므로 **표현은 되지만, 묶임이 세졌다는 사실은 새것이다** —
  문법 승급이 이제 좌표 이동을 동반한다
- **더 정확해졌다.** 트리 모양이 실리므로 같은 토큰 열을 갖는 서로 다른 프로그램이
  갈린다. `body_digest` 가 재는 것이 *"글자가 같은가"* 에서 *"구조가 같은가"* 로 옮겼다
- **두 언어가 같은 규칙 위에 선다.** `parenthesized_expression` 은 두 문법에서 이름이
  같고, 마디 표식은 언어와 무관하다. F02 가 *"언어마다 따로 쓰면 같은 리팩터가 한
  언어에서만 결박을 `stale` 로 만든다"* 라고 적은 규율이 지켜진다
- **요약이 통째로 한 번 이동했다.** 심볼의 뿌리 마디에 표식이 붙으므로 예외가 없다 —
  ditto 4,578 · portal-backend 1,296 **전부**. `EXTRACTOR_REV` 가 그것을 진다

### 이 결정이 닫지 **않는** 것

**「같은 뜻인데 트리가 다른」 것은 여전히 갈린다.** `new RegExp('x')` 와 `/x/` 는 다른
요약을 갖고, 그것이 옳다고 판단했다([F03-2 게이트](../gates/F03-2-normalize.md) §5) —
같다고 적으려면 *"두 표현식이 같은 값을 만든다"* 를 알아야 하고 그것은 이 기능이
보증하지 않는다고 F03 §4.2 가 스스로 적었다.

**어디까지 벗길 것인가에 바깥 정본이 없다.** 이 결정이 벗긴 셋은 실물 포매터가 실제로
바꾼 것을 보고 고른 것이고, **다음 포매터·다음 언어는 넷째를 요구할 수 있다.**
그때의 판단 기준은 이 ADR 이 세운 하나다 — **벗겨도 프로그램을 구별할 수 있는가.**
