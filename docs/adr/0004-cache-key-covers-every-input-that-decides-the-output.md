# ADR-0004 — 캐시 키는 내용이 아니라 산출을 정하는 입력 전부를 담는다

**상태**: 채택 (2026-08-13) · [F01](../gates/F01.md) 종료 시점에 발행 ·
근거 [F01 게이트](../gates/F01.md)

## 맥락

[stack §2.4](../plan/00-stack.md)는 1층을 **콘텐츠 주소 캐시**로 정했고 키를
`(blob 이름, 추출기 버전)` 으로 잡았다. 그 이름이 뜻하는 바는 *"같은 내용이면 같은
산출"* 이고, 추출에 대해서는 참이다 — `Symbol` 은 이름·종류·본문 요약이고 경로를 보지
않는다.

**그런데 캐시가 담는 것은 추출 결과가 아니라 `FileOutcome` 이다.** 거기에는 `FileState`
가 들어 있고 그것은 **분류 결과**다. 분류는 내용만 보지 않는다:

- 언어를 **확장자와 파일 이름**에서 얻는다
- `Generated` 판정이 **경로 패턴**(`/generated/` · `.generated.`)을 본다
- F01 이 켠 인식 ③ 은 **`.gitattributes` 의 `linguist-language`** 를 보고 그것이 위
  둘을 이긴다

**키가 blob 뿐이면 내용이 같고 경로가 다른 두 파일이 한 칸을 쓴다.** 빈 파일이 그
자리다 — 빈 `.kt` 와 `.gitkeep` 은 같은 blob(`e69de29`)이고, 먼저 온 쪽의 분류가 뒤에
온 쪽에 그대로 나간다. 대장이 파일의 언어를 틀리게 적고 **그 틀림이 캐시에 굳는다.**

[S1 의 캐시 합격선](../../corpus/criteria.toml)은 이것을 잡지 못했다. 그것이 물은 것은
*"적중했을 때의 산출이 미스했을 때와 같은가"* 였고, 여기서는 **둘 다 틀린 답**이다.

## 결정

**캐시 키는 그 캐시가 담는 산출을 정하는 입력을 전부 담는다.**

`(blob 이름, 추출기 버전, 경로, 선언된 언어)` 이고, 형태가 바뀌면 키의 층 표시를
올린다(`pal1` → `pal2`) — 옛 항목이 새 규칙으로 읽히지 않게.

**규칙은 "내용이 같으면 같은 키" 가 아니라 "산출이 같아야 할 것들만 같은 키" 다.**
캐시에 담을 값을 정할 때 *"이 값이 무엇에 의존하는가"* 를 먼저 세고, 그 목록이 키다.

## 결과

- **값을 치른다.** 파일을 옮기면 내용이 같아도 미스가 난다. 대장이 거짓말하지 않는
  값으로 싼 편이고, 이동은 흔한 일이 아니다.
- **분류와 추출을 나누면 키를 되돌릴 수 있다.** 지금은 한 캐시가 둘을 함께 담는다.
  추출 결과만 담는 캐시를 따로 두면 그쪽 키는 `(blob, 버전)` 으로 충분하다 —
  그 분리가 필요해지는 것은 재사용률이 실제로 문제가 될 때이고, 그것은 측정이 정한다.
- **이 규칙은 1층만의 것이 아니다.** 2층의 파생물, F05 의 증분 재추출 단위, F17 의
  합성물 재현 입력 — **무엇이든 캐시하는 자리에 같은 질문이 걸린다.**
  [ADR-0002](0002-empty-population-is-not-zero-violations.md)가 *검사*에 건 규율
  (*"모집단이 없으면 0 이 아니다"*)과 짝이 된다: 이쪽은 *산출*에 건다 —
  **입력을 다 세지 않은 키는 틀린 답을 정답처럼 굳힌다.**
- **실물에서 드러나지 않은 결함을 고쳤다는 사실을 숨기지 않는다.** 코퍼스에는 확장자가
  다른 중복 blob 이 0 건이다(세어 봤다). **드러나지 않는 것과 없는 것은 다르고**,
  인식 ③ 을 켜면서 분류가 `.gitattributes` 에도 의존하게 되어 위험이 커졌다.

## 무엇이 이 결정을 뒤집는가

- **캐시가 담는 값에서 경로 의존이 사라지면.** 분류를 캐시 밖으로 빼고 추출 결과만
  담게 되면 키는 `(blob, 버전)` 으로 돌아간다.
- **재사용률이 실제로 문제가 되면.** 대규모 리팩터링(디렉터리 이동)에서 캐시가 통째로
  무효화되는 비용이 측정에서 드러나면, 키를 경로 전체가 아니라 **분류에 실제로 쓰이는
  성분**(확장자 · 파일명 · 생성물 패턴 매칭 여부 · 선언된 언어)의 요약으로 좁힌다.
  지금 그렇게 하지 않은 이유는 **성분 목록이 분류 규칙과 함께 자라고, 자라는 목록을
  키에 손으로 유지하면 그 목록이 낡는 순간 같은 결함이 돌아오기 때문**이다.
